# Chapter 20. Docker 모니터링

## 20.1 모니터링 개요

Docker 컨테이너 모니터링은 다음 메트릭을 추적합니다:

| 메트릭 | 설명 |
|--------|------|
| CPU | CPU 사용률 |
| Memory | 메모리 사용량 및 제한 |
| Network I/O | 네트워크 입출력 |
| Block I/O | 디스크 읽기/쓰기 |
| PIDs | 프로세스 수 |

## 20.2 docker stats 명령어

### 기본 사용법

```bash
# 실행 중인 모든 컨테이너 실시간 모니터링
docker stats

# 출력 예시
CONTAINER ID  NAME          CPU %   MEM USAGE / LIMIT   MEM %    NET I/O         BLOCK I/O
abc123def456  my-nginx      0.00%   4.5MiB / 3.84GiB    0.12%    1.2kB / 0B      0B / 0B
ghi789jkl012  my-mysql      3.41%   512MiB / 3.84GiB    13.02%   25.6kB / 18.2kB 150MB / 25MB
mno345pqr678  my-app        15.62%  256MiB / 512MiB     50.00%   100kB / 50kB    10MB / 5MB
```

### 상세 옵션

```bash
# 한 번만 출력 (실시간 스트리밍 없이)
docker stats --no-stream

# 특정 컨테이너만
docker stats my-nginx my-mysql

# JSON 형식 출력
docker stats --format json --no-stream

# 커스텀 형식
docker stats --format "table {{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}\t{{.MemPerc}}"

# 컨테이너 이름과 메모리만
docker stats --format "{{.Name}}: CPU={{.CPUPerc}}, MEM={{.MemUsage}}"
```

### 스크립트 활용

```bash
#!/bin/bash
# 메모리 임계값 초과 컨테이너 알림
while true; do
  docker stats --no-stream --format "{{.Name}}\t{{.MemPerc}}" | \
  while IFS=$'\t' read -r name mem_perc; do
    # % 제거 후 숫자 비교
    mem_num=$(echo $mem_perc | tr -d '%')
    if (( $(echo "$mem_num > 80" | bc -l) )); then
      echo "ALERT: $name 메모리 사용량 ${mem_perc}!"
    fi
  done
  sleep 60
done
```

## 20.3 리소스 사용량 확인

### 컨테이너별 리소스 현황

```bash
# 현재 모든 컨테이너 리소스 스냅샷
docker stats --no-stream --format \
  "table {{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}\t{{.NetIO}}\t{{.BlockIO}}"
```

### 시스템 전체 리소스

```bash
# Docker 전체 디스크 사용량
docker system df

# TYPE            TOTAL     ACTIVE    SIZE      RECLAIMABLE
# Images          20        8         5.2GB     2.1GB (40%)
# Containers      5         3         10MB      1MB (10%)
# Local Volumes   3         2         2.5GB     0B (0%)
# Build Cache     50        0         1.2GB     1.2GB

# 상세 정보
docker system df -v
```

### 컨테이너 상세 리소스 (inspect)

```bash
# 메모리 제한 확인
docker inspect --format '{{.HostConfig.Memory}}' my-app
# 536870912  (512MB in bytes)

# CPU 제한 확인
docker inspect --format '{{.HostConfig.NanoCpus}}' my-app
# 500000000  (0.5 CPU in nanocpus)
```

## 20.4 cAdvisor 소개

cAdvisor(Container Advisor)는 Google이 만든 **컨테이너 리소스 사용량 및 성능 모니터링** 도구입니다.

### cAdvisor 실행

```bash
docker run -d \
  --name cadvisor \
  --restart unless-stopped \
  -p 8080:8080 \
  -v /:/rootfs:ro \
  -v /var/run:/var/run:ro \
  -v /sys:/sys:ro \
  -v /var/lib/docker:/var/lib/docker:ro \
  -v /dev/disk/:/dev/disk:ro \
  --privileged \
  --device=/dev/kmsg \
  gcr.io/cadvisor/cadvisor:v0.47.0
```

**웹 UI**: http://localhost:8080
- 실시간 컨테이너별 CPU, 메모리, 네트워크, 디스크 그래프
- 컨테이너 목록 및 상세 정보

## 20.5 Prometheus + Grafana 연동

### 전체 모니터링 스택

```yaml
# monitoring/docker-compose.yml
services:
  cadvisor:
    image: gcr.io/cadvisor/cadvisor:v0.47.0
    privileged: true
    volumes:
      - /:/rootfs:ro
      - /var/run:/var/run:ro
      - /sys:/sys:ro
      - /var/lib/docker:/var/lib/docker:ro
    ports:
      - "8080:8080"
    restart: unless-stopped

  prometheus:
    image: prom/prometheus:v2.47.0
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml:ro
      - prometheus-data:/prometheus
    command:
      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.retention.time=15d'
    restart: unless-stopped

  grafana:
    image: grafana/grafana:10.1.0
    ports:
      - "3000:3000"
    environment:
      GF_SECURITY_ADMIN_PASSWORD: admin
      GF_USERS_ALLOW_SIGN_UP: "false"
    volumes:
      - grafana-data:/var/lib/grafana
      - ./grafana/provisioning:/etc/grafana/provisioning
    restart: unless-stopped

volumes:
  prometheus-data:
  grafana-data:
```

### Prometheus 설정

```yaml
# prometheus/prometheus.yml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'cadvisor'
    static_configs:
      - targets: ['cadvisor:8080']

  - job_name: 'node-exporter'
    static_configs:
      - targets: ['node-exporter:9100']
```

### 주요 Prometheus 쿼리 (PromQL)

```promql
# 컨테이너 CPU 사용률
rate(container_cpu_usage_seconds_total{name!=""}[5m]) * 100

# 컨테이너 메모리 사용량
container_memory_usage_bytes{name!=""}

# 컨테이너 메모리 사용률
container_memory_usage_bytes{name!=""} / container_spec_memory_limit_bytes{name!=""} * 100

# 네트워크 수신량
rate(container_network_receive_bytes_total{name!=""}[5m])
```

## 20.6 Docker Desktop 모니터링

Docker Desktop에서 기본 제공하는 모니터링:

1. **Containers 탭**: 실행 중인 컨테이너 상태
2. **CPU/Memory 그래프**: 실시간 리소스 사용량
3. **Port 포워딩**: 활성화된 포트 확인
4. **Logs 탭**: 컨테이너 로그

## 20.7 알림 설정 패턴

### Prometheus Alertmanager 알림

```yaml
# prometheus/alert-rules.yml
groups:
  - name: container-alerts
    rules:
      - alert: 컨테이너높은메모리사용량
        expr: container_memory_usage_bytes / container_spec_memory_limit_bytes > 0.8
        for: 2m
        labels:
          severity: warning
        annotations:
          summary: "컨테이너 메모리 사용량 높음 ({{ $labels.name }})"
          description: "메모리 사용량: {{ $value | humanizePercentage }}"

      - alert: 컨테이너중지됨
        expr: absent(container_last_seen{name!=""})
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "컨테이너가 중지됨"
```

### 간단한 Slack 알림 스크립트

```bash
#!/bin/bash
# check-containers.sh

WEBHOOK_URL="https://hooks.slack.com/services/YOUR/WEBHOOK/URL"

# 중지된 컨테이너 확인
STOPPED=$(docker ps -a --filter "status=exited" --format "{{.Names}}" | head -5)

if [ -n "$STOPPED" ]; then
  MESSAGE="중지된 컨테이너 발견:\n$STOPPED"
  curl -X POST -H 'Content-type: application/json' \
    --data "{\"text\":\"$MESSAGE\"}" \
    $WEBHOOK_URL
fi
```

## 20.8 모니터링 모범 사례

### 수집해야 할 핵심 메트릭

| 메트릭 | 임계값 | 설명 |
|--------|--------|------|
| CPU 사용률 | > 80% | 성능 병목 가능 |
| 메모리 사용률 | > 85% | OOM Kill 위험 |
| 메모리 RSS | 급격한 증가 | 메모리 누수 의심 |
| 재시작 횟수 | > 5회 | 크래시 루프 의심 |
| 응답 시간 | > 임계값 | 서비스 품질 저하 |

### Compose에 모니터링 통합

```yaml
services:
  app:
    image: myapp
    # ... 앱 설정 ...

  # 사이드카 패턴으로 메트릭 수집
  app-metrics:
    image: prom/node-exporter
    volumes:
      - /proc:/host/proc:ro
      - /sys:/host/sys:ro
    command:
      - '--path.procfs=/host/proc'
      - '--path.sysfs=/host/sys'
```
