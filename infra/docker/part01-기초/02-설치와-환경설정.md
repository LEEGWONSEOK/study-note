## 2.2 macOS 설치 (Docker Desktop)

### Docker Desktop 다운로드 및 설치

**방법 1: 공식 사이트에서 다운로드**

1. [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/) 접속
2. Mac with Apple chip / Mac with Intel chip 중 선택하여 다운로드
3. 다운로드된 `.dmg` 파일 실행
4. Docker 아이콘을 Applications 폴더로 드래그

**방법 2: Homebrew (권장)**

```bash
# Homebrew가 없다면 먼저 설치
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Docker Desktop 설치
brew install --cask docker

# 설치 확인
docker --version
docker compose version
```

### Docker Desktop 실행

1. Spotlight (`Cmd+Space`) → "Docker" 검색
2. 상단 메뉴바에 Docker 고래 아이콘이 나타남
3. 아이콘이 정지되면 Docker 준비 완료

```bash
# 설치 확인
docker --version
# Docker version 24.0.6, build ed223bc

docker info
# 상세 정보 출력
```

## 2.3 Linux 설치 (Ubuntu)

### Ubuntu 20.04 / 22.04

```bash
# 1. 기존 버전 제거 (있을 경우)
sudo apt-get remove docker docker-engine docker.io containerd runc

# 2. 필수 패키지 설치
sudo apt-get update
sudo apt-get install -y \
    ca-certificates \
    curl \
    gnupg \
    lsb-release

# 3. Docker 공식 GPG 키 추가
sudo mkdir -m 0755 -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
    sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 4. Docker 저장소 등록
echo \
  "deb [arch="$(dpkg --print-architecture)" signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  "$(. /etc/os-release && echo "$VERSION_CODENAME")" stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 5. Docker 설치
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 6. Docker 서비스 시작
sudo systemctl start docker
sudo systemctl enable docker  # 부팅 시 자동 시작

# 7. sudo 없이 docker 실행하기 위한 설정
sudo usermod -aG docker $USER
newgrp docker

# 8. 설치 확인
docker --version
docker run hello-world
```

### CentOS 7/8 / RHEL

```bash
# 1. 기존 버전 제거
sudo yum remove docker \
    docker-client \
    docker-client-latest \
    docker-common \
    docker-latest \
    docker-latest-logrotate \
    docker-logrotate \
    docker-engine

# 2. yum-utils 설치
sudo yum install -y yum-utils

# 3. Docker 저장소 추가
sudo yum-config-manager \
    --add-repo \
    https://download.docker.com/linux/centos/docker-ce.repo

# 4. Docker 설치
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 5. Docker 시작 및 활성화
sudo systemctl start docker
sudo systemctl enable docker

# 6. sudo 없이 실행
sudo usermod -aG docker $USER

# 7. 확인
docker --version
```

## 2.4 Windows 설치 (Docker Desktop + WSL2)

### WSL2 설치 (Docker Desktop 설치 전)

```powershell
# PowerShell을 관리자 권한으로 실행

# 1. WSL 기능 활성화
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

# 2. 가상 머신 기능 활성화
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 3. 재시작 후 WSL2를 기본으로 설정
wsl --set-default-version 2

# 4. Ubuntu 설치 (Microsoft Store에서 또는)
wsl --install -d Ubuntu
```

### Docker Desktop 설치

1. [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/) 에서 Windows 버전 다운로드
2. 설치 시 "Use WSL 2 instead of Hyper-V" 체크
3. 재시작 후 Docker Desktop 실행
4. Settings → Resources → WSL Integration에서 Ubuntu 활성화

```bash
# WSL Ubuntu 터미널에서 확인
docker --version
docker run hello-world
```

## 2.6 Docker Desktop 설정

### 리소스 설정 (macOS / Windows)

Docker Desktop → Settings → Resources

```
CPUs: 4 (전체의 절반 권장)
Memory: 8 GB (최소 4GB)
Swap: 1 GB
Disk image size: 60 GB
```

**설정 팁**:
- Java 앱은 메모리를 많이 사용하므로 최소 4GB 이상
- Spring Boot + MySQL + Redis 개발 시 8GB 권장

| 탭 | 설명 |

| Volumes | 볼륨 관리 |

| Extensions | 플러그인 설치 |

## 2.7 .docker 디렉토리 구조

Docker 설정과 데이터는 `~/.docker` 디렉토리에 저장됩니다:

```bash
ls -la ~/.docker/
```

```
~/.docker/
├── config.json          # Docker 클라이언트 설정 (인증, 설정 등)
├── contexts/            # Docker 컨텍스트 (여러 Docker 호스트 관리)
│   └── meta/
├── buildx/              # Docker BuildX 플러그인 데이터
└── desktop-build/       # Docker Desktop 빌드 정보
```

### config.json 구조

```json
{
  "auths": {
    "https://index.docker.io/v1/": {
      "auth": "base64_encoded_credentials"
    }
  },
  "credsStore": "desktop",
  "currentContext": "desktop-linux",
  "plugins": {
    "scout": {
      "organization": "myorg"
    }
  }
}
```

## 2.8 환경 변수 설정

### DOCKER_HOST

원격 Docker Daemon에 연결할 때 사용:

```bash
# 원격 Docker에 연결
export DOCKER_HOST=tcp://remote-server:2376

# 기본값으로 복원
unset DOCKER_HOST
```

### DOCKER_BUILDKIT

BuildKit 활성화 (빌드 성능 향상):

```bash
# BuildKit 활성화 (Docker 23.0부터 기본 활성화)
export DOCKER_BUILDKIT=1

# .bashrc 또는 .zshrc에 추가
echo 'export DOCKER_BUILDKIT=1' >> ~/.zshrc
```

### COMPOSE_FILE

여러 Compose 파일 지정:

```bash
export COMPOSE_FILE=docker-compose.yml:docker-compose.override.yml
```

### 자주 쓰는 환경변수 정리

| 변수 | 설명 | 기본값 |
|------|------|--------|
| `DOCKER_HOST` | Docker Daemon 소켓 경로 | `unix:///var/run/docker.sock` |
| `DOCKER_BUILDKIT` | BuildKit 활성화 | `1` (24.0+) |
| `COMPOSE_PROJECT_NAME` | Compose 프로젝트 이름 | 디렉토리명 |
| `COMPOSE_FILE` | Compose 파일 경로 | `docker-compose.yml` |
| `DOCKER_DEFAULT_PLATFORM` | 기본 빌드 플랫폼 | 호스트 플랫폼 |

### Apple Silicon (M1/M2/M3) 플랫폼 설정

```bash
# x86 이미지 빌드 시 (Intel 서버 배포용)
export DOCKER_DEFAULT_PLATFORM=linux/amd64

# ARM 이미지 빌드 시
export DOCKER_DEFAULT_PLATFORM=linux/arm64

# 빌드 시 직접 지정
docker build --platform linux/amd64 -t myapp .
```

## 2.9 Shell 자동완성 설정

### zsh 자동완성

```bash
# oh-my-zsh 사용 시 .zshrc에 플러그인 추가
plugins=(git docker docker-compose)

# 수동 설정
mkdir -p ~/.zsh/completion
docker completion zsh > ~/.zsh/completion/_docker
echo 'fpath=(~/.zsh/completion $fpath)' >> ~/.zshrc
echo 'autoload -Uz compinit && compinit' >> ~/.zshrc
source ~/.zshrc
```

### bash 자동완성

```bash
# 자동완성 스크립트 생성
docker completion bash > /etc/bash_completion.d/docker
source ~/.bashrc
```
