# Chapter 3. 기본 명령어

## 3.1 Docker 명령어 구조

```
docker [옵션] 커맨드 [인수...]
```

```
docker
├── container   # 컨테이너 관련
│   ├── run     # 컨테이너 생성 및 실행
│   ├── start   # 컨테이너 시작
│   ├── stop    # 컨테이너 중지
│   ├── rm      # 컨테이너 삭제
│   └── ls      # 컨테이너 목록
├── image       # 이미지 관련
│   ├── pull    # 이미지 다운로드
│   ├── push    # 이미지 업로드
│   ├── build   # 이미지 빌드
│   ├── rm      # 이미지 삭제
│   └── ls      # 이미지 목록
├── network     # 네트워크 관련
├── volume      # 볼륨 관련
└── system      # 시스템 관련
```

> **팁**: Docker 명령어는 단축 형태도 지원합니다.
> `docker container run` = `docker run`
> `docker image ls` = `docker images`

## 3.2 컨테이너 명령어

### docker run - 컨테이너 생성 및 실행

가장 중요한 명령어입니다. 이미지로 컨테이너를 생성하고 실행합니다.

```bash
docker run [옵션] 이미지명[:태그] [명령어] [인수]
```

**기본 예시**:
```bash
# nginx 웹서버 실행
docker run nginx

# 이름을 지정하여 실행
docker run --name my-nginx nginx

# 백그라운드 실행 (-d: detached mode)
docker run -d nginx

# 포트 매핑 (-p 호스트포트:컨테이너포트)
docker run -d -p 8080:80 nginx

# 환경변수 설정
docker run -e MYSQL_ROOT_PASSWORD=password mysql:8.0

# 볼륨 마운트
docker run -v /host/path:/container/path nginx

# 실행 후 자동 삭제 (--rm)
docker run --rm nginx

# 대화형 실행 (-it)
docker run -it ubuntu bash
```

### docker ps - 컨테이너 목록

```bash
# 실행 중인 컨테이너만 표시
docker ps

# 모든 컨테이너 표시 (중지된 것 포함)
docker ps -a

# 컨테이너 ID만 표시
docker ps -q

# 마지막으로 실행된 컨테이너
docker ps -l
```

**출력 형식**:
```
CONTAINER ID   IMAGE     COMMAND                  CREATED       STATUS       PORTS                  NAMES
a1b2c3d4e5f6   nginx     "/docker-entrypoint.…"   2 hours ago   Up 2 hours   0.0.0.0:8080->80/tcp   my-nginx
```

### docker start / stop / restart

```bash
# 컨테이너 시작 (중지된 컨테이너)
docker start 컨테이너명|ID

# 컨테이너 중지 (SIGTERM 후 SIGKILL)
docker stop 컨테이너명|ID

# 중지 대기 시간 지정 (기본 10초)
docker stop -t 30 컨테이너명

# 강제 중지 (SIGKILL 즉시)
docker kill 컨테이너명|ID

# 재시작
docker restart 컨테이너명|ID

# 일시 중지 / 재개
docker pause 컨테이너명|ID
docker unpause 컨테이너명|ID
```

### docker rm - 컨테이너 삭제

```bash
# 컨테이너 삭제 (중지된 것만 가능)
docker rm 컨테이너명|ID

# 실행 중인 컨테이너 강제 삭제
docker rm -f 컨테이너명|ID

# 여러 컨테이너 한번에 삭제
docker rm 컨테이너1 컨테이너2 컨테이너3

# 중지된 모든 컨테이너 삭제
docker rm $(docker ps -aq)

# 또는
docker container prune
```

## 3.3 이미지 명령어

### docker pull - 이미지 다운로드

```bash
# 최신 버전 다운로드 (latest 태그)
docker pull nginx

# 특정 버전 지정
docker pull nginx:1.25

# 특정 플랫폼 지정
docker pull --platform linux/amd64 nginx

# 레지스트리 지정
docker pull registry.company.com/myapp:1.0
```

### docker images - 이미지 목록

```bash
# 이미지 목록 확인
docker images
# 또는
docker image ls

# 특정 이미지 검색
docker images nginx

# 이미지 ID만 표시
docker images -q

# dangling 이미지 (태그 없는) 표시
docker images -f dangling=true
```

**출력 형식**:
```
REPOSITORY   TAG       IMAGE ID       CREATED       SIZE
nginx        latest    a6bd71f48f68   2 weeks ago   187MB
mysql        8.0       05db07cd74c0   3 weeks ago   578MB
ubuntu       22.04     08d22c0ceb15   4 weeks ago   77.8MB
```

### docker rmi - 이미지 삭제

```bash
# 이미지 삭제
docker rmi nginx

# 특정 버전 삭제
docker rmi nginx:1.25

# 이미지 ID로 삭제
docker rmi a6bd71f48f68

# 강제 삭제 (컨테이너가 참조 중이어도)
docker rmi -f nginx

# 사용하지 않는 모든 이미지 삭제
docker image prune -a
```

### docker tag - 이미지 태그

```bash
# 이미지에 태그 추가
docker tag nginx:latest myregistry/nginx:1.0

# 현재 이미지에 여러 태그 추가
docker tag myapp:latest myapp:v1.0.0
docker tag myapp:latest myapp:stable
```

### docker push - 이미지 업로드

```bash
# Docker Hub에 업로드
docker push username/myapp:1.0

# Private Registry에 업로드
docker push registry.company.com/myapp:1.0
```

### docker search - 이미지 검색

```bash
# Docker Hub에서 이미지 검색
docker search nginx

# 공식 이미지만 검색
docker search --filter is-official=true nginx

# 별점 100 이상
docker search --filter stars=100 node
```

## 3.4 실행 옵션 상세

### -d (detached mode)

```bash
# 백그라운드 실행 (터미널 점유 없음)
docker run -d nginx

# 포그라운드 실행 (터미널 점유)
docker run nginx  # Ctrl+C로 중지됨
```

### -it (interactive + tty)

```bash
# 대화형 터미널 접속
docker run -it ubuntu bash

# 특정 쉘로 접속
docker run -it alpine sh
docker run -it python:3.11 python
```

**-i**: 표준 입력(stdin) 열어두기
**-t**: TTY(가상 터미널) 할당

### -p (포트 바인딩)

```bash
# 호스트포트:컨테이너포트
docker run -p 8080:80 nginx

# 여러 포트 매핑
docker run -p 8080:80 -p 443:443 nginx

# 특정 IP 바인딩 (보안)
docker run -p 127.0.0.1:8080:80 nginx

# 랜덤 포트 할당
docker run -P nginx
docker port 컨테이너명  # 할당된 포트 확인
```

### -v (볼륨 마운트)

```bash
# 호스트 디렉토리 마운트
docker run -v /host/path:/container/path nginx

# 현재 디렉토리 마운트
docker run -v $(pwd):/app node:18

# Named Volume 사용
docker run -v myvolume:/data mysql:8.0

# 읽기 전용 마운트
docker run -v /host/config:/app/config:ro nginx
```

### --name (컨테이너 이름)

```bash
# 이름 지정
docker run --name my-nginx nginx

# 이름으로 관리
docker stop my-nginx
docker start my-nginx
docker rm my-nginx
```

### -e (환경변수)

```bash
# 환경변수 하나
docker run -e MYSQL_ROOT_PASSWORD=secret mysql:8.0

# 여러 환경변수
docker run \
  -e MYSQL_ROOT_PASSWORD=secret \
  -e MYSQL_DATABASE=mydb \
  -e MYSQL_USER=user \
  -e MYSQL_PASSWORD=userpassword \
  mysql:8.0

# .env 파일에서 읽기
docker run --env-file .env mysql:8.0
```

### --rm (실행 후 자동 삭제)

```bash
# 컨테이너 종료 시 자동 삭제
docker run --rm ubuntu echo "Hello, World!"

# 테스트나 일회성 작업에 유용
docker run --rm -v $(pwd):/app node:18 npm test
```

## 3.5 docker logs - 로그 보기

```bash
# 컨테이너 로그 출력
docker logs 컨테이너명|ID

# 실시간 로그 추적 (-f: follow)
docker logs -f 컨테이너명

# 마지막 N줄만 출력
docker logs --tail 100 컨테이너명

# 타임스탬프 포함
docker logs -t 컨테이너명

# 특정 시간 이후 로그
docker logs --since 2024-01-01T00:00:00 컨테이너명
docker logs --since 1h 컨테이너명  # 1시간 전부터

# 실시간 + 마지막 50줄
docker logs -f --tail 50 컨테이너명
```

## 3.6 docker exec - 컨테이너 접속

```bash
# 실행 중인 컨테이너에 명령어 실행
docker exec 컨테이너명 ls /app

# 대화형 bash 접속
docker exec -it 컨테이너명 bash

# bash가 없을 때 sh 사용 (Alpine 등)
docker exec -it 컨테이너명 sh

# 특정 사용자로 실행
docker exec -it -u root 컨테이너명 bash

# 환경변수 설정하여 실행
docker exec -it -e DEBUG=true 컨테이너명 bash
```

**주의**: `docker exec`는 실행 중인 컨테이너에만 사용 가능합니다.

## 3.7 docker inspect - 컨테이너 상세 정보

```bash
# 컨테이너 상세 정보 (JSON 형식)
docker inspect 컨테이너명|ID

# 특정 필드만 출력 (Go 템플릿)
docker inspect --format '{{.State.Status}}' 컨테이너명
docker inspect --format '{{.NetworkSettings.IPAddress}}' 컨테이너명
docker inspect --format '{{json .Mounts}}' 컨테이너명

# 이미지 정보 확인
docker inspect 이미지명|ID
```

**유용한 inspect 명령어**:
```bash
# 컨테이너 IP 주소 확인
docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' 컨테이너명

# 환경변수 확인
docker inspect -f '{{range .Config.Env}}{{println .}}{{end}}' 컨테이너명

# 포트 매핑 확인
docker inspect -f '{{json .NetworkSettings.Ports}}' 컨테이너명
```

## 3.8 시스템 관련 명령어

### docker system prune - 시스템 정리

```bash
# 사용하지 않는 리소스 정리
docker system prune

# 볼륨까지 포함하여 정리 (주의!)
docker system prune --volumes

# 모든 이미지까지 삭제
docker system prune -a

# 확인 없이 바로 삭제
docker system prune -f
```

### 리소스 사용량 확인

```bash
# 디스크 사용량 확인
docker system df

# 상세 정보
docker system df -v
```

```
TYPE            TOTAL     ACTIVE    SIZE      RECLAIMABLE
Images          15        8         5.234GB   2.18GB (41%)
Containers      8         3         128.3MB   50.2MB (39%)
Local Volumes   5         3         2.456GB   1.2GB (48%)
Build Cache     0         0         0B        0B
```

### docker stats - 실시간 리소스 모니터링

```bash
# 실행 중인 모든 컨테이너 모니터링
docker stats

# 특정 컨테이너 모니터링
docker stats 컨테이너명

# 한 번만 출력 (스트리밍 없이)
docker stats --no-stream
```

## 3.9 실습: nginx, redis, mysql 컨테이너 실행

### nginx 실행

```bash
# nginx 웹서버 실행
docker run -d \
  --name my-nginx \
  -p 8080:80 \
  nginx:latest

# 접속 확인
curl http://localhost:8080
# 또는 브라우저에서 http://localhost:8080

# 로그 확인
docker logs my-nginx

# 컨테이너 내부 접속
docker exec -it my-nginx bash

# 정리
docker stop my-nginx
docker rm my-nginx
```

### redis 실행

```bash
# Redis 실행
docker run -d \
  --name my-redis \
  -p 6379:6379 \
  redis:7-alpine

# Redis CLI 접속
docker exec -it my-redis redis-cli

# Redis 명령어 실행
# SET key "value"
# GET key
# exit

# 비밀번호 설정하여 실행
docker run -d \
  --name my-redis \
  -p 6379:6379 \
  redis:7-alpine redis-server --requirepass "mypassword"

# 정리
docker stop my-redis && docker rm my-redis
```

### mysql 실행

```bash
# MySQL 실행
docker run -d \
  --name my-mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=rootpassword \
  -e MYSQL_DATABASE=mydb \
  -e MYSQL_USER=user \
  -e MYSQL_PASSWORD=userpassword \
  -v mysql-data:/var/lib/mysql \
  mysql:8.0

# MySQL 접속
docker exec -it my-mysql mysql -u root -p
# 비밀번호 입력: rootpassword

# SQL 실행
# SHOW DATABASES;
# USE mydb;
# CREATE TABLE test (id INT, name VARCHAR(50));
# exit

# 정리
docker stop my-mysql && docker rm my-mysql
docker volume rm mysql-data
```

### 세 가지 동시 실행 확인

```bash
# 모두 실행 중인지 확인
docker ps

# 출력 예시
# CONTAINER ID   IMAGE           COMMAND                  PORTS                   NAMES
# abc123         nginx:latest    "/docker-entrypoint…"    0.0.0.0:8080->80/tcp    my-nginx
# def456         redis:7-alpine  "docker-entrypoint.s…"   0.0.0.0:6379->6379/tcp  my-redis
# ghi789         mysql:8.0       "docker-entrypoint.s…"   0.0.0.0:3306->3306/tcp  my-mysql

# 리소스 사용량 확인
docker stats --no-stream
```

## 핵심 요약

| 명령어 | 설명 |
|--------|------|
| `docker run` | 컨테이너 생성 + 실행 |
| `docker ps` | 실행 중 컨테이너 목록 |
| `docker stop/start` | 컨테이너 중지/시작 |
| `docker rm` | 컨테이너 삭제 |
| `docker images` | 이미지 목록 |
| `docker pull` | 이미지 다운로드 |
| `docker rmi` | 이미지 삭제 |
| `docker logs` | 로그 확인 |
| `docker exec -it` | 컨테이너 접속 |
| `docker inspect` | 상세 정보 확인 |
| `docker system prune` | 리소스 정리 |

**주요 옵션**:
- `-d`: 백그라운드 실행
- `-it`: 대화형 터미널
- `-p 호스트:컨테이너`: 포트 매핑
- `-v 호스트:컨테이너`: 볼륨 마운트
- `--name`: 컨테이너 이름
- `-e KEY=VALUE`: 환경변수
