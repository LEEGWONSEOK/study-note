# Chapter 3. 제어문

## 3.1 조건문 (if/else)

> 🚦 **비유**: if문은 **신호등**입니다.
> - 조건이 참(초록불): 코드 실행
> - 조건이 거짓(빨간불): 건너뜀

### 기본 if문

```javascript
const age = 20;

if (age >= 18) {
  console.log("성인입니다");
}
```

**Java와 비교**:
```java
// Java
int age = 20;
if (age >= 18) {
    System.out.println("성인입니다");
}

// JavaScript - 동일
const age = 20;
if (age >= 18) {
  console.log("성인입니다");
}
```

---

### if-else

```javascript
const score = 75;

if (score >= 80) {
  console.log("합격");
} else {
  console.log("불합격");
}
```

---

### if-else if-else

```javascript
const score = 85;

if (score >= 90) {
  console.log("A 등급");
} else if (score >= 80) {
  console.log("B 등급");
} else if (score >= 70) {
  console.log("C 등급");
} else {
  console.log("불합격");
}
```

---

### 중첩 if문

```javascript
const age = 25;
const hasLicense = true;

if (age >= 18) {
  if (hasLicense) {
    console.log("운전 가능");
  } else {
    console.log("면허 필요");
  }
} else {
  console.log("나이 미달");
}

// 더 나은 방법: 논리 연산자
if (age >= 18 && hasLicense) {
  console.log("운전 가능");
}
```

---

### 삼항 연산자 (Ternary Operator)

짧은 if-else는 삼항 연산자로!

```javascript
// 기존 방식
let message;
if (isLoggedIn) {
  message = "Welcome";
} else {
  message = "Login Please";
}

// 삼항 연산자 (권장)
const message = isLoggedIn ? "Welcome" : "Login Please";

// 중첩 삼항 (비권장)
const grade = score >= 90 ? "A" : score >= 80 ? "B" : "C";

// 실용 예제
const price = isMember ? 9000 : 10000;
const discount = quantity >= 10 ? 0.2 : 0.1;
```

## 3.2 switch문

> 🎰 **비유**: switch는 **자판기 버튼**입니다.
> - 버튼마다 다른 동작 수행

### 기본 switch

```javascript
const day = "월요일";

switch (day) {
  case "월요일":
    console.log("주 시작!");
    break;
  case "금요일":
    console.log("불금!");
    break;
  case "토요일":
  case "일요일":
    console.log("주말!");
    break;
  default:
    console.log("평일입니다");
}
```

**주의**: `break` 없으면 다음 case도 실행! (fall-through)

```javascript
const score = "B";

switch (score) {
  case "A":
    console.log("훌륭합니다");
    break;
  case "B":
    console.log("좋습니다");
    // break 없음!
  case "C":
    console.log("보통입니다");  // 이것도 실행됨!
    break;
  default:
    console.log("노력하세요");
}

// 출력:
// 좋습니다
// 보통입니다
```

---

### switch vs if-else

```javascript
// if-else (범위 비교에 적합)
if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
}

// switch (정확한 값 비교에 적합)
switch (color) {
  case "red":
    console.log("빨강");
    break;
  case "blue":
    console.log("파랑");
    break;
}
```

**권장 사용 시기**:
- **if-else**: 범위, 복잡한 조건
- **switch**: 정확한 값, 많은 경우의 수

---

### 모던 대안: 객체 매핑

```javascript
// ❌ switch 남발
function getAnimalSound(animal) {
  switch (animal) {
    case "dog": return "멍멍";
    case "cat": return "야옹";
    case "cow": return "음메";
    default: return "???";
  }
}

// ✅ 객체 사용 (더 깔끔)
const animalSounds = {
  dog: "멍멍",
  cat: "야옹",
  cow: "음메"
};

function getAnimalSound(animal) {
  return animalSounds[animal] ?? "???";
}
```

## 3.3 for 루프

> 🔄 **비유**: for문은 **회전목마**입니다.
> - 정해진 횟수만큼 반복

### 기본 for문

```javascript
// 0부터 4까지 출력
for (let i = 0; i < 5; i++) {
  console.log(i);
}
// 출력: 0 1 2 3 4

// 1부터 10까지의 합
let sum = 0;
for (let i = 1; i <= 10; i++) {
  sum += i;
}
console.log(sum);  // 55
```

---

### 배열 순회

```javascript
const fruits = ["사과", "바나나", "딸기"];

// 전통적 방법
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// for-of (ES6, 권장!) ✅
for (const fruit of fruits) {
  console.log(fruit);
}

// forEach (함수형)
fruits.forEach(fruit => {
  console.log(fruit);
});
```

---

### for-in (객체 순회)

```javascript
const person = {
  name: "홍길동",
  age: 25,
  job: "개발자"
};

// 키(key) 순회
for (const key in person) {
  console.log(key, person[key]);
}
// 출력:
// name 홍길동
// age 25
// job 개발자

// 모던 방법
Object.keys(person).forEach(key => {
  console.log(key, person[key]);
});

// 또는
Object.entries(person).forEach(([key, value]) => {
  console.log(key, value);
});
```

---

### 역순 루프

```javascript
const arr = [1, 2, 3, 4, 5];

// 역순 출력
for (let i = arr.length - 1; i >= 0; i--) {
  console.log(arr[i]);
}
// 출력: 5 4 3 2 1

// 또는 배열 메서드 사용
[...arr].reverse().forEach(item => console.log(item));
```

## 3.4 while 루프

> ⏰ **비유**: while은 **알람 시계**입니다.
> - 조건이 참인 동안 계속 반복

### 기본 while

```javascript
let count = 0;

while (count < 5) {
  console.log(count);
  count++;
}
// 출력: 0 1 2 3 4
```

---

### 무한 루프 주의! ⚠️

```javascript
// ❌ 무한 루프 (count가 증가하지 않음)
let count = 0;
while (count < 5) {
  console.log(count);
  // count++; 빠짐!
}

// ✅ 의도적 무한 루프 + break
while (true) {
  const input = prompt("종료하려면 'q' 입력:");
  if (input === 'q') break;
  console.log("계속 실행 중...");
}
```

---

### do-while

최소 1번은 실행 보장

```javascript
let password;

do {
  password = prompt("비밀번호 입력:");
} while (password !== "1234");

console.log("로그인 성공!");
```

**while vs do-while**:
```javascript
// while: 조건 먼저 체크
let i = 10;
while (i < 5) {
  console.log("실행 안 됨");
}

// do-while: 일단 실행, 나중에 체크
let j = 10;
do {
  console.log("최소 1번 실행");
} while (j < 5);
```

## 3.5 break와 continue

### break - 즉시 종료

```javascript
// 숫자 5를 찾으면 종료
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    console.log("5를 찾았습니다!");
    break;  // 루프 종료
  }
  console.log(i);
}
// 출력: 1 2 3 4 5를 찾았습니다!

// 실용 예제: 검색
const users = ["Alice", "Bob", "Charlie", "David"];
let found = null;

for (const user of users) {
  if (user === "Charlie") {
    found = user;
    break;  // 찾았으니 더 이상 검색 안 함
  }
}
```

---

### continue - 현재 반복만 건너뜀

```javascript
// 홀수만 출력 (짝수는 건너뜀)
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {
    continue;  // 짝수면 건너뜀
  }
  console.log(i);
}
// 출력: 1 3 5 7 9

// 실용 예제: 유효한 값만 처리
const numbers = [1, null, 3, undefined, 5, 0];

for (const num of numbers) {
  if (num == null || num === 0) {
    continue;  // 유효하지 않은 값 건너뜀
  }
  console.log(num * 2);
}
// 출력: 2 6 10
```

---

### label (거의 안 씀)

중첩 루프에서 외부 루프 제어

```javascript
// ❌ label 없이 (내부 루프만 종료)
for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) {
      break;  // 내부 루프만 종료
    }
    console.log(i, j);
  }
}

// ✅ label 사용 (외부 루프 종료)
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) {
      break outer;  // 외부 루프 종료
    }
    console.log(i, j);
  }
}
```

> 💡 **권장**: label은 가독성이 떨어지니 함수로 분리하세요!

```javascript
// 더 나은 방법: 함수 사용
function findTarget() {
  for (let i = 0; i < 3; i++) {
    for (let j = 0; j < 3; j++) {
      if (i === 1 && j === 1) {
        return { i, j };  // 함수 종료
      }
    }
  }
}
```

## 3.6 실전 패턴

### 조기 반환 (Early Return)

```javascript
// ❌ 중첩 if (읽기 어려움)
function processUser(user) {
  if (user) {
    if (user.age >= 18) {
      if (user.isActive) {
        console.log("처리 중...");
      }
    }
  }
}

// ✅ 조기 반환 (가드 절)
function processUser(user) {
  if (!user) return;
  if (user.age < 18) return;
  if (!user.isActive) return;

  console.log("처리 중...");
}
```

---

### 배열 메서드 활용

```javascript
const numbers = [1, 2, 3, 4, 5];

// ❌ 전통적 for문
const doubled = [];
for (let i = 0; i < numbers.length; i++) {
  doubled.push(numbers[i] * 2);
}

// ✅ map 사용
const doubled = numbers.map(n => n * 2);

// ❌ 전통적 for문
const evens = [];
for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] % 2 === 0) {
    evens.push(numbers[i]);
  }
}

// ✅ filter 사용
const evens = numbers.filter(n => n % 2 === 0);
```

## 📝 핵심 요약

1. **조건문**: `if-else`, 삼항 연산자, switch
