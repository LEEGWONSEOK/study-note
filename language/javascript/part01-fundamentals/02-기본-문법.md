# Chapter 2. 기본 문법

## 2.1 변수 선언

> 🎯 **핵심**: JavaScript에는 3가지 변수 선언 방법이 있습니다.
> - `var`: 구식 (사용 금지!)
> - `let`: 재할당 가능
> - `const`: 재할당 불가 (상수)

### const (상수) - 기본 선택

**사용 원칙**: **기본적으로 const 사용!**

```javascript
const name = "홍길동";
const age = 25;
const isStudent = true;

// ❌ 재할당 불가
name = "김철수";  // TypeError: Assignment to constant variable
```

**비유**: **접착제로 붙인 라벨**
- 한 번 붙이면 떼어낼 수 없음

**Java와 비교**:
```java
// Java
final String name = "홍길동";
name = "김철수";  // ❌ 컴파일 에러

// JavaScript
const name = "홍길동";
name = "김철수";  // ❌ 런타임 에러
```

---

### let (변수) - 값이 변할 때

**사용 시점**: 값이 변경될 필요가 있을 때만

```javascript
let score = 0;
score = 10;  // ✅ 가능
score = 20;  // ✅ 가능

let message = "안녕";
message = "잘가";  // ✅ 가능
```

**실생활 예시**:
```javascript
// 게임 점수 (계속 변함)
let score = 0;
score += 10;  // 10
score += 5;   // 15

// 루프 카운터
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

---

### var (구식) - 절대 사용하지 마세요! ⛔

**문제점**:
1. 함수 스코프 (블록 스코프 무시)
2. 호이스팅 이상 동작
3. 재선언 가능 (버그 유발)

```javascript
// ❌ var의 문제점들
if (true) {
  var x = 10;
}
console.log(x);  // 10 (블록 밖에서도 접근 가능!)

var y = 1;
var y = 2;  // ⚠️ 재선언 가능 (실수 유발)
console.log(y);  // 2

// ❌ 호이스팅 문제
console.log(z);  // undefined (에러가 아님!)
var z = 5;
```

> 💡 **규칙**: var는 무시하고 let/const만 사용하세요!

---

### const vs let 선택 기준

```javascript
// ✅ const 사용 (대부분의 경우)
const USER_ROLE = "admin";
const PI = 3.14159;
const config = { port: 3000, host: "localhost" };
const users = [];

// ✅ let 사용 (값이 변경될 때)
let count = 0;
let isLoading = false;
let currentPage = 1;

// ⚠️ const인데 값이 변하는 것처럼 보이는 경우
const arr = [1, 2, 3];
arr.push(4);  // ✅ 가능! (배열 내용 변경은 가능)
arr = [5, 6];  // ❌ 재할당은 불가

const obj = { name: "홍길동" };
obj.age = 25;  // ✅ 가능! (객체 속성 변경은 가능)
obj = {};      // ❌ 재할당은 불가
```

> 📌 **요약**:
> - `const`: 재할당 불가 (참조 불변)
> - 내용 변경은 가능 (배열 요소, 객체 속성)

## 2.2 데이터 타입

> 🔢 **비유**: JavaScript의 타입은 **변신 로봇**입니다.
> - 필요에 따라 자동으로 변신 (타입 변환)

### Primitive 타입 (원시 타입)

불변(immutable) 값

| 타입 | 설명 | 예시 |
|------|------|------|
| `number` | 숫자 (정수, 실수) | `42`, `3.14`, `NaN`, `Infinity` |
| `string` | 문자열 | `"hello"`, `'world'`, `` `템플릿` `` |
| `boolean` | 참/거짓 | `true`, `false` |
| `undefined` | 정의되지 않음 | `undefined` |
| `null` | 빈 값 | `null` |
| `symbol` | 고유 식별자 (ES6) | `Symbol('id')` |
| `bigint` | 큰 정수 (ES2020) | `9007199254740991n` |

```javascript
// number
const age = 25;
const pi = 3.14;
const notANumber = NaN;  // "Not a Number"
const infinity = Infinity;

// string
const name = "홍길동";
const greeting = '안녕하세요';
const template = `이름: ${name}`;  // 템플릿 리터럴

// boolean
const isStudent = true;
const hasJob = false;

// undefined
let x;  // 선언만 하고 할당 안 함
console.log(x);  // undefined

// null
const empty = null;  // 명시적으로 빈 값

// symbol (거의 안 씀)
const id = Symbol('id');

// bigint (매우 큰 숫자)
const bigNumber = 9007199254740991n;
```

---

### Reference 타입 (참조 타입)

가변(mutable) 값

| 타입 | 설명 | 예시 |
|------|------|------|
| `object` | 객체 | `{ name: "홍길동", age: 25 }` |
| `array` | 배열 | `[1, 2, 3]` |
| `function` | 함수 | `function() {}` |
| `Date` | 날짜 | `new Date()` |
| `RegExp` | 정규표현식 | `/\d+/` |

```javascript
// object
const person = {
  name: "홍길동",
  age: 25
};

// array
const numbers = [1, 2, 3, 4, 5];

// function
const greet = function(name) {
  return `안녕, ${name}`;
};

// Date
const now = new Date();

// RegExp
const pattern = /\d+/;
```

### typeof 연산자

타입 확인

```javascript
console.log(typeof 42);         // "number"
console.log(typeof "hello");    // "string"
console.log(typeof true);       // "boolean"
console.log(typeof undefined);  // "undefined"
console.log(typeof null);       // "object" ⚠️ 버그! (역사적 이유)
console.log(typeof Symbol());   // "symbol"
console.log(typeof 10n);        // "bigint"

console.log(typeof {});         // "object"
console.log(typeof []);         // "object" (배열도 객체)
console.log(typeof function(){}); // "function"
```

> ⚠️ **null의 typeof가 "object"인 이유**:
> - JavaScript 초기 설계 버그
> - 하위 호환성 때문에 수정 불가

**올바른 null 체크**:
```javascript
const value = null;

// ❌ 잘못된 방법
if (typeof value === "object") {  // null도 true!
}

// ✅ 올바른 방법
if (value === null) {
}

// ✅ null 또는 undefined 체크
if (value == null) {  // null과 undefined 모두 체크
}
```

## 2.3 타입 변환

### 1. 명시적 변환 (Explicit)

**Number() - 숫자로 변환**:
```javascript
Number("42");      // 42
Number("3.14");    // 3.14
Number("hello");   // NaN
Number(true);      // 1
Number(false);     // 0
Number(null);      // 0
Number(undefined); // NaN

// parseInt, parseFloat
parseInt("42px");      // 42
parseFloat("3.14px");  // 3.14
```

**String() - 문자열로 변환**:
```javascript
String(42);        // "42"
String(true);      // "true"
String(null);      // "null"
String(undefined); // "undefined"

// .toString()
(42).toString();   // "42"
true.toString();   // "true"
```

**Boolean() - 불린으로 변환**:
```javascript
// Falsy 값 (false로 변환)
Boolean(0);         // false
Boolean("");        // false
Boolean(null);      // false
Boolean(undefined); // false
Boolean(NaN);       // false
Boolean(false);     // false

// Truthy 값 (true로 변환)
Boolean(1);         // true
Boolean("hello");   // true
Boolean({});        // true
Boolean([]);        // true
```

---

### 2. 암묵적 변환 (Implicit) - 주의! ⚠️

**문자열 연결 (+)**:
```javascript
"hello" + " world"  // "hello world"
"3" + 4             // "34" (숫자가 문자열로)
3 + "4"             // "34"
"3" + 4 + 5         // "345"
3 + 4 + "5"         // "75" (왼쪽부터 계산)
```

**산술 연산 (-, *, /, %)**:
```javascript
"5" - 2    // 3 (문자열이 숫자로)
"5" * 2    // 10
"10" / 2   // 5
"10" % 3   // 1

"hello" - 2  // NaN (변환 실패)
```

**동등 비교 (==)**:
```javascript
// ⚠️ 타입 변환 후 비교
5 == "5"       // true
0 == false     // true
null == undefined  // true
"" == 0        // true

// ✅ 타입 변환 없이 비교 (권장!)
5 === "5"      // false
0 === false    // false
null === undefined  // false
"" === 0       // false
```

> 💡 **규칙**: 항상 `===` 사용! (`==`는 사용 금지)

## 2.4 연산자

### 산술 연산자

```javascript
let x = 10;
let y = 3;

console.log(x + y);  // 13 (더하기)
console.log(x - y);  // 7  (빼기)
console.log(x * y);  // 30 (곱하기)
console.log(x / y);  // 3.333... (나누기)
console.log(x % y);  // 1  (나머지)
console.log(x ** y); // 1000 (거듭제곱, ES2016)

// 증감 연산자
let count = 0;
count++;  // 1 (후위 증가)
++count;  // 2 (전위 증가)
count--;  // 1 (후위 감소)
--count;  // 0 (전위 감소)
```

**Java와 비교**:
```java
// Java
int x = 10;
int y = 3;
System.out.println(x / y);  // 3 (정수 나눗셈)
System.out.println((double)x / y);  // 3.333...

// JavaScript
let x = 10;
let y = 3;
console.log(x / y);  // 3.333... (자동으로 실수)
console.log(Math.floor(x / y));  // 3 (정수 나눗셈)
```

---

### 비교 연산자

```javascript
// 일치 연산자 (타입도 체크) - 권장! ✅
5 === 5       // true
5 === "5"     // false
0 === false   // false

5 !== 6       // true
5 !== "5"     // true

// 동등 연산자 (타입 변환) - 사용 금지! ❌
5 == "5"      // true (타입 변환됨)
0 == false    // true (타입 변환됨)

// 크기 비교
10 > 5        // true
10 >= 10      // true
5 < 10        // true
5 <= 5        // true
```

---

### 논리 연산자

```javascript
// AND (&&)
true && true    // true
true && false   // false
false && true   // false

// OR (||)
true || false   // true
false || false  // false

// NOT (!)
!true    // false
!false   // true
!!value  // 불린으로 변환

// 단축 평가 (Short-circuit)
const name = userName || "Guest";  // userName이 falsy면 "Guest"
const greeting = isLoggedIn && "Welcome";  // isLoggedIn이 true면 "Welcome"
```

---

### Nullish 병합 연산자 (??) - ES2020

```javascript
// || 의 문제점
const count = 0;
const value1 = count || 10;  // 10 (0은 falsy)

// ??는 null과 undefined만 체크
const value2 = count ?? 10;  // 0

// 실용 예제
const port = config.port ?? 3000;
const name = user.name ?? "Anonymous";
```

---

### 옵셔널 체이닝 (?.) - ES2020

```javascript
// 기존 방식
const userName = user && user.profile && user.profile.name;

// 옵셔널 체이닝
const userName = user?.profile?.name;

// 배열
const first = arr?.[0];

// 메서드
const result = obj?.method?.();

// 실용 예제
function getStreetName(user) {
  return user?.address?.street ?? "Unknown";
}
```

## 2.6 세미콜론 (;)

JavaScript는 세미콜론 **선택사항**!

```javascript
// 세미콜론 있음 (전통적)
const x = 10;
console.log(x);

// 세미콜론 없음 (모던)
const x = 10
console.log(x)
```

**ASI (Automatic Semicolon Insertion)**:
- JavaScript가 자동으로 세미콜론 추가
- 대부분 잘 동작하지만 가끔 문제 발생

**문제가 되는 경우**:
```javascript
// ❌ 잘못된 경우
const value = 10
[1, 2, 3].forEach(x => console.log(x))
// 해석: const value = 10[1, 2, 3].forEach(...)

// ✅ 올바른 해결
const value = 10;
[1, 2, 3].forEach(x => console.log(x));
```

> 💡 **권장**: Prettier 같은 포매터 사용
