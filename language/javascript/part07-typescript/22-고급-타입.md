# Chapter 22. 고급 타입

## 22.1 제네릭 (Generics)

> 🎁 **비유**: 제네릭은 **선물 상자**입니다.
> - 상자는 같지만 내용물은 다양 (숫자, 문자열 등)
> - 타입을 매개변수처럼 전달

**타입을 매개변수화하여 재사용 가능한 컴포넌트 작성**

### 기본 제네릭 함수

```typescript
// 제네릭 없이 (반복 코드)
function identityNumber(value: number): number {
  return value;
}

function identityString(value: string): string {
  return value;
}

// 제네릭 사용 (한 번만 작성)
function identity<T>(value: T): T {
  return value;
}

// 사용
const num = identity<number>(42);        // T = number
const str = identity<string>("hello");   // T = string
const bool = identity<boolean>(true);    // T = boolean

// 타입 추론 (더 간결)
const num2 = identity(42);        // T가 number로 자동 추론
const str2 = identity("hello");   // T가 string으로 자동 추론
```

### Java vs TypeScript 제네릭

**Java**:
```java
// 제네릭 클래스
public class Box<T> {
    private T value;

    public Box(T value) {
        this.value = value;
    }

    public T getValue() {
        return value;
    }
}

// 사용
Box<Integer> intBox = new Box<>(42);
Box<String> strBox = new Box<>("hello");

// 제네릭 메서드
public <T> T identity(T value) {
    return value;
}
```

**TypeScript**:
```typescript
// 제네릭 클래스
class Box<T> {
  constructor(private value: T) {}

  getValue(): T {
    return this.value;
  }
}

// 사용
const intBox = new Box<number>(42);
const strBox = new Box<string>("hello");

// 제네릭 함수
function identity<T>(value: T): T {
  return value;
}
```

> 💡 **유사점**: 문법이 거의 동일
> **차이점**: TypeScript는 타입 추론이 더 강력

### 제네릭 배열

```typescript
// 배열 반환
function getFirstElement<T>(arr: T[]): T | undefined {
  return arr[0];
}

const first = getFirstElement([1, 2, 3]);           // number | undefined
const firstStr = getFirstElement(["a", "b", "c"]); // string | undefined

// 배열 필터링
function filterArray<T>(arr: T[], predicate: (item: T) => boolean): T[] {
  return arr.filter(predicate);
}

const numbers = [1, 2, 3, 4, 5];
const evens = filterArray(numbers, n => n % 2 === 0);  // [2, 4]
```

### 제네릭 제약 (Generic Constraints)

**특정 속성이 있는 타입만 허용**

```typescript
// extends로 제약
interface HasLength {
  length: number;
}

function logLength<T extends HasLength>(value: T): void {
  console.log(`Length: ${value.length}`);
}

logLength("hello");           // ✅ string은 length 속성 있음
logLength([1, 2, 3]);         // ✅ 배열도 length 속성 있음
// logLength(42);             // ❌ number는 length 속성 없음

// 객체 속성 제약
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const person = { name: "Alice", age: 25 };
const name = getProperty(person, "name");  // "Alice" (string)
const age = getProperty(person, "age");    // 25 (number)
// getProperty(person, "email");           // ❌ 'email'은 person의 키가 아님
```

### 제네릭 클래스

```typescript
// Stack 자료구조
class Stack<T> {
  private items: T[] = [];

  push(item: T): void {
    this.items.push(item);
  }

  pop(): T | undefined {
    return this.items.pop();
  }

  peek(): T | undefined {
    return this.items[this.items.length - 1];
  }

  isEmpty(): boolean {
    return this.items.length === 0;
  }

  size(): number {
    return this.items.length;
  }

  toArray(): T[] {
    return [...this.items];
  }
}

// 사용
const numberStack = new Stack<number>();
numberStack.push(1);
numberStack.push(2);
numberStack.push(3);
console.log(numberStack.pop());  // 3

const stringStack = new Stack<string>();
stringStack.push("hello");
stringStack.push("world");
console.log(stringStack.toArray());  // ["hello", "world"]
```

### 여러 개의 제네릭 타입

```typescript
// 2개의 제네릭 타입
function pair<T, U>(first: T, second: U): [T, U] {
  return [first, second];
}

const p1 = pair(1, "one");           // [number, string]
const p2 = pair("hello", true);      // [string, boolean]

// Map 래퍼 클래스
class Dictionary<K, V> {
  private items = new Map<K, V>();

  set(key: K, value: V): void {
    this.items.set(key, value);
  }

  get(key: K): V | undefined {
    return this.items.get(key);
  }

  has(key: K): boolean {
    return this.items.has(key);
  }

  delete(key: K): boolean {
    return this.items.delete(key);
  }

  keys(): K[] {
    return Array.from(this.items.keys());
  }

  values(): V[] {
    return Array.from(this.items.values());
  }
}

// 사용
const dict = new Dictionary<string, number>();
dict.set("age", 25);
dict.set("score", 100);
console.log(dict.get("age"));  // 25
```

## 22.2 유틸리티 타입 (Utility Types)

> 🛠️ **비유**: 유틸리티 타입은 **공구 세트**입니다.
> - 기존 타입을 변형하는 도구
> - 반복 코드 줄이기

**TypeScript 내장 타입 변환 도구**

### Partial<T>

**모든 속성을 선택적으로 변경**

```typescript
interface User {
  id: number;
  name: string;
  email: string;
  age: number;
}

// 모든 속성이 선택적
type PartialUser = Partial<User>;
// {
//   id?: number;
//   name?: string;
//   email?: string;
//   age?: number;
// }

// 사용: 부분 업데이트
function updateUser(user: User, updates: Partial<User>): User {
  return { ...user, ...updates };
}

const user: User = {
  id: 1,
  name: "Alice",
  email: "alice@example.com",
  age: 25
};

const updated = updateUser(user, { age: 26 });  // age만 업데이트
```

## 22.3 조건부 타입 (Conditional Types)

> 🔀 **비유**: 조건부 타입은 **분기점**입니다.
> - 조건에 따라 타입 결정
> - 삼항 연산자와 유사

**조건에 따라 타입 선택**

```typescript
// 기본 문법: T extends U ? X : Y
type IsString<T> = T extends string ? true : false;

type A = IsString<string>;   // true
type B = IsString<number>;   // false

// 실용 예제: 배열 요소 타입 추출
type ElementType<T> = T extends Array<infer U> ? U : T;

type E1 = ElementType<string[]>;     // string
type E2 = ElementType<number[]>;     // number
type E3 = ElementType<string>;       // string (배열이 아님)

// 함수 반환 타입 추출
type ReturnTypeCustom<T> = T extends (...args: any[]) => infer R ? R : never;

type R1 = ReturnTypeCustom<() => string>;           // string
type R2 = ReturnTypeCustom<(x: number) => boolean>; // boolean
```

---

### infer 키워드

**타입을 추론하여 변수처럼 사용**

```typescript
// Promise 내부 타입 추출
type UnwrapPromise<T> = T extends Promise<infer U> ? U : T;

type T1 = UnwrapPromise<Promise<string>>;  // string
type T2 = UnwrapPromise<Promise<number>>;  // number
type T3 = UnwrapPromise<string>;           // string (Promise가 아님)

// 함수의 첫 번째 매개변수 타입 추출
type FirstParameter<T> = T extends (first: infer F, ...args: any[]) => any ? F : never;

type P1 = FirstParameter<(name: string, age: number) => void>;  // string
type P2 = FirstParameter<(id: number) => void>;                 // number
```

## 22.4 Mapped Types

> 🗺️ **비유**: Mapped Types는 **복사기**입니다.
> - 기존 타입을 변형하여 새로운 타입 생성
> - 모든 속성에 같은 규칙 적용

**객체 타입의 각 속성을 변환**

```typescript
// 기본 문법
type Readonly<T> = {
  readonly [P in keyof T]: T[P];
};

type Partial<T> = {
  [P in keyof T]?: T[P];
};

// 커스텀 Mapped Type
type Nullable<T> = {
  [P in keyof T]: T[P] | null;
};

interface User {
  name: string;
  age: number;
}

type NullableUser = Nullable<User>;
// {
//   name: string | null;
//   age: number | null;
// }

// Getters 생성
type Getters<T> = {
  [P in keyof T as `get${Capitalize<string & P>}`]: () => T[P];
};

type UserGetters = Getters<User>;
// {
//   getName: () => string;
//   getAge: () => number;
// }
```

## 22.5 Template Literal Types

**문자열 리터럴 타입 조합**

```typescript
// 기본 사용
type Greeting = "hello" | "hi";
type Name = "world" | "typescript";

type Phrase = `${Greeting} ${Name}`;
// "hello world" | "hello typescript" | "hi world" | "hi typescript"

// 이벤트 핸들러 타입
type EventName = "click" | "focus" | "blur";
type HandlerName = `on${Capitalize<EventName>}`;
// "onClick" | "onFocus" | "onBlur"

// 실용 예제: CSS 속성
type CSSProperty = "color" | "background" | "border";
type CSSValue = string;
type CSSRule = `${CSSProperty}: ${CSSValue}`;

const rule: CSSRule = "color: red";
```

### 예제 1: API 클라이언트

```typescript
// API 응답 타입
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

// API 엔드포인트
interface Endpoints {
  users: User[];
  posts: Post[];
  comments: Comment[];
}

interface User {
  id: number;
  name: string;
  email: string;
}

interface Post {
  id: number;
  title: string;
  content: string;
  userId: number;
}

interface Comment {
  id: number;
  text: string;
  postId: number;
}

// 제네릭 API 클라이언트
class ApiClient {
  private baseUrl: string;

  constructor(baseUrl: string) {
    this.baseUrl = baseUrl;
  }

  async get<K extends keyof Endpoints>(
    endpoint: K
  ): Promise<ApiResponse<Endpoints[K]>> {
    const response = await fetch(`${this.baseUrl}/${endpoint}`);
    const data = await response.json();

    return {
      data,
      status: response.status,
      message: "Success"
    };
  }

  async getById<K extends keyof Endpoints>(
    endpoint: K,
    id: number
  ): Promise<ApiResponse<Endpoints[K][number]>> {
    const response = await fetch(`${this.baseUrl}/${endpoint}/${id}`);
    const data = await response.json();

    return {
      data,
      status: response.status,
      message: "Success"
    };
  }

  async post<K extends keyof Endpoints>(
    endpoint: K,
    body: Omit<Endpoints[K][number], "id">
  ): Promise<ApiResponse<Endpoints[K][number]>> {
    const response = await fetch(`${this.baseUrl}/${endpoint}`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(body)
    });
    const data = await response.json();

    return {
      data,
      status: response.status,
      message: "Created"
    };
  }
}

// 사용
const api = new ApiClient("https://api.example.com");

// 타입 안전한 API 호출
const users = await api.get("users");           // ApiResponse<User[]>
const user = await api.getById("users", 1);     // ApiResponse<User>

const newPost = await api.post("posts", {
  title: "New Post",
  content: "Content",
  userId: 1
});
```

### 예제 2: 폼 빌더

```typescript
// 폼 필드 타입
type FieldType = "text" | "number" | "email" | "password" | "checkbox";

interface FieldConfig<T extends FieldType> {
  type: T;
  label: string;
  placeholder?: string;
  required?: boolean;
  validation?: (value: any) => string | null;
}

// 필드 타입에 따른 값 타입
type FieldValue<T extends FieldType> =
  T extends "number" ? number :
  T extends "checkbox" ? boolean :
  string;

// 폼 스키마
type FormSchema = {
  [key: string]: FieldConfig<FieldType>;
};

// 폼 값 타입 추론
type FormValues<T extends FormSchema> = {
  [K in keyof T]: FieldValue<T[K]["type"]>;
};

// 폼 빌더
class FormBuilder<T extends FormSchema> {
  constructor(private schema: T) {}

  getInitialValues(): FormValues<T> {
    const values: any = {};

    for (const key in this.schema) {
      const field = this.schema[key];
      values[key] = field.type === "checkbox" ? false :
                    field.type === "number" ? 0 : "";
    }

    return values;
  }

  validate(values: FormValues<T>): Record<keyof T, string | null> {
    const errors: any = {};

    for (const key in this.schema) {
      const field = this.schema[key];
      const value = values[key];

      if (field.required && !value) {
        errors[key] = `${field.label} is required`;
        continue;
      }

      if (field.validation) {
        errors[key] = field.validation(value);
      } else {
        errors[key] = null;
      }
    }

    return errors;
  }
}

// 사용
const loginFormSchema = {
  email: {
    type: "email" as const,
    label: "Email",
    placeholder: "Enter your email",
    required: true,
    validation: (value: string) =>
      /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value) ? null : "Invalid email"
  },
  password: {
    type: "password" as const,
    label: "Password",
    placeholder: "Enter your password",
    required: true,
    validation: (value: string) =>
      value.length >= 6 ? null : "Password must be at least 6 characters"
  },
  remember: {
    type: "checkbox" as const,
    label: "Remember me"
  }
};

const formBuilder = new FormBuilder(loginFormSchema);
const initialValues = formBuilder.getInitialValues();
// { email: "", password: "", remember: false }

const values: FormValues<typeof loginFormSchema> = {
  email: "user@example.com",
  password: "password123",
  remember: true
};

const errors = formBuilder.validate(values);
console.log(errors);
```

### 💡 Tip 3: 타입 안전한 이벤트 시스템

```typescript
// 이벤트 맵
interface EventMap {
  "user:login": { userId: number; timestamp: Date };
  "user:logout": { userId: number };
  "post:created": { postId: number; title: string };
}

// 타입 안전한 이벤트 이미터
class TypedEventEmitter {
  private listeners: {
    [K in keyof EventMap]?: Array<(data: EventMap[K]) => void>;
  } = {};

  on<K extends keyof EventMap>(
    event: K,
    callback: (data: EventMap[K]) => void
  ): void {
    if (!this.listeners[event]) {
      this.listeners[event] = [];
    }
    this.listeners[event]!.push(callback);
  }

  emit<K extends keyof EventMap>(event: K, data: EventMap[K]): void {
    const callbacks = this.listeners[event];
    if (callbacks) {
      callbacks.forEach(callback => callback(data));
    }
  }
}

// 사용
const emitter = new TypedEventEmitter();

emitter.on("user:login", (data) => {
  console.log(`User ${data.userId} logged in at ${data.timestamp}`);
});

emitter.emit("user:login", { userId: 1, timestamp: new Date() });
```

### 문제 1: Result 타입

<details>
<summary>정답 보기</summary>

```typescript
type Result<T, E = Error> =
  | { success: true; value: T }
  | { success: false; error: E };

// 사용
function divide(a: number, b: number): Result<number, string> {
  if (b === 0) {
    return { success: false, error: "Division by zero" };
  }
  return { success: true, value: a / b };
}

const result = divide(10, 2);
if (result.success) {
  console.log(result.value);  // 5
} else {
  console.error(result.error);
}
```
