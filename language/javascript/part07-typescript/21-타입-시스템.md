# Chapter 21. 타입 시스템

## 21.1 기본 타입 (Primitive Types)

> 🧱 **비유**: 타입은 **재료의 종류**입니다.
> - 숫자, 문자열, 불린 등 각각의 용도
> - 잘못된 타입 사용 시 컴파일 에러

### 기본 타입 종류

```typescript
// 1. number: 모든 숫자 (정수, 실수)
let age: number = 25;
let price: number = 19.99;
let hex: number = 0xf00d;
let binary: number = 0b1010;

// 2. string: 문자열
let name: string = "Alice";
let greeting: string = `Hello, ${name}`;

// 3. boolean: 참/거짓
let isActive: boolean = true;
let hasPermission: boolean = false;

// 4. null & undefined
let nothing: null = null;
let notDefined: undefined = undefined;

// 5. symbol: 고유한 식별자
let sym: symbol = Symbol("key");

// 6. bigint: 큰 정수 (ES2020+)
let bigNumber: bigint = 9007199254740991n;
```

---

### Java vs TypeScript 비교

**Java**:
```java
// 원시 타입 vs 래퍼 클래스
int age = 25;              // 원시 타입
Integer ageObj = 25;       // 래퍼 클래스

String name = "Alice";     // 참조 타입
boolean isActive = true;   // 원시 타입
```

**TypeScript**:
```typescript
// 모든 타입이 소문자 (원시 타입)
let age: number = 25;
let name: string = "Alice";
let isActive: boolean = true;

// ❌ 대문자는 사용하지 않음
let age: Number = 25;     // 가능하지만 권장 안 함
let name: String = "Alice";  // 가능하지만 권장 안 함
```

> 💡 **규칙**: 항상 소문자 타입 사용 (`string`, `number`, `boolean`)

### 튜플 (Tuple)

> 🎯 **비유**: 튜플은 **정해진 순서의 좌석표**입니다.
> - 첫 번째는 이름, 두 번째는 나이처럼 고정

**고정된 길이와 타입의 배열**

```typescript
// 튜플 선언
let user: [string, number] = ["Alice", 25];
let rgb: [number, number, number] = [255, 0, 0];

// 구조 분해
let [name, age] = user;
console.log(name);  // Alice (string)
console.log(age);   // 25 (number)

// 옵셔널 요소
let optionalTuple: [string, number?] = ["Alice"];
let optionalTuple2: [string, number?] = ["Bob", 30];

// Rest 요소
let tuple: [string, ...number[]] = ["Alice", 1, 2, 3, 4];
```

### 인터페이스 (Interface)

> 🔌 **비유**: 인터페이스는 **USB 규격**입니다.
> - 어떤 속성과 메서드가 있어야 하는지 정의
> - 같은 규격이면 호환 가능

**객체의 구조를 정의**

```typescript
// 기본 인터페이스
interface User {
  id: number;

  email: string;

const user: User = {
  id: 1,

interface Product {

interface Config {

const config: Config = {
  apiUrl: "https://api.example.com",
  timeout: 5000

// config.apiUrl = "https://new-api.com";  // ❌ 에러
```

### Type Alias vs Interface

**Type Alias**: 타입에 이름 부여

```typescript
// Type Alias
type User = {
  id: number;
  name: string;
  email: string;
};

type ID = number | string;

type Point = {
  x: number;
  y: number;
};

// Union, Intersection도 가능
type Admin = User & {
  role: "admin";
};
```

**Interface vs Type 비교**

| 특성 | Interface | Type Alias |
|-----|-----------|-----------|
| 확장 | `extends` | `&` (Intersection) |
| 선언 병합 | O | X |
| Union/Intersection | X | O |
| Primitive 타입 | X | O |
| 튜플 | 가능 | 더 간결 |
| 용도 | 객체 구조 | 모든 타입 |

```typescript
// 선언 병합 (Interface만 가능)
interface Window {
  title: string;
}

interface Window {
  version: string;
}

// 자동으로 병합됨
const win: Window = {
  title: "My Window",
  version: "1.0"
};

// Type은 선언 병합 불가
type Config = { apiUrl: string };
// type Config = { timeout: number };  // ❌ Duplicate identifier 'Config'
```

> 💡 **권장**:
> - **객체 구조**: Interface 사용
> - **Union, Primitive**: Type Alias 사용

## 21.4 함수 타입 (Function Types)

### 함수 타입 선언

```typescript
// 기본 함수
function add(a: number, b: number): number {
  return a + b;
}

// 화살표 함수
const multiply = (a: number, b: number): number => {
  return a * b;
};

// 한 줄 함수
const divide = (a: number, b: number): number => a / b;

// 반환 타입 추론 (생략 가능)
const subtract = (a: number, b: number) => a - b;  // number로 자동 추론
```

---

### 옵셔널 매개변수

```typescript
// 선택적 매개변수
function greet(name: string, greeting?: string): string {
  return `${greeting || "Hello"}, ${name}!`;
}

console.log(greet("Alice"));              // Hello, Alice!
console.log(greet("Bob", "Hi"));          // Hi, Bob!

// 기본값 (추천)
function greet(name: string, greeting: string = "Hello"): string {
  return `${greeting}, ${name}!`;
}
```

---

### Rest 매개변수

```typescript
// 나머지 매개변수
function sum(...numbers: number[]): number {
  return numbers.reduce((acc, n) => acc + n, 0);
}

console.log(sum(1, 2, 3));        // 6
console.log(sum(1, 2, 3, 4, 5));  // 15

// 일반 + Rest 혼합
function introduce(greeting: string, ...names: string[]): string {
  return `${greeting} ${names.join(", ")}!`;
}

console.log(introduce("Hello", "Alice", "Bob", "Charlie"));
// Hello Alice, Bob, Charlie!
```

### 함수 오버로딩

> 📞 **비유**: 오버로딩은 **같은 이름, 다른 전화번호**입니다.
> - 같은 함수 이름
> - 매개변수 타입/개수에 따라 다르게 동작

**TypeScript는 선언만 오버로딩, 구현은 하나**

```typescript
// 오버로드 시그니처
function process(value: string): string;
function process(value: number): number;
function process(value: string[]): string[];

// 구현 시그니처 (하나만)
function process(value: string | number | string[]): string | number | string[] {
  if (typeof value === "string") {
    return value.toUpperCase();
  } else if (typeof value === "number") {
    return value * 2;
  } else {
    return value.map(v => v.toUpperCase());
  }
}

console.log(process("hello"));        // HELLO
console.log(process(10));             // 20
console.log(process(["a", "b"]));     // ["A", "B"]
```

---

### Java vs TypeScript 함수

**Java**:
```java
// 메서드 오버로딩
public int add(int a, int b) {
    return a + b;
}

public double add(double a, double b) {
    return a + b;
}

// 선택적 매개변수 없음 (오버로딩으로 구현)
public void greet(String name) {
    greet(name, "Hello");
}

public void greet(String name, String greeting) {
    System.out.println(greeting + ", " + name);
}
```

**TypeScript**:
```typescript

function add(a: number, b: number): number;
function add(a: string, b: string): string;
function add(a: any, b: any): any {
  return a + b;
}

// 선택적 매개변수
function greet(name: string, greeting: string = "Hello"): void {
  console.log(`${greeting}, ${name}`);
}
```

## 21.5 유니온 (Union Types)

> 🎭 **비유**: 유니온은 **멀티플레이어**입니다.
> - 여러 타입 중 하나
> - "또는(OR)" 관계

**여러 타입 중 하나를 허용**

```typescript
// 기본 유니온
let id: number | string;
id = 123;       // ✅
id = "ABC123";  // ✅
// id = true;   // ❌ Type 'boolean' is not assignable

// 함수 매개변수
function printId(id: number | string): void {
  console.log(`ID: ${id}`);
}

printId(123);       // ✅
printId("ABC123");  // ✅

// 배열 유니온
let mixed: (number | string)[] = [1, "two", 3, "four"];

// 리터럴 유니온
type Status = "pending" | "approved" | "rejected";
let status: Status = "pending";
// status = "unknown";  // ❌ Type '"unknown"' is not assignable to type 'Status'
```

---

### 타입 가드 (Type Guards)

**유니온 타입 좁히기**

```typescript
function processValue(value: string | number) {
  // typeof 타입 가드
  if (typeof value === "string") {
    // 이 블록에서는 value가 string
    return value.toUpperCase();
  } else {
    // 이 블록에서는 value가 number
    return value.toFixed(2);
  }
}

// instanceof 타입 가드
function processDate(date: Date | string) {
  if (date instanceof Date) {
    return date.toISOString();
  } else {
    return new Date(date).toISOString();
  }
}

// in 타입 가드
interface Bird {
  fly(): void;
  layEggs(): void;
}

interface Fish {
  swim(): void;
  layEggs(): void;
}

function move(animal: Bird | Fish) {
  if ("fly" in animal) {
    animal.fly();
  } else {
    animal.swim();
  }
}
```

## 21.6 인터섹션 (Intersection Types)

> 🔗 **비유**: 인터섹션은 **합체**입니다.
> - 모든 타입의 속성을 가짐
> - "그리고(AND)" 관계

**여러 타입을 합침**

```typescript
// 기본 인터섹션
interface Person {
  name: string;
  age: number;
}

interface Employee {
  employeeId: number;
  department: string;
}

type EmployeePerson = Person & Employee;

const employee: EmployeePerson = {
  name: "Alice",
  age: 25,
  employeeId: 1001,
  department: "Engineering"
};

// 여러 타입 결합
interface Timestamped {
  createdAt: Date;
  updatedAt: Date;
}

interface Auditable {
  createdBy: string;
  updatedBy: string;
}

type AuditedEntity = Timestamped & Auditable & {
  id: number;
  name: string;
};

const entity: AuditedEntity = {
  id: 1,
  name: "Entity",
  createdAt: new Date(),
  updatedAt: new Date(),
  createdBy: "admin",
  updatedBy: "admin"
};
```

---

### Union vs Intersection

```typescript
// Union: OR (하나만 만족)
type A = { name: string };
type B = { age: number };

type UnionAB = A | B;
const union1: UnionAB = { name: "Alice" };          // ✅
const union2: UnionAB = { age: 25 };                // ✅
const union3: UnionAB = { name: "Bob", age: 30 };   // ✅

// Intersection: AND (모두 만족)
type IntersectionAB = A & B;
// const inter1: IntersectionAB = { name: "Alice" };  // ❌ Property 'age' is missing
// const inter2: IntersectionAB = { age: 25 };        // ❌ Property 'name' is missing
const inter3: IntersectionAB = { name: "Bob", age: 30 };  // ✅
```

## 21.7 리터럴 타입 (Literal Types)

> 🎯 **비유**: 리터럴은 **정확한 값**입니다.
> - "이 값만" 허용
> - Enum보다 가벼움

**특정 값만 허용**

```typescript
// 문자열 리터럴
let direction: "north" | "south" | "east" | "west";
direction = "north";  // ✅
// direction = "up";  // ❌ Type '"up"' is not assignable

// 숫자 리터럴
let diceRoll: 1 | 2 | 3 | 4 | 5 | 6;
diceRoll = 3;  // ✅
// diceRoll = 7;  // ❌

// 불린 리터럴
let isTrue: true = true;
// isTrue = false;  // ❌

// 함수 반환 타입
function getStatus(): "success" | "error" | "pending" {
  return "success";
}

// 타입 별칭과 함께 사용
type HttpMethod = "GET" | "POST" | "PUT" | "DELETE" | "PATCH";

function sendRequest(url: string, method: HttpMethod): void {
  console.log(`${method} ${url}`);
}

sendRequest("/api/users", "GET");   // ✅
// sendRequest("/api/users", "get");  // ❌ 대소문자 구분
```

---

### 리터럴 vs Enum

**Enum** (Java 스타일):
```typescript
enum Direction {
  North = "NORTH",
  South = "SOUTH",

let dir: Direction = Direction.North;
```

## 21.8 Null과 Undefined

### strictNullChecks

```typescript
// strictNullChecks: false (기본값, 권장 안 함)
let name: string = null;      // ✅ 허용
let age: number = undefined;  // ✅ 허용

// strictNullChecks: true (권장)
let name: string = null;      // ❌ Type 'null' is not assignable to type 'string'
let age: number = undefined;  // ❌ Type 'undefined' is not assignable to type 'number'

// 명시적으로 허용
let name: string | null = null;          // ✅
let age: number | undefined = undefined; // ✅
let value: string | null | undefined;    // ✅
```

---

### Non-null Assertion (!)

```typescript
// null/undefined가 아님을 단언
function processValue(value: string | null) {
  // console.log(value.length);  // ❌ Object is possibly 'null'

  // ! 연산자: null이 아니라고 단언
  console.log(value!.length);  // ✅ (위험! 확신할 때만 사용)
}

// 더 안전한 방법: 타입 가드
function processValue(value: string | null) {
  if (value !== null) {
    console.log(value.length);  // ✅ 안전
  }
}

// 옵셔널 체이닝 (권장)
function processValue(value: string | null) {
  console.log(value?.length);  // undefined 또는 length
}
```

---

### Java vs TypeScript Null 처리

**Java**:
```java
// null만 존재
String name = null;

// NullPointerException 방지
if (name != null) {
    System.out.println(name.length());
}

// Java 8+: Optional
Optional<String> optName = Optional.ofNullable(name);
optName.ifPresent(n -> System.out.println(n.length()));
```

**TypeScript**:
```typescript
// null과 undefined 모두 존재
let name: string | null = null;
let age: number | undefined = undefined;

// 타입 가드
if (name !== null) {
  console.log(name.length);
}

// 옵셔널 체이닝
console.log(name?.length);

// Nullish Coalescing
let displayName = name ?? "Guest";
```

## 21.9 실전 예제

### 예제 1: API 응답 타입

```typescript
// API 응답 타입 정의
interface ApiResponse<T> {
  success: boolean;
  data: T | null;
  error: string | null;
  timestamp: Date;
}

interface User {
  id: number;
  name: string;
  email: string;
  role: "admin" | "user" | "guest";
}

// 사용
async function fetchUser(id: number): Promise<ApiResponse<User>> {
  try {
    const response = await fetch(`/api/users/${id}`);
    const data = await response.json();

    return {
      success: true,
      data: data,
      error: null,
      timestamp: new Date()
    };
  } catch (error) {
    return {
      success: false,
      data: null,
      error: error.message,
      timestamp: new Date()
    };
  }
}

// 타입 안전하게 사용
const response = await fetchUser(1);
if (response.success && response.data) {
  console.log(response.data.name);  // 타입 안전
}
```

### 예제 2: 폼 검증

```typescript
// 폼 필드 타입
interface FormField<T> {
  value: T;
  error: string | null;
  touched: boolean;
  valid: boolean;
}

type FormData = {
  username: FormField<string>;
  email: FormField<string>;
  age: FormField<number>;
  terms: FormField<boolean>;
};

// 검증 함수
function validateUsername(value: string): string | null {
  if (value.length < 3) {
    return "Username must be at least 3 characters";
  }
  if (!/^[a-zA-Z0-9_]+$/.test(value)) {
    return "Username can only contain letters, numbers, and underscores";
  }
  return null;
}

function validateEmail(value: string): string | null {
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value)) {
    return "Invalid email format";
  }
  return null;
}

// 폼 상태 관리
class FormManager {
  private form: FormData;

  constructor() {
    this.form = {
      username: { value: "", error: null, touched: false, valid: false },
      email: { value: "", error: null, touched: false, valid: false },
      age: { value: 0, error: null, touched: false, valid: false },
      terms: { value: false, error: null, touched: false, valid: false }
    };
  }

  updateField(field: keyof FormData, value: any): void {
    this.form[field].value = value;
    this.form[field].touched = true;
    this.validateField(field);
  }

  private validateField(field: keyof FormData): void {
    const fieldData = this.form[field];

    switch (field) {
      case "username":
        fieldData.error = validateUsername(fieldData.value as string);
        break;
      case "email":
        fieldData.error = validateEmail(fieldData.value as string);
        break;
      case "age":
        fieldData.error = (fieldData.value as number) < 18 ? "Must be 18 or older" : null;
        break;
      case "terms":
        fieldData.error = (fieldData.value as boolean) ? null : "You must accept the terms";
        break;
    }

    fieldData.valid = fieldData.error === null;
  }

  isFormValid(): boolean {
    return Object.values(this.form).every(field => field.valid);
  }

  getFormData(): { username: string; email: string; age: number; terms: boolean } {
    return {
      username: this.form.username.value,
      email: this.form.email.value,
      age: this.form.age.value,
      terms: this.form.terms.value
    };
  }
}

// 사용
const formManager = new FormManager();
formManager.updateField("username", "alice");
formManager.updateField("email", "alice@example.com");
formManager.updateField("age", 25);
formManager.updateField("terms", true);

if (formManager.isFormValid()) {
  const data = formManager.getFormData();
  console.log("Form submitted:", data);
}
```

### 문제 1: Shopping Cart 타입

장바구니 시스템의 타입을 정의하세요.

```typescript
interface Product {
  id: number;
  name: string;
  price: number;
  category: "electronics" | "clothing" | "food";
}

interface CartItem {
  product: Product;
  quantity: number;
}

interface ShoppingCart {
  items: CartItem[];
  total: number;
}

function addToCart(cart: ShoppingCart, product: Product, quantity: number): ShoppingCart {
  const existingItem = cart.items.find(item => item.product.id === product.id);

  if (existingItem) {
    existingItem.quantity += quantity;
  } else {
    cart.items.push({ product, quantity });
  }

  cart.total = cart.items.reduce(
    (sum, item) => sum + item.product.price * item.quantity,
    0
  );

  return cart;
}

// 사용
const cart: ShoppingCart = { items: [], total: 0 };
const product: Product = {
  id: 1,
  name: "Laptop",
  price: 1000,
  category: "electronics"
};

addToCart(cart, product, 2);
console.log(cart.total);  // 2000
```

```typescript
interface Dog {

  type: "cat";

interface Bird {
  type: "bird";
  fly(): void;

type Animal = Dog | Cat | Bird;

function isDog(animal: Animal): animal is Dog {
  return animal.type === "dog";
}

function isCat(animal: Animal): animal is Cat {
  return animal.type === "cat";
}

function isBird(animal: Animal): animal is Bird {
  return animal.type === "bird";
}

// 사용
function makeSound(animal: Animal) {
  if (isDog(animal)) {
    animal.bark();
  } else if (isCat(animal)) {
    animal.meow();
  } else if (isBird(animal)) {
    animal.fly();
  }
}
```
