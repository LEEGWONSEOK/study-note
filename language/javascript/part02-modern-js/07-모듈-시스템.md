# Chapter 7. 모듈 시스템

## 7.1 모듈이란?

> 🎯 **핵심**: 모듈은 **코드를 파일로 나누는 방법**입니다.
> - 재사용성 향상
> - 유지보수 용이
> - 네임스페이스 충돌 방지

**비유**: 모듈은 **레고 블록**입니다.
- 각 블록(모듈)은 독립적
- 필요한 블록만 조립해서 사용
- 블록을 다른 작품에도 재사용 가능

**Java와 비교**:
```java
// Java - 패키지와 클래스
package com.example.utils;

public class MathUtils {
    public static int add(int a, int b) {
        return a + b;
    }
}

// 다른 파일에서
import com.example.utils.MathUtils;
MathUtils.add(1, 2);

// JavaScript - 모듈
// mathUtils.js
export function add(a, b) {
    return a + b;
}

// 다른 파일에서
import { add } from './mathUtils.js';
add(1, 2);
```

## 7.2 ES6 모듈 (ESM) - 표준

> 💡 **권장**: ES6 모듈을 사용하세요 (2015년 이후 표준)

### Named Export (이름 있는 내보내기)

```javascript
// mathUtils.js

// 방법 1: 선언과 동시에 export
export function add(a, b) {
    return a + b;
}

export function subtract(a, b) {
    return a - b;
}

export const PI = 3.14159;

// 방법 2: 나중에 한 번에 export
function multiply(a, b) {
    return a * b;
}

function divide(a, b) {
    return a / b;
}

export { multiply, divide };

// 방법 3: 이름 변경해서 export
function power(base, exponent) {
    return base ** exponent;
}

export { power as pow };
```

**import 하기**:
```javascript
// app.js

// 방법 1: 필요한 것만 import
import { add, subtract } from './mathUtils.js';
console.log(add(5, 3));       // 8
console.log(subtract(5, 3));  // 2

// 방법 2: 이름 변경해서 import
import { add as sum } from './mathUtils.js';
console.log(sum(5, 3));  // 8

// 방법 3: 모두 import (네임스페이스)
import * as math from './mathUtils.js';
console.log(math.add(5, 3));       // 8
console.log(math.subtract(5, 3));  // 2
console.log(math.PI);              // 3.14159
```

### Default Export (기본 내보내기)

```javascript
// calculator.js

// 방법 1: 함수 기본 내보내기
export default function calculator(operation, a, b) {
    switch (operation) {
        case 'add': return a + b;
        case 'subtract': return a - b;
        case 'multiply': return a * b;
        case 'divide': return a / b;
        default: throw new Error('Unknown operation');
    }
}

// 방법 2: 클래스 기본 내보내기
export default class Calculator {
    add(a, b) { return a + b; }
    subtract(a, b) { return a - b; }
}

// 방법 3: 객체 기본 내보내기
const calculator = {
    add: (a, b) => a + b,
    subtract: (a, b) => a - b
};
export default calculator;

// 방법 4: 익명 함수 기본 내보내기
export default (a, b) => a + b;
```

**import 하기**:
```javascript
// app.js

// 이름은 자유롭게 지정 가능
import calculator from './calculator.js';
import calc from './calculator.js';  // 다른 이름도 가능
import anyName from './calculator.js';  // 아무 이름이나 가능

console.log(calculator('add', 5, 3));  // 8
```

### Re-export (재내보내기)


## 7.3 CommonJS - Node.js 전통 방식

> ⚠️ **주의**: Node.js의 구식 모듈 시스템
> - 여전히 많이 사용됨
> - ES6 모듈이 권장되지만 호환성 위해 알아야 함

### exports와 module.exports

```javascript
// mathUtils.js

// 방법 1: exports 객체에 추가
exports.add = function(a, b) {
    return a + b;
};

exports.subtract = function(a, b) {
    return a - b;
};

exports.PI = 3.14159;

// 방법 2: module.exports 직접 할당
module.exports = {
    add: (a, b) => a + b,
    subtract: (a, b) => a - b,
    PI: 3.14159
};

// 방법 3: 함수 하나만 내보내기
module.exports = function calculator(operation, a, b) {
    switch (operation) {
        case 'add': return a + b;
        case 'subtract': return a - b;
    }
};

// 방법 4: 클래스 내보내기
module.exports = class Calculator {
    add(a, b) { return a + b; }
    subtract(a, b) { return a - b; }
};
```

**require로 import**:
```javascript
// app.js

// 방법 1, 2: 객체로 받기
const math = require('./mathUtils');
console.log(math.add(5, 3));  // 8
console.log(math.PI);          // 3.14159

// 구조 분해로 받기
const { add, subtract } = require('./mathUtils');
console.log(add(5, 3));  // 8

// 방법 3, 4: 함수/클래스로 받기
const calculator = require('./calculator');
console.log(calculator('add', 5, 3));  // 8

const Calculator = require('./calculator');
const calc = new Calculator();
console.log(calc.add(5, 3));  // 8
```

---

### exports vs module.exports 차이

```javascript
// ⚠️ 헷갈리는 부분!

// ✅ 올바른 사용
exports.add = (a, b) => a + b;
exports.subtract = (a, b) => a - b;

// ❌ 잘못된 사용
exports = {
    add: (a, b) => a + b,
    subtract: (a, b) => a - b
};
// exports를 재할당하면 module.exports와 연결이 끊어짐!

// ✅ 올바른 방법
module.exports = {
    add: (a, b) => a + b,
    subtract: (a, b) => a - b
};
```

**비유**:
- `exports`는 `module.exports`의 **별명(참조)**
- `exports`를 재할당하면 별명만 바뀌고 원본은 그대로
- `module.exports`를 재할당하면 실제 내보내는 것이 바뀜

---

### ES6 vs CommonJS 비교

| 특성 | ES6 (ESM) | CommonJS |
|------|-----------|----------|
| 문법 | `import`/`export` | `require`/`module.exports` |
| 로딩 | 정적 (컴파일 시) | 동적 (런타임) |
| 비동기 | 가능 | 불가능 |
| Tree-shaking | 가능 | 불가능 |
| 브라우저 | 지원 | 불가능 (번들러 필요) |
| Node.js | 16+ (기본 지원) | 모든 버전 |

```javascript
// ES6 (ESM)
import { add } from './math.js';      // 정적 import
const result = add(1, 2);

// 동적 import (비동기)
if (condition) {
    const { add } = await import('./math.js');
}

// CommonJS
const { add } = require('./math');    // 항상 동기
const result = add(1, 2);

// 조건부 require (가능하지만 비권장)
if (condition) {
    const { add } = require('./math');
}
```

## 7.4 동적 Import

> 💡 **최신 기능**: 필요할 때만 모듈 로딩

### 기본 문법

```javascript
// 정적 import (파일 시작 부분, 항상 로딩)
import { heavyFunction } from './heavy.js';

// 동적 import (필요할 때만 로딩)
async function loadModule() {
    const module = await import('./heavy.js');
    module.heavyFunction();
}

// 또는
button.addEventListener('click', async () => {
    const { heavyFunction } = await import('./heavy.js');
    heavyFunction();
});
```

### 절대 경로 설정


```json
{
    "compilerOptions": {

            "@/*": ["src/*"],
            "@components/*": ["src/components/*"],
            "@utils/*": ["src/utils/*"]
        }

}
```

### CommonJS와 ES6 혼용

```javascript
// CommonJS 모듈을 ES6에서 import
// old-module.js (CommonJS)
module.exports = {
    add: (a, b) => a + b
};

// app.js (ES6)
import oldModule from './old-module.js';
console.log(oldModule.add(1, 2));  // 3

// ⚠️ ES6 모듈을 CommonJS에서 require (복잡함)
// new-module.js (ES6)

// app.js (CommonJS)

// ✅ 동적 import 사용
(async () => {
    const { add } = await import('./new-module.js');
    console.log(add(1, 2));
})();
```

## 7.7 실전 예제

### API 서비스 모듈

```javascript
// services/api.js
const API_BASE = 'https://api.example.com';

async function fetchJSON(endpoint) {
    const response = await fetch(`${API_BASE}${endpoint}`);
    if (!response.ok) {
        throw new Error(`HTTP error! status: ${response.status}`);
    }
    return response.json();
}

export async function getUsers() {
    return fetchJSON('/users');
}

export async function getUser(id) {
    return fetchJSON(`/users/${id}`);
}

export async function createUser(data) {
    const response = await fetch(`${API_BASE}/users`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data)
    });
    return response.json();
}

// services/index.js
export * from './api.js';
export * from './auth.js';
export * from './storage.js';
```

## 📝 핵심 요약

1. **ES6 모듈 사용 (ESM)**: `import`/`export` (권장!)
   - Named Export: 여러 함수/변수 내보내기
   - Default Export: 주요 하나만 내보내기

2. **CommonJS**: `require`/`module.exports`
   - Node.js 구식 방식
   - 호환성 위해 알아야 함

3. **동적 Import**: 필요할 때만 로딩
   - 코드 스플리팅
   - 조건부 로딩

4. **베스트 프랙티스**:
   - index.js로 Re-export
   - 절대 경로 사용
   - 순환 의존성 피하기
   - Named Export 우선

```javascript
// 1. mathUtils.js
export function add(a, b) {
    return a + b;
}

export function subtract(a, b) {
    return a - b;
}

export function multiply(a, b) {
    return a * b;
}

export function divide(a, b) {
    if (b === 0) throw new Error('Division by zero');
    return a / b;
}

export const PI = 3.14159;

// 2. calculator.js
export default class Calculator {
    add(a, b) { return a + b; }
    subtract(a, b) { return a - b; }
    multiply(a, b) { return a * b; }
    divide(a, b) {
        if (b === 0) throw new Error('Division by zero');
        return a / b;
    }
}

// 3. utils/index.js
export * from './mathUtils.js';
export { default as Calculator } from './calculator.js';

// 4. app.js

// 방법 1: 개별 import
import { add, subtract, PI } from './utils/mathUtils.js';
import Calculator from './utils/calculator.js';

import { add, Calculator } from './utils';
```
