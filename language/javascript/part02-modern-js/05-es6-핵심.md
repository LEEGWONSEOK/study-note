# Chapter 5. ES6 핵심

## 5.1 ES6란?

**ES6 (ECMAScript 2015)**: JavaScript의 가장 중요한 업데이트

> 🚀 **비유**: ES6는 JavaScript의 **대격변**입니다.
> - ES5 이전: 자전거 (기본 기능만)
> - ES6+: 자동차 (현대적이고 강력한 기능)

### 왜 중요한가?

1. **현대 JavaScript의 표준**
   - 모든 최신 프레임워크가 ES6+ 기반
   - React, Vue, Next.js 모두 ES6 필수

2. **생산성 향상**
   - 코드가 간결해짐
   - 읽기 쉬워짐
   - 버그가 줄어듦

3. **Java 개발자에게 친숙한 기능**
   - 클래스 문법
   - 모듈 시스템
   - Promise (Future와 유사)

## 5.4 구조 분해 할당 (Destructuring)

> 📦 **비유**: 구조 분해는 **택배 개봉**입니다.
> - 박스(배열/객체)를 열어서
> - 내용물을 하나씩 꺼내서
> - 각각의 변수에 할당

### 배열 구조 분해

```javascript
// ❌ 기존 방식
const colors = ["red", "green", "blue"];
const first = colors[0];
const second = colors[1];
const third = colors[2];

// ✅ ES6: 배열 구조 분해
const [first, second, third] = colors;

// 일부만 가져오기
const [red, , blue] = colors;  // green 건너뛰기

// 나머지 요소
const [head, ...tail] = [1, 2, 3, 4, 5];
console.log(head);  // 1
console.log(tail);  // [2, 3, 4, 5]

// 기본값 설정
const [a, b, c = 0] = [1, 2];
console.log(a, b, c);  // 1 2 0
```

---

### 객체 구조 분해

```javascript
const user = {
  name: "Alice",
  age: 25,
  email: "alice@example.com"
};

// ❌ 기존 방식
const name = user.name;
const age = user.age;

// ✅ ES6: 객체 구조 분해
const { name, age } = user;

// 변수명 변경
const { name: userName, age: userAge } = user;
console.log(userName);  // Alice

// 기본값 설정
const { name, age, country = "Korea" } = user;
console.log(country);  // Korea

// 중첩 객체
const person = {
  name: "Bob",
  address: {
    city: "Seoul",
    country: "Korea"
  }
};

const { address: { city, country } } = person;
console.log(city);  // Seoul

// 나머지 속성
const { name, ...rest } = user;
console.log(rest);  // { age: 25, email: 'alice@example.com' }
```

### 함수 매개변수에서 사용

```javascript
// ✅ 객체 구조 분해
function greet({ name, age }) {
  return `안녕, ${name}! ${age}세구나.`;
}

greet({ name: "Alice", age: 25 });

// 기본값과 함께

// 배열 구조 분해
function getMinMax([first, ...rest]) {
  let min = first, max = first;
  for (const num of rest) {
    if (num < min) min = num;
    if (num > max) max = num;
  }
  return [min, max];
}

const [min, max] = getMinMax([3, 1, 4, 1, 5, 9]);
```

## 5.5 전개 연산자 (Spread Operator)

> 🌊 **비유**: Spread는 **물을 쏟는 것**입니다.
> - 배열/객체를 **펼쳐서** 나열
> - 깊은 복사에 유용

### 배열 전개

```javascript
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

// ❌ 기존 방식: concat
const combined = arr1.concat(arr2);

// ✅ ES6: Spread
const combined = [...arr1, ...arr2];  // [1, 2, 3, 4, 5, 6]

// 배열 복사
const original = [1, 2, 3];
const copy = [...original];  // 새 배열 생성
copy.push(4);
console.log(original);  // [1, 2, 3] (원본 안 바뀜)
console.log(copy);      // [1, 2, 3, 4]

// 배열 요소 추가
const arr = [2, 3, 4];
const newArr = [1, ...arr, 5];  // [1, 2, 3, 4, 5]

// 함수 인자로 전개
const numbers = [1, 2, 3, 4, 5];
console.log(Math.max(...numbers));  // 5
```

---

### 객체 전개

```javascript
const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3, d: 4 };

// ✅ 객체 병합
const combined = { ...obj1, ...obj2 };
// { a: 1, b: 2, c: 3, d: 4 }

// 속성 덮어쓰기
const defaults = { theme: "light", lang: "ko" };
const userSettings = { lang: "en" };
const settings = { ...defaults, ...userSettings };
// { theme: 'light', lang: 'en' }

// 객체 복사 및 수정
const user = { name: "Alice", age: 25 };
const updatedUser = { ...user, age: 26 };
// { name: 'Alice', age: 26 }

// 조건부 속성 추가
const isAdmin = true;
const user = {
  name: "Alice",
  ...(isAdmin && { role: "admin" })  // admin이면 role 추가
};
```

## 5.7 화살표 함수 (Arrow Functions) 심화

### this 바인딩 차이

```javascript
// 일반 함수: this가 동적
const obj1 = {
  name: "Alice",
  greet: function() {
    setTimeout(function() {
      console.log(`Hello, ${this.name}`);  // this = window (또는 undefined)
    }, 1000);
  }
};

// 화살표 함수: this가 렉시컬 (상위 스코프의 this)
const obj2 = {
  name: "Alice",
  greet: function() {
    setTimeout(() => {
      console.log(`Hello, ${this.name}`);  // this = obj2
    }, 1000);
  }
};

// 화살표 함수로 메서드 정의하면 안 됨!
const obj3 = {
  name: "Alice",
  // ❌ 이렇게 하면 this가 window를 가리킴
  greet: () => {
    console.log(this.name);  // undefined
  }
};
```

> 💡 **규칙**:
> - 일반 함수: 메서드, 생성자
> - 화살표 함수: 콜백, 간단한 함수

## 5.8 기본 매개변수 (Default Parameters)

```javascript
// ❌ 기존 방식
function greet(name) {
  name = name || "Guest";  // falsy 값 문제 (0, "", false도 Guest로!)
  return `안녕, ${name}!`;
}

// ✅ ES6: 기본 매개변수
function greet(name = "Guest") {
  return `안녕, ${name}!`;
}

// 다른 매개변수 참조 가능
function createUrl(domain, path = "index.html", protocol = "https") {
  return `${protocol}://${domain}/${path}`;
}

// 함수 호출을 기본값으로
function getDefaultDate() {
  return new Date();
}

function log(message, timestamp = getDefaultDate()) {
  console.log(`[${timestamp}] ${message}`);
}
```

## 5.9 나머지 매개변수 (Rest Parameters)

```javascript
// ❌ 기존 방식: arguments (유사 배열)
function sum() {
  let total = 0;
  for (let i = 0; i < arguments.length; i++) {
    total += arguments[i];
  }
  return total;
}

// ✅ ES6: Rest Parameters (진짜 배열)
function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}

// 일부 매개변수 + Rest
function multiply(factor, ...numbers) {
  return numbers.map(n => n * factor);
}

multiply(2, 1, 2, 3);  // [2, 4, 6]

// Java 가변 인자와 비교
// Java: public void log(String... messages) {}
// JS:   function log(...messages) {}
```

## 5.10 향상된 객체 리터럴

```javascript
const name = "Alice";
const age = 25;

const user = {
  // 단축 속성
  name,
  age,

  // 메서드 단축
  greet() {
    return `안녕, ${this.name}!`;
  },

  // 계산된 속성명
  [`user_${name}`]: true,

  // Getter/Setter
  get info() {
    return `${this.name} (${this.age})`;
  },

  set info(value) {
    const [name, age] = value.split(",");
    this.name = name.trim();
    this.age = parseInt(age.trim());
  }
};

console.log(user.info);  // Alice (25)
user.info = "Bob, 30";
console.log(user.name);  // Bob
```

### 예제 4: 유틸리티 함수

```javascript
// 객체 병합 (깊은 병합)
function deepMerge(target, source) {
  const result = { ...target };

  for (const key in source) {
    if (source[key] instanceof Object && key in target) {
      result[key] = deepMerge(target[key], source[key]);
    } else {
      result[key] = source[key];
    }
  }

  return result;
}

// 객체 pick (특정 속성만 선택)
function pick(obj, keys) {
  return keys.reduce((acc, key) => {
    if (key in obj) {
      acc[key] = obj[key];
    }
    return acc;
  }, {});
}

const user = { id: 1, name: "Alice", age: 25, email: "alice@example.com" };
const picked = pick(user, ["name", "email"]);
// { name: 'Alice', email: 'alice@example.com' }

// 객체 omit (특정 속성 제외)
function omit(obj, keys) {
  const { [keys[0]]: _, ...rest } = obj;
  return keys.length > 1 ? omit(rest, keys.slice(1)) : rest;
}

const omitted = omit(user, ["age", "email"]);
// { id: 1, name: 'Alice' }
```

## 핵심 요약

### 꼭 기억할 것

1. **let/const**
   - `const` 기본 사용
   - 변경 필요 시 `let`
   - `var` 절대 사용 금지

2. **템플릿 리터럴**
   - 백틱 `` ` `` 사용
   - `${expression}` 으로 삽입

3. **구조 분해**
   - 배열: `const [a, b] = arr`
   - 객체: `const { x, y } = obj`

4. **전개 연산자**
   - 배열: `[...arr1, ...arr2]`
   - 객체: `{ ...obj1, ...obj2 }`

5. **화살표 함수**
   - `const fn = () => {}`
   - 간결하고 this 바인딩 안정적
