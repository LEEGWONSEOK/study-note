# Chapter 6. 배열과 객체

## 6.1 배열 (Array)

> 🎯 **핵심**: JavaScript의 배열은 **유연한 컨테이너**입니다.
> - Java와 달리 크기 고정 불필요
> - 다양한 타입 혼합 가능 (권장하진 않음)
> - 강력한 내장 메서드 제공

### 배열 생성

```javascript
// 리터럴 방식 (권장!)
const numbers = [1, 2, 3, 4, 5];
const fruits = ["사과", "바나나", "오렌지"];

// 생성자 방식 (비권장)
const arr1 = new Array(5);        // [empty × 5]
const arr2 = new Array(1, 2, 3);  // [1, 2, 3]

// 빈 배열
const empty = [];

// 다양한 타입 혼합 (비권장)
const mixed = [1, "hello", true, null, { name: "홍길동" }];
```

**비유**: 배열은 **기차 칸**입니다.
- 각 칸에는 번호(인덱스)가 있음
- 칸 수는 자유롭게 늘리거나 줄일 수 있음

**Java와 비교**:
```java
// Java - 타입과 크기 고정
int[] numbers = new int[5];
numbers[0] = 1;
numbers[5] = 6;  // ❌ ArrayIndexOutOfBoundsException

String[] fruits = {"사과", "바나나", "오렌지"};
fruits[0] = 123;  // ❌ 타입 에러

// JavaScript - 유연함
const numbers = [];
numbers[0] = 1;
numbers[5] = 6;  // ✅ 가능 (중간은 empty)
console.log(numbers);  // [1, empty × 4, 6]

const fruits = ["사과", "바나나", "오렌지"];
fruits[0] = 123;  // ✅ 가능 (권장하진 않음)
```

### 배열 접근 및 수정

```javascript
const fruits = ["사과", "바나나", "오렌지"];

// 접근
console.log(fruits[0]);     // "사과"
console.log(fruits[2]);     // "오렌지"
console.log(fruits[10]);    // undefined (에러 아님!)

fruits[1] = "딸기";
console.log(fruits);  // ["사과", "딸기", "오렌지"]

// 길이
console.log(fruits.length);  // 3

// 마지막 요소
console.log(fruits[fruits.length - 1]);  // "오렌지"
console.log(fruits.at(-1));  // "오렌지" (ES2022)
```

### 배열 메서드 - 추가/삭제

```javascript
const arr = [1, 2, 3];

// push - 끝에 추가 (원본 변경)
arr.push(4);
console.log(arr);  // [1, 2, 3, 4]

// pop - 끝에서 제거 (원본 변경)
const last = arr.pop();
console.log(last);  // 4
console.log(arr);   // [1, 2, 3]

// unshift - 앞에 추가 (원본 변경)
arr.unshift(0);
console.log(arr);  // [0, 1, 2, 3]

// shift - 앞에서 제거 (원본 변경)
const first = arr.shift();
console.log(first);  // 0
console.log(arr);    // [1, 2, 3]
```

**비유**:
- `push`/`pop`: 끝 칸에 붙이기/떼기 (빠름)
- `unshift`/`shift`: 앞 칸에 붙이기/떼기 (느림, 모든 칸이 이동)

### 배열 메서드 - 변환 (원본 불변)

```javascript
const numbers = [1, 2, 3, 4, 5];

// map - 각 요소 변환
const doubled = numbers.map(n => n * 2);
console.log(doubled);  // [2, 4, 6, 8, 10]

// filter - 조건 필터링
const even = numbers.filter(n => n % 2 === 0);
console.log(even);  // [2, 4]

// reduce - 하나의 값으로 축약
const sum = numbers.reduce((acc, n) => acc + n, 0);
console.log(sum);  // 15

// find - 첫 번째 일치 요소
const found = numbers.find(n => n > 3);
console.log(found);  // 4

// findIndex - 첫 번째 일치 인덱스
const index = numbers.findIndex(n => n > 3);
console.log(index);  // 3

// some - 하나라도 만족?
const hasEven = numbers.some(n => n % 2 === 0);
console.log(hasEven);  // true

// every - 모두 만족?
const allPositive = numbers.every(n => n > 0);
console.log(allPositive);  // true
```

**Java와 비교**:
```java
// Java Stream API
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// map
List<Integer> doubled = numbers.stream()
    .map(n -> n * 2)
    .collect(Collectors.toList());

// filter
List<Integer> even = numbers.stream()
    .filter(n -> n % 2 == 0)
    .collect(Collectors.toList());

// reduce
int sum = numbers.stream()
    .reduce(0, (a, b) -> a + b);

// JavaScript는 더 간결!
const doubled = numbers.map(n => n * 2);
const even = numbers.filter(n => n % 2 === 0);
const sum = numbers.reduce((a, b) => a + b, 0);
```

### 배열 메서드 - 정렬/검색

```javascript
const numbers = [3, 1, 4, 1, 5, 9, 2, 6];

// sort - 정렬 (원본 변경!)
numbers.sort((a, b) => a - b);  // 오름차순
console.log(numbers);  // [1, 1, 2, 3, 4, 5, 6, 9]

numbers.sort((a, b) => b - a);  // 내림차순
console.log(numbers);  // [9, 6, 5, 4, 3, 2, 1, 1]

// reverse - 역순 (원본 변경!)
numbers.reverse();
console.log(numbers);  // [1, 1, 2, 3, 4, 5, 6, 9]

// slice - 부분 배열 (원본 불변)
const sliced = numbers.slice(2, 5);
console.log(sliced);  // [2, 3, 4]

// splice - 요소 삭제/추가 (원본 변경!)
const arr = [1, 2, 3, 4, 5];
arr.splice(2, 1);  // 인덱스 2부터 1개 삭제
console.log(arr);  // [1, 2, 4, 5]

arr.splice(2, 0, 3);  // 인덱스 2에 3 추가
console.log(arr);  // [1, 2, 3, 4, 5]

// includes - 포함 여부 (ES2016)
console.log(numbers.includes(3));  // true
console.log(numbers.includes(10));  // false

// indexOf / lastIndexOf
console.log(numbers.indexOf(1));  // 0 (첫 번째 위치)
console.log(numbers.lastIndexOf(1));  // 1 (마지막 위치)
```

**⚠️ 주의**: `sort()` 기본 동작은 문자열 정렬!
```javascript
const numbers = [1, 10, 2, 20];

// ❌ 잘못된 방법
numbers.sort();
console.log(numbers);  // [1, 10, 2, 20] (문자열로 정렬됨!)

// ✅ 올바른 방법
numbers.sort((a, b) => a - b);
console.log(numbers);  // [1, 2, 10, 20]
```

### 배열 메서드 - 결합/평탄화

```javascript
// concat - 배열 결합 (원본 불변)
const arr1 = [1, 2];
const arr2 = [3, 4];
const combined = arr1.concat(arr2);
console.log(combined);  // [1, 2, 3, 4]

// 스프레드 연산자 (권장!)
const combined2 = [...arr1, ...arr2];
console.log(combined2);  // [1, 2, 3, 4]

// join - 문자열로 결합
const words = ["Hello", "World"];
console.log(words.join(" "));   // "Hello World"
console.log(words.join("-"));   // "Hello-World"

// flat - 중첩 배열 평탄화 (ES2019)
const nested = [1, [2, 3], [4, [5, 6]]];
console.log(nested.flat());     // [1, 2, 3, 4, [5, 6]]
console.log(nested.flat(2));    // [1, 2, 3, 4, 5, 6]
console.log(nested.flat(Infinity));  // 완전 평탄화

// flatMap - map + flat (ES2019)
const sentences = ["Hello World", "Foo Bar"];
const words2 = sentences.flatMap(s => s.split(" "));
console.log(words2);  // ["Hello", "World", "Foo", "Bar"]
```

### 배열 순회

```javascript
const fruits = ["사과", "바나나", "오렌지"];

// 1. for 루프 (전통적)
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// 2. for...of (권장!)
for (const fruit of fruits) {
  console.log(fruit);
}

// 3. forEach (함수형)
fruits.forEach((fruit, index) => {
  console.log(`${index}: ${fruit}`);
});

// 4. for...in (비권장! 객체용)
for (const index in fruits) {
  console.log(fruits[index]);  // 프로토타입 속성도 순회됨
}
```

**비유**: 배열 순회는 **기차 칸 검표**
- `for`: 칸 번호로 직접 찾아감
- `for...of`: 칸을 순서대로 방문
- `forEach`: 각 칸마다 함수 실행

### 배열 구조 분해 (Destructuring)

```javascript
const numbers = [1, 2, 3, 4, 5];

// 기본 구조 분해
const [first, second] = numbers;
console.log(first);   // 1
console.log(second);  // 2

// 나머지 요소
const [a, b, ...rest] = numbers;
console.log(a);     // 1
console.log(b);     // 2
console.log(rest);  // [3, 4, 5]

// 건너뛰기
const [x, , z] = numbers;
console.log(x);  // 1
console.log(z);  // 3

// 기본값
const [p, q, r = 0] = [1, 2];
console.log(r);  // 0

// 값 교환
let num1 = 10;
let num2 = 20;
[num1, num2] = [num2, num1];
console.log(num1, num2);  // 20 10
```

**Java와 비교**:
```java
// Java - 불가능 (변수별로 개별 할당 필요)
int[] numbers = {1, 2, 3, 4, 5};
int first = numbers[0];
int second = numbers[1];

// JavaScript - 간편!
const [first, second] = numbers;
```

## 6.2 객체 (Object)

> 🎯 **핵심**: JavaScript의 객체는 **키-값 저장소**입니다.
> - Java의 HashMap과 유사하지만 더 유연
> - 동적으로 속성 추가/삭제 가능
> - 메서드도 속성으로 저장 가능

### 객체 생성

```javascript
// 리터럴 방식 (권장!)
const person = {
  name: "홍길동",
  age: 25,
  job: "개발자"
};

// 생성자 방식 (비권장)
const person2 = new Object();
person2.name = "홍길동";
person2.age = 25;

// 빈 객체
const empty = {};

// 동적 키
const key = "email";
const user = {
  name: "홍길동",
  [key]: "hong@example.com",  // 계산된 속성명
  [`${key}_verified`]: true
};
console.log(user);  // { name: "홍길동", email: "hong@...", email_verified: true }
```

**비유**: 객체는 **사물함**입니다.
- 각 칸에는 라벨(키)이 붙어 있음
- 라벨로 내용물(값)을 찾음

**Java와 비교**:
```java
// Java - 클래스 필요
public class Person {
    private String name;
    private int age;
    private String job;

    // 생성자, getter, setter 필요...
}
Person person = new Person("홍길동", 25, "개발자");

// 또는 HashMap
Map<String, Object> person = new HashMap<>();
person.put("name", "홍길동");
person.put("age", 25);
person.put("job", "개발자");

// JavaScript - 간단!
const person = {
  name: "홍길동",
  age: 25,
  job: "개발자"
};
```

### 객체 접근 및 수정

```javascript
const person = {
  name: "홍길동",
  age: 25,
  job: "개발자"
};

// 점 표기법 (권장)
console.log(person.name);  // "홍길동"
person.age = 26;

// 대괄호 표기법 (동적 키)
console.log(person["name"]);  // "홍길동"
const key = "job";
console.log(person[key]);  // "개발자"

// 속성 추가
person.email = "hong@example.com";
console.log(person);  // { name: "홍길동", age: 26, job: "개발자", email: "..." }

// 속성 삭제
delete person.job;
console.log(person);  // { name: "홍길동", age: 26, email: "..." }

// 속성 존재 확인
console.log("name" in person);  // true
console.log("job" in person);   // false
console.log(person.hasOwnProperty("name"));  // true
```

### 메서드 (Method)

```javascript
const person = {
  name: "홍길동",
  age: 25,

  // 메서드 (전통적)
  greet: function() {
    return `안녕하세요, ${this.name}입니다.`;
  },

  // 메서드 축약 (ES6)
  introduce() {
    return `제 이름은 ${this.name}이고, ${this.age}살입니다.`;
  },

  // 화살표 함수 (this 주의!)
  greet2: () => {
    return `안녕하세요, ${this.name}입니다.`;  // ⚠️ this가 다름!
  }
};

console.log(person.greet());       // "안녕하세요, 홍길동입니다."
console.log(person.introduce());   // "제 이름은 홍길동이고, 25살입니다."
console.log(person.greet2());      // "안녕하세요, undefined입니다." (this 다름!)
```

**⚠️ 중요**: 화살표 함수는 `this`를 바인딩하지 않습니다!
```javascript
const obj = {
  value: 42,

  // ✅ 일반 함수 - this는 obj
  getValue: function() {
    return this.value;
  },

  // ❌ 화살표 함수 - this는 외부 스코프
  getValue2: () => {
    return this.value;  // undefined
  }
};

console.log(obj.getValue());   // 42
console.log(obj.getValue2());  // undefined
```

### 객체 메서드

```javascript
const person = {
  name: "홍길동",
  age: 25,
  job: "개발자"
};

// Object.keys() - 키 배열
console.log(Object.keys(person));  // ["name", "age", "job"]

// Object.values() - 값 배열
console.log(Object.values(person));  // ["홍길동", 25, "개발자"]

// Object.entries() - [키, 값] 배열
console.log(Object.entries(person));
// [["name", "홍길동"], ["age", 25], ["job", "개발자"]]

// Object.fromEntries() - 배열을 객체로
const entries = [["name", "홍길동"], ["age", 25]];
const obj = Object.fromEntries(entries);
console.log(obj);  // { name: "홍길동", age: 25 }

// Object.assign() - 객체 병합
const target = { a: 1 };
const source = { b: 2, c: 3 };
Object.assign(target, source);
console.log(target);  // { a: 1, b: 2, c: 3 }

// 스프레드 연산자 (권장!)
const obj1 = { a: 1 };
const obj2 = { b: 2, c: 3 };
const merged = { ...obj1, ...obj2 };
console.log(merged);  // { a: 1, b: 2, c: 3 }
```

### 객체 순회

```javascript
const person = {
  name: "홍길동",
  age: 25,
  job: "개발자"
};

// 1. for...in (키 순회)
for (const key in person) {
  console.log(`${key}: ${person[key]}`);

// 3. Object.entries() + for...of (권장!)
for (const [key, value] of Object.entries(person)) {

}

// 4. Object.entries() + forEach
Object.entries(person).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});
```

### 객체 구조 분해 (Destructuring)

## 6.3 배열과 객체 조합

### 객체 배열

```javascript
const users = [
  { id: 1, name: "홍길동", age: 25 },
  { id: 2, name: "김철수", age: 30 },
  { id: 3, name: "이영희", age: 28 }
];

// map - 이름만 추출
const names = users.map(user => user.name);
console.log(names);  // ["홍길동", "김철수", "이영희"]

// filter - 나이 조건
const adults = users.filter(user => user.age >= 28);
console.log(adults);  // [{ id: 2, ... }, { id: 3, ... }]

// find - ID로 찾기
const user = users.find(user => user.id === 2);
console.log(user);  // { id: 2, name: "김철수", age: 30 }

// reduce - 평균 나이
const avgAge = users.reduce((sum, user) => sum + user.age, 0) / users.length;
console.log(avgAge);  // 27.67

// sort - 나이순 정렬
const sorted = [...users].sort((a, b) => a.age - b.age);
console.log(sorted);  // [{ id: 1, ... }, { id: 3, ... }, { id: 2, ... }]
```

### 그룹화

```javascript
const products = [
  { id: 1, name: "노트북", category: "전자제품", price: 1000 },
  { id: 2, name: "마우스", category: "전자제품", price: 20 },
  { id: 3, name: "책상", category: "가구", price: 200 },
  { id: 4, name: "의자", category: "가구", price: 150 }
];

// 카테고리별 그룹화
const grouped = products.reduce((acc, product) => {
  const { category } = product;
  if (!acc[category]) {
    acc[category] = [];
  }
  acc[category].push(product);
  return acc;
}, {});

console.log(grouped);
// {
//   전자제품: [{ id: 1, ... }, { id: 2, ... }],
//   가구: [{ id: 3, ... }, { id: 4, ... }]
// }

// Object.groupBy (ES2024, 최신)
const grouped2 = Object.groupBy(products, product => product.category);
```

### 배열 복사

```javascript
const original = [1, 2, 3];

// ❌ 참조 복사 (같은 배열)
const copy1 = original;
copy1.push(4);
console.log(original);  // [1, 2, 3, 4] (원본도 변경!)

// ✅ 얕은 복사 (새 배열)
const copy2 = [...original];
const copy3 = original.slice();
const copy4 = Array.from(original);

copy2.push(5);
console.log(original);  // [1, 2, 3, 4] (원본 그대로)
console.log(copy2);     // [1, 2, 3, 4, 5]

// ⚠️ 중첩 배열은 얕은 복사만 됨
const nested = [[1, 2], [3, 4]];
const shallowCopy = [...nested];
shallowCopy[0].push(3);
console.log(nested);  // [[1, 2, 3], [3, 4]] (원본도 변경!)

// ✅ 깊은 복사
const deepCopy = JSON.parse(JSON.stringify(nested));
// 또는 structuredClone (최신)
const deepCopy2 = structuredClone(nested);
```
