# Chapter 11. 객체와 프로토타입

## 11.1 JavaScript의 객체 지향

> 🎯 **핵심**: JavaScript는 **프로토타입 기반** 객체 지향 언어입니다.
> - 클래스 기반이 아님 (ES6 class는 문법 설탕)
> - 모든 객체는 다른 객체를 상속
> - 동적으로 속성/메서드 추가 가능

**비유**: 프로토타입은 **유전자**입니다.
- 부모의 특성을 자식이 물려받음
- 자식은 고유한 특성도 가질 수 있음
- 부모의 특성을 변경하면 모든 자식에 영향

**Java와 비교**:
```java
// Java - 클래스 기반
public class Animal {
    private String name;

    public Animal(String name) {
        this.name = name;
    }

    public void speak() {
        System.out.println(name + " makes a sound");
    }
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }

    @Override
    public void speak() {
        System.out.println(getName() + " barks");
    }
}

// JavaScript - 프로토타입 기반 (ES5)
function Animal(name) {
    this.name = name;
}

Animal.prototype.speak = function() {
    console.log(this.name + ' makes a sound');
};

function Dog(name) {
    Animal.call(this, name);
}

Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

Dog.prototype.speak = function() {
    console.log(this.name + ' barks');
};
```

## 11.2 프로토타입이란?

### 기본 개념

```javascript
// 모든 객체는 프로토타입을 가짐
const obj = {};
console.log(obj.__proto__);  // Object.prototype

// 함수도 객체
function fn() {}
console.log(fn.__proto__);  // Function.prototype

// 배열도 객체
const arr = [];
console.log(arr.__proto__);  // Array.prototype
```

**프로토타입 체인**:
```
obj → Object.prototype → null
arr → Array.prototype → Object.prototype → null
fn → Function.prototype → Object.prototype → null
```

---

### 프로토타입 확인

```javascript
const person = {
    name: '홍길동',
    greet() {
        console.log(`안녕, ${this.name}`);
    }
};

// 프로토타입 접근
console.log(Object.getPrototypeOf(person));  // Object.prototype (권장)
console.log(person.__proto__);  // Object.prototype (비권장, 레거시)

// 프로토타입 확인
console.log(Object.getPrototypeOf(person) === Object.prototype);  // true

// 속성 확인
console.log(person.hasOwnProperty('name'));  // true (자신의 속성)
console.log(person.hasOwnProperty('toString'));  // false (프로토타입 속성)
console.log('toString' in person);  // true (프로토타입 포함)
```

## 11.3 생성자 함수

### 기본 사용법

```javascript
// 생성자 함수 (관례: 대문자 시작)
function Person(name, age) {
    this.name = name;
    this.age = age;
}

// 프로토타입에 메서드 추가
Person.prototype.greet = function() {
    console.log(`안녕하세요, ${this.name}입니다.`);
};

Person.prototype.getAge = function() {
    return this.age;
};

// 인스턴스 생성
const person1 = new Person('홍길동', 25);
const person2 = new Person('김철수', 30);

person1.greet();  // "안녕하세요, 홍길동입니다."
person2.greet();  // "안녕하세요, 김철수입니다."

// 프로토타입 메서드는 공유됨
console.log(person1.greet === person2.greet);  // true
```

### new 없이 호출하면?

```javascript
function Person(name) {
    this.name = name;
}

// ❌ new 없이 호출
const person = Person('홍길동');
console.log(person);  // undefined
console.log(window.name);  // '홍길동' (전역 객체 오염!)

// ✅ new 강제하는 패턴
function Person(name) {
    if (!(this instanceof Person)) {
        return new Person(name);
    }
    this.name = name;
}

const person1 = Person('홍길동');  // new 없어도 작동
const person2 = new Person('김철수');
```

## 11.4 프로토타입 상속

### 기본 상속

```javascript
// 부모 생성자
function Animal(name) {
    this.name = name;
}

Animal.prototype.eat = function() {
    console.log(`${this.name}이(가) 먹습니다.`);
};

Animal.prototype.sleep = function() {
    console.log(`${this.name}이(가) 잡니다.`);
};

// 자식 생성자
function Dog(name, breed) {
    // 부모 생성자 호출
    Animal.call(this, name);
    this.breed = breed;
}

// 프로토타입 체인 설정
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

// 자식 메서드 추가
Dog.prototype.bark = function() {
    console.log(`${this.name}이(가) 짖습니다: 멍멍!`);
};

// 메서드 오버라이딩
Dog.prototype.eat = function() {
    console.log(`${this.name}이(가) 사료를 먹습니다.`);
};

// 사용
const dog = new Dog('바둑이', '진돗개');
dog.eat();    // "바둑이이(가) 사료를 먹습니다."
dog.sleep();  // "바둑이이(가) 잡니다." (부모 메서드)
dog.bark();   // "바둑이이(가) 짖습니다: 멍멍!" (자식 메서드)
```

---

### 프로토타입 체인

```javascript
console.log(dog.name);  // "바둑이"

// 속성 조회 순서:
// 1. dog 객체 자신 → name 발견!
// 2. (발견 못하면) Dog.prototype
// 3. (발견 못하면) Animal.prototype
// 4. (발견 못하면) Object.prototype
// 5. (발견 못하면) undefined

// 프로토타입 체인 확인
console.log(dog instanceof Dog);     // true
console.log(dog instanceof Animal);  // true
console.log(dog instanceof Object);  // true

console.log(Object.getPrototypeOf(dog) === Dog.prototype);  // true
console.log(Object.getPrototypeOf(Dog.prototype) === Animal.prototype);  // true
```

## 11.5 Object.create()

### 프로토타입 상속의 다른 방법

```javascript
const animal = {
    type: 'animal',
    eat() {
        console.log(`${this.name}이(가) 먹습니다.`);
    }
};

// animal을 프로토타입으로 하는 새 객체 생성
const dog = Object.create(animal);
dog.name = '바둑이';
dog.bark = function() {
    console.log('멍멍!');
};

dog.eat();   // "바둑이이(가) 먹습니다." (프로토타입 메서드)
dog.bark();  // "멍멍!" (자신의 메서드)

console.log(dog.type);  // "animal" (프로토타입 속성)
```

### 속성 설명자와 함께 사용

```javascript
const person = Object.create(Object.prototype, {
    name: {
        value: '홍길동',
        writable: true,
        enumerable: true,
        configurable: true
    },
    age: {
        value: 25,
        writable: true,
        enumerable: true,
        configurable: true
    },
    greet: {
        value: function() {
            console.log(`안녕, ${this.name}`);
        },
        writable: true,
        enumerable: false,  // for...in에서 제외
        configurable: true
    }
});

console.log(person.name);  // "홍길동"
person.greet();  // "안녕, 홍길동"

for (const key in person) {
    console.log(key);  // "name", "age" (greet는 제외)
}
```

## 11.6 프로토타입 메서드 vs 인스턴스 메서드

```javascript
function Person(name) {
    this.name = name;

    // ❌ 인스턴스 메서드 (비효율적)
    this.greet = function() {
        console.log(`안녕, ${this.name}`);
    };
}

// 각 인스턴스마다 메서드 복사 (메모리 낭비)
const p1 = new Person('홍길동');
const p2 = new Person('김철수');
console.log(p1.greet === p2.greet);  // false

// ✅ 프로토타입 메서드 (효율적)
function Person(name) {
    this.name = name;
}

Person.prototype.greet = function() {
    console.log(`안녕, ${this.name}`);
};

// 모든 인스턴스가 메서드 공유
const p1 = new Person('홍길동');
const p2 = new Person('김철수');
console.log(p1.greet === p2.greet);  // true
```

**비유**:
- 인스턴스 메서드: 각자 도구 보관함 (중복, 낭비)
- 프로토타입 메서드: 공용 도구 창고 (공유, 효율적)

## 11.7 내장 객체 프로토타입

### Array.prototype 확장 (비권장!)

```javascript
// ⚠️ 내장 프로토타입 수정은 위험!
Array.prototype.last = function() {
    return this[this.length - 1];
};

const arr = [1, 2, 3, 4, 5];
console.log(arr.last());  // 5

// 문제점:
// 1. 다른 라이브러리와 충돌 가능
// 2. 미래 JavaScript 표준과 충돌 가능
// 3. for...in 순회에 나타남

for (const key in arr) {
    console.log(key);  // 0, 1, 2, 3, 4, "last" (혼란!)
}
```

---

### 안전한 확장 방법

```javascript
// ✅ 유틸리티 함수로 작성
function last(arr) {
    return arr[arr.length - 1];
}

console.log(last([1, 2, 3]));  // 3

// ✅ 또는 클래스 상속
class MyArray extends Array {
    last() {
        return this[this.length - 1];
    }
}

const arr = new MyArray(1, 2, 3);
console.log(arr.last());  // 3
```

## 11.8 프로토타입 패턴

### Mixin 패턴

```javascript
// Mixin 객체들
const canEat = {
    eat() {
        console.log(`${this.name}이(가) 먹습니다.`);
    }
};

const canWalk = {
    walk() {
        console.log(`${this.name}이(가) 걷습니다.`);
    }
};

const canSwim = {
    swim() {
        console.log(`${this.name}이(가) 수영합니다.`);
    }
};

// Mixin 함수
function mixin(target, ...sources) {
    Object.assign(target, ...sources);
}

// 사용
function Person(name) {
    this.name = name;
}

mixin(Person.prototype, canEat, canWalk);

const person = new Person('홍길동');
person.eat();   // "홍길동이(가) 먹습니다."
person.walk();  // "홍길동이(가) 걷습니다."
// person.swim();  // 에러! (추가 안 됨)

// Duck (오리는 수영도 가능)
function Duck(name) {
    this.name = name;
}

mixin(Duck.prototype, canEat, canWalk, canSwim);

const duck = new Duck('도날드');
duck.eat();   // "도날드이(가) 먹습니다."
duck.walk();  // "도날드이(가) 걷습니다."
duck.swim();  // "도날드이(가) 수영합니다."
```

## 11.9 실전 예제

### 이벤트 에미터 구현

```javascript
function EventEmitter() {
    this.events = {};
}

EventEmitter.prototype.on = function(event, listener) {
    if (!this.events[event]) {
        this.events[event] = [];
    }
    this.events[event].push(listener);
};

EventEmitter.prototype.emit = function(event, ...args) {
    if (this.events[event]) {
        this.events[event].forEach(listener => {
            listener.apply(this, args);
        });
    }
};

EventEmitter.prototype.off = function(event, listenerToRemove) {
    if (this.events[event]) {
        this.events[event] = this.events[event].filter(
            listener => listener !== listenerToRemove
        );
    }
};

// 사용
const emitter = new EventEmitter();

function onUserLogin(user) {
    console.log(`${user.name} 로그인!`);
}

emitter.on('login', onUserLogin);
emitter.on('login', (user) => {
    console.log(`환영합니다, ${user.name}님!`);
});

emitter.emit('login', { name: '홍길동' });
// "홍길동 로그인!"
// "환영합니다, 홍길동님!"

emitter.off('login', onUserLogin);
emitter.emit('login', { name: '김철수' });
// "환영합니다, 김철수님!" (첫 번째 리스너는 제거됨)
```

### 캐시 객체

```javascript
function Cache() {
    this.data = {};
}

Cache.prototype.set = function(key, value, ttl = 60000) {
    this.data[key] = {
        value,
        expiry: Date.now() + ttl
    };
};

Cache.prototype.get = function(key) {
    const item = this.data[key];

    if (!item) {
        return null;
    }

    if (Date.now() > item.expiry) {
        delete this.data[key];
        return null;
    }

    return item.value;
};

Cache.prototype.has = function(key) {
    return this.get(key) !== null;
};

Cache.prototype.clear = function() {
    this.data = {};
};

// 사용
const cache = new Cache();

cache.set('user:1', { name: '홍길동' }, 5000);  // 5초 TTL
console.log(cache.get('user:1'));  // { name: '홍길동' }

setTimeout(() => {
    console.log(cache.get('user:1'));  // null (만료됨)
}, 6000);
```

## 📝 핵심 요약

1. **프로토타입**: 객체 상속의 메커니즘
   - 모든 객체는 프로토타입을 가짐
   - 프로토타입 체인으로 속성/메서드 조회

2. **생성자 함수**: 객체 생성 패턴
   - new 키워드와 함께 사용
   - prototype에 메서드 추가 (공유)

3. **상속**: Object.create() 또는 프로토타입 체인
   - 부모의 속성/메서드 물려받기
   - 메서드 오버라이딩 가능

4. **패턴**:
   - Mixin: 여러 기능 조합
   - Factory: 객체 생성 간소화

5. **주의사항**:
   - 내장 프로토타입 수정 금지
   - 프로토타입 메서드 사용 (메모리 효율)

// 3. Observable
function Observable(value) {
    this._value = value;
    this.listeners = [];
}

Observable.prototype.get = function() {
    return this._value;
};

Observable.prototype.set = function(value) {
    const oldValue = this._value;
    this._value = value;

    this.listeners.forEach(listener => {
        listener(value, oldValue);
    });
};

Observable.prototype.subscribe = function(listener) {
    this.listeners.push(listener);

    // 구독 취소 함수 반환
    return () => {
        this.listeners = this.listeners.filter(l => l !== listener);
    };
};

// 사용
const count = new Observable(0);

const unsubscribe = count.subscribe((newVal, oldVal) => {
    console.log(`값 변경: ${oldVal} → ${newVal}`);
});

count.set(1);  // "값 변경: 0 → 1"
count.set(2);  // "값 변경: 1 → 2"

unsubscribe();  // 구독 취소
count.set(3);  // 출력 없음
