# Chapter 5. 제어 흐름

## 5.1 if 문

> 🚦 **비유**: if문은 **갈림길**입니다.
> - 조건이 참이면 왼쪽 길
> - 거짓이면 오른쪽 길

### 기본 if-else

```python
age = 20

if age >= 18:
    print("성인입니다")
else:
    print("미성년자입니다")
```

**Java와 비교**:
```java
// Java - 괄호와 중괄호 필요
if (age >= 18) {
    System.out.println("성인입니다");
} else {
    System.out.println("미성년자입니다");
}

// Python - 들여쓰기만 있으면 됨
if age >= 18:
    print("성인입니다")
else:
    print("미성년자입니다")
```

---

### if-elif-else

> 🎰 **비유**: elif는 **자판기 버튼**입니다.
> - 첫 번째 버튼(if)부터 차례로 확인
> - 처음 맞는 버튼 하나만 실행
> - 다 안 맞으면 else

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"학점: {grade}")
```

**실생활 예시 - 요금 계산**:
```python
age = int(input("나이를 입력하세요: "))

if age < 7:
    price = 0
    category = "미취학아동 (무료)"
elif age < 13:
    price = 5000
    category = "어린이"
elif age < 19:
    price = 8000
    category = "청소년"
elif age < 65:
    price = 10000
    category = "성인"
else:
    price = 5000
    category = "경로우대"

print(f"{category}: {price:,}원")
```

### 조건 표현식 (Ternary Operator)

> 💡 **비유**: 조건 표현식은 **한 줄 if문**입니다.
> - 간단한 조건에만 사용
> - 가독성이 중요!

```python
# 기본 형태
age = 20
status = "성인" if age >= 18 else "미성년자"

# 여러 줄 if문
if age >= 18:
    status = "성인"
else:
    status = "미성년자"
```

**Java와 비교**:
```java
// Java
String status = (age >= 18) ? "성인" : "미성년자";

// Python
status = "성인" if age >= 18 else "미성년자"
```

**실전 활용**:
```python
# 절댓값 구하기
num = -5
abs_num = num if num >= 0 else -num

# 최댓값/최솟값
a, b = 10, 20
max_val = a if a > b else b
min_val = a if a < b else b

# 기본값 설정
name = input("이름: ")
display_name = name if name else "익명"

# 리스트에서 사용
numbers = [1, -2, 3, -4, 5]
positives = [n if n > 0 else 0 for n in numbers]
print(positives)  # [1, 0, 3, 0, 5]
```

### 중첩 if문

```python
# 로그인 검증
username = "alice"
password = "1234"
is_admin = True

if username == "alice":
    if password == "1234":

# ✅ 더 좋은 방법: and 사용

    if is_admin:
        print("관리자로 로그인")
    else:
        print("일반 사용자로 로그인")
else:
    print("로그인 실패")
```

## 5.2 for 루프

> 🔄 **비유**: for문은 **컨베이어 벨트**입니다.
> - 물건(요소)이 하나씩 나옴
> - 각 물건마다 작업 수행

### 기본 for문

```python
# 리스트 순회
fruits = ["사과", "바나나", "체리"]
for fruit in fruits:
    print(fruit)

# 문자열 순회
for char in "Python":
    print(char)

# range() 사용
for i in range(5):  # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):  # 1, 2, 3, 4, 5
    print(i)

for i in range(0, 10, 2):  # 0, 2, 4, 6, 8 (2씩 증가)
    print(i)
```

**Java와 비교**:
```java
// Java - 인덱스 기반
String[] fruits = {"사과", "바나나", "체리"};
for (int i = 0; i < fruits.length; i++) {
    System.out.println(fruits[i]);
}

// Java - for-each
for (String fruit : fruits) {
    System.out.println(fruit);
}

// Python - 더 간결
fruits = ["사과", "바나나", "체리"]
for fruit in fruits:
    print(fruit)
```

### enumerate()로 인덱스와 값 함께

> 📍 **비유**: enumerate는 **번호표 발급기**입니다.

```python
fruits = ["사과", "바나나", "체리"]

# ❌ 인덱스가 필요할 때 - 안 좋은 방법
for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")

# ✅ enumerate 사용
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

# 시작 번호 지정
for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")
```

**실생활 예시 - 순위 표시**:
```python
scores = [95, 88, 92, 87, 90]

print("=== 성적 순위 ===")
for rank, score in enumerate(sorted(scores, reverse=True), start=1):
    print(f"{rank}등: {score}점")

# 출력:
# 1등: 95점
# 2등: 92점
# 3등: 90점
# ...
```

### zip()으로 여러 리스트 동시 순회

> 🤐 **비유**: zip은 **지퍼**입니다.
> - 두 개 이상의 리스트를 묶어줌

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
cities = ["Seoul", "Busan", "Jeju"]

# 동시 순회
for name, age, city in zip(names, ages, cities):
    print(f"{name}({age}세)는 {city}에 살고 있습니다")

# 출력:
# Alice(25세)는 Seoul에 살고 있습니다
# Bob(30세)는 Busan에 살고 있습니다
# Charlie(35세)는 Jeju에 살고 있습니다
```

**실생활 예시 - 딕셔너리 생성**:
```python
keys = ["name", "age", "city"]
values = ["Alice", 25, "Seoul"]

# zip으로 딕셔너리 생성
user = dict(zip(keys, values))
print(user)
# {'name': 'Alice', 'age': 25, 'city': 'Seoul'}

# 두 리스트 요소별 합
a = [1, 2, 3]
b = [10, 20, 30]
result = [x + y for x, y in zip(a, b)]
print(result)  # [11, 22, 33]
```

### 딕셔너리 순회

```python
user = {
    "name": "Alice",
    "age": 30,
    "city": "Seoul"
}

# 키만 순회
for key in user:
    print(key)

# 값만 순회
for value in user.values():

# 키-값 쌍 순회 (추천!)
for key, value in user.items():
    print(f"{key}: {value}")
```

```python
}

# 출력:
# host                 : localhost
# port                 : 8080
# debug                : True
# max_connections      : 100
```

## 5.3 while 루프

> ⏰ **비유**: while문은 **알람 시계**입니다.
> - 조건이 거짓이 될 때까지 계속 울림

### 기본 while문

```python
# 카운트다운
count = 5
while count > 0:
    print(count)
    count -= 1
print("발사!")

# 사용자 입력 받기
password = ""
while password != "1234":
    password = input("비밀번호: ")
print("로그인 성공!")
```

**실생활 예시 - 게임**:
```python
import random

# 숫자 맞추기 게임
answer = random.randint(1, 100)
attempts = 0

print("1부터 100 사이의 숫자를 맞춰보세요!")

while True:
    guess = int(input("예상: "))
    attempts += 1

    if guess < answer:
        print("더 큰 숫자입니다")
    elif guess > answer:
        print("더 작은 숫자입니다")
    else:
        print(f"정답! {attempts}번 만에 맞췄습니다!")
        break
```

### 무한 루프

```python
# ⚠️ 무한 루프 (Ctrl+C로 중단)
```

## 5.4 break, continue, pass

> 🎮 **비유**: 루프 제어는 **게임 컨트롤러**입니다.
> - **break**: 게임 종료 (루프 탈출)
> - **continue**: 스킵 (다음 반복으로)
> - **pass**: 아무것도 안 함 (자리 채우기)

### break - 루프 탈출

```python
# 특정 조건에서 중단
for i in range(10):
    if i == 5:
        break  # 5가 되면 중단
    print(i)
# 출력: 0 1 2 3 4

# 리스트에서 찾기
numbers = [1, 3, 5, 7, 9, 2, 4, 6]
target = 7

for num in numbers:
    if num == target:
        print(f"{target}을 찾았습니다!")
        break
else:  # break 없이 끝나면 실행
    print(f"{target}을 못 찾았습니다")
```

---

### continue - 다음 반복으로

```python
# 홀수만 출력
for i in range(10):
    if i % 2 == 0:
        continue  # 짝수면 스킵
    print(i)
# 출력: 1 3 5 7 9

# 특정 값 제외
fruits = ["사과", "바나나", "체리", "딸기"]
exclude = "바나나"

for fruit in fruits:
    if fruit == exclude:
        continue
    print(fruit)
# 출력: 사과 체리 딸기
```

**실생활 예시 - 유효성 검사**:
```python
# 양수만 처리
numbers = [10, -5, 3, -8, 15, 0, 7]
total = 0

for num in numbers:
    if num <= 0:
        continue  # 0이하는 스킵
    total += num

print(f"양수의 합: {total}")  # 35
```

### pass - 아무것도 안 함

> 📝 **비유**: pass는 **TODO 메모**입니다.
> - 나중에 채울 자리 표시

```python
# 아직 구현 안 된 함수
def future_function():
    pass  # TODO: 나중에 구현

# 빈 클래스
class EmptyClass:
    pass

# 조건문에서 사용
age = 20

if age < 18:
    pass  # TODO: 미성년자 처리
elif age >= 65:
    print("경로우대")
else:
    print("일반")
```

## 5.5 match-case (Python 3.10+)

> 🎯 **비유**: match-case는 **스위치 게임판**입니다.
> - 값에 따라 다른 케이스로 이동
> - Java의 switch와 유사하지만 더 강력

```python
# 기본 사용
command = "start"

match command:
    case "start":
        print("게임 시작")
    case "stop":
        print("게임 중지")
    case "pause":
        print("일시정지")
    case _:  # default
        print("알 수 없는 명령")
```

**Java와 비교**:
```java
// Java
switch (command) {
    case "start":
        System.out.println("게임 시작");
        break;
    case "stop":
        System.out.println("게임 중지");
        break;
    default:
        System.out.println("알 수 없는 명령");
}

// Python (더 강력함)
match command:
    case "start":
        print("게임 시작")
    case "stop":
        print("게임 중지")
    case _:
        print("알 수 없는 명령")
```

---

### 패턴 매칭

```python
# 리스트 패턴
point = [0, 0]

match point:
    case [0, 0]:
        print("원점")
    case [0, y]:
        print(f"Y축 위의 점: {y}")
    case [x, 0]:
        print(f"X축 위의 점: {x}")
    case [x, y]:
        print(f"점: ({x}, {y})")

# 튜플 패턴
status_code = 404

match status_code:
    case 200:
        print("성공")
    case 404:
        print("찾을 수 없음")
    case 500:
        print("서버 오류")
    case code if 400 <= code < 500:
        print(f"클라이언트 오류: {code}")
    case _:
        print("알 수 없는 상태")
```

**실생활 예시 - HTTP 응답 처리**:
```python
def handle_response(status, message):
    match status:
        case 200 | 201:  # OR 패턴
            print(f"성공: {message}")
        case 400:
            print(f"잘못된 요청: {message}")
        case 401 | 403:
            print(f"인증 오류: {message}")
        case 404:
            print(f"찾을 수 없음: {message}")
        case 500 | 502 | 503:
            print(f"서버 오류: {message}")
        case _:
            print(f"알 수 없는 상태 {status}: {message}")

handle_response(200, "데이터 조회 성공")
handle_response(404, "페이지를 찾을 수 없습니다")
```

## 실전 팁

### 💡 Tip 1: for-else와 while-else

```python
# for-else: break 없이 끝나면 else 실행
numbers = [1, 3, 5, 7, 9]
target = 4

for num in numbers:
    if num == target:
        print(f"{target}을 찾았습니다")
        break
else:  # break 없이 끝남
    print(f"{target}을 못 찾았습니다")

# while-else도 동일
attempts = 0
max_attempts = 3

while attempts < max_attempts:
    password = input("비밀번호: ")
    if password == "1234":
        print("로그인 성공")
        break
    attempts += 1
else:  # break 없이 끝남 (실패)
    print("로그인 실패 - 계정 잠김")
```

### 💡 Tip 2: 리스트 컴프리헨션으로 간결하게

```python
# ❌ 일반 for문
squares = []
for i in range(10):
    squares.append(i ** 2)

# ✅ 리스트 컴프리헨션
squares = [i ** 2 for i in range(10)]

# 조건 포함
even_squares = [i ** 2 for i in range(10) if i % 2 == 0]
```

### 💡 Tip 3: all()과 any() 활용

```python
# 모든 요소가 조건을 만족하는지
numbers = [2, 4, 6, 8]
print(all(n % 2 == 0 for n in numbers))  # True

# 하나라도 조건을 만족하는지
numbers = [1, 3, 5, 8]
print(any(n % 2 == 0 for n in numbers))  # True (8이 짝수)

# 실전: 모든 필드가 입력되었는지
form = {"name": "Alice", "age": 30, "email": ""}
if all(form.values()):
    print("모든 필드가 입력되었습니다")
else:
    print("빈 필드가 있습니다")
```
