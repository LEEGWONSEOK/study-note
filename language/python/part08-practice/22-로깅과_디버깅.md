## 1. 로깅이란?

### 1.1 print vs logging

**비유**:
- `print()`: 건물에서 **창문으로 소리 지르기** (임시, 제어 불가)
- `logging`: 건물의 **CCTV 시스템** (체계적, 제어 가능, 기록 보관)

```python
# ❌ print 사용 (안 좋은 예)
def process_order(order_id):
    print(f"Processing order {order_id}")  # 프로덕션에서 제거해야 함
    result = do_something(order_id)
    print(f"Result: {result}")  # 로그 레벨 조절 불가
    return result

# ✅ logging 사용 (좋은 예)
import logging

logger = logging.getLogger(__name__)

def process_order(order_id):
    logger.info(f"Processing order {order_id}")  # 레벨 조절 가능
    result = do_something(order_id)
    logger.debug(f"Result: {result}")  # 프로덕션에서 자동 숨김
    return result
```

### Java vs Python

**Java (SLF4J + Logback)**:
```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class OrderService {
    private static final Logger logger = LoggerFactory.getLogger(OrderService.class);

    public void processOrder(int orderId) {
        logger.info("Processing order {}", orderId);
        logger.debug("Debug information");
    }
}
```

**Python**:
```python
import logging

logger = logging.getLogger(__name__)

def process_order(order_id):
    logger.info(f"Processing order {order_id}")
    logger.debug("Debug information")
```

## 2. 로그 레벨

### 2.1 로그 레벨 종류

```python
"""
┌──────────────────────────────────────┐
│         로그 레벨 (낮음 → 높음)       │
├──────────────────────────────────────┤
│                                      │
│  DEBUG (10)    - 상세한 디버그 정보   │
│  INFO (20)     - 일반 정보           │
│  WARNING (30)  - 경고 메시지         │
│  ERROR (40)    - 에러 발생           │
│  CRITICAL (50) - 치명적 에러         │
│                                      │
│  설정한 레벨 이상만 출력됨            │
│  예: WARNING 설정 → WARNING, ERROR,  │
│      CRITICAL만 출력                 │
│                                      │
└──────────────────────────────────────┘
"""
```

### 2.2 로그 레벨 사용 예제

```python
import logging

# 기본 설정
logging.basicConfig(level=logging.DEBUG)
logger = logging.getLogger(__name__)

def process_payment(amount):
    logger.debug(f"처리 시작: 금액={amount}")  # DEBUG

    if amount <= 0:
        logger.error(f"잘못된 금액: {amount}")  # ERROR
        return False

    if amount > 10000:
        logger.warning(f"고액 결제: {amount}")  # WARNING

    try:
        # 결제 처리
        logger.info(f"결제 성공: {amount}")  # INFO
        return True

    except Exception as e:
        logger.critical(f"결제 시스템 오류: {e}")  # CRITICAL
        raise

# 실행
process_payment(5000)
process_payment(-100)
process_payment(15000)

# 출력:
# DEBUG:__main__:처리 시작: 금액=5000
# INFO:__main__:결제 성공: 5000
# DEBUG:__main__:처리 시작: 금액=-100
# ERROR:__main__:잘못된 금액: -100
# DEBUG:__main__:처리 시작: 금액=15000
# WARNING:__main__:고액 결제: 15000
# INFO:__main__:결제 성공: 15000
```

## 3. 로깅 설정

### 3.1 basicConfig - 간단한 설정

```python
import logging

# 파일로 로그 저장
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    filename='app.log',
    filemode='w'  # 'w': 덮어쓰기, 'a': 추가
```

### 3.2 고급 설정 - 핸들러와 포매터

**비유**:
- **Handler**: 로그를 **어디에** 보낼지 (파일, 콘솔, 이메일 등)
- **Formatter**: 로그를 **어떻게** 보여줄지 (형식)

```python
import logging

# Logger 생성
logger = logging.getLogger('my_app')
logger.setLevel(logging.DEBUG)

# 1. 콘솔 핸들러 (INFO 이상)
console_handler = logging.StreamHandler()
console_handler.setLevel(logging.INFO)
console_format = logging.Formatter('%(levelname)s - %(message)s')
console_handler.setFormatter(console_format)

# 2. 파일 핸들러 (DEBUG 이상)
file_handler = logging.FileHandler('debug.log')
file_handler.setLevel(logging.DEBUG)
file_format = logging.Formatter(
    '%(asctime)s - %(name)s - %(levelname)s - %(filename)s:%(lineno)d - %(message)s'
)
file_handler.setFormatter(file_format)

# 핸들러 등록
logger.addHandler(console_handler)
logger.addHandler(file_handler)

# 사용
logger.debug("상세 디버그 정보")  # 파일에만 기록
logger.info("일반 정보")  # 콘솔 + 파일
logger.warning("경고!")  # 콘솔 + 파일
logger.error("에러 발생!")  # 콘솔 + 파일

# 콘솔 출력:
# INFO - 일반 정보
# WARNING - 경고!
# ERROR - 에러 발생!

# debug.log 파일:
# 2024-01-15 10:30:15,123 - my_app - DEBUG - test.py:20 - 상세 디버그 정보
# 2024-01-15 10:30:15,124 - my_app - INFO - test.py:21 - 일반 정보
# 2024-01-15 10:30:15,125 - my_app - WARNING - test.py:22 - 경고!
# 2024-01-15 10:30:15,126 - my_app - ERROR - test.py:23 - 에러 발생!
```

### 4.3 구조화된 로깅

```python
import logging
import json

class JsonFormatter(logging.Formatter):
    """JSON 형식 로그"""

    def format(self, record):
        log_data = {
            'timestamp': self.formatTime(record),
            'level': record.levelname,
            'logger': record.name,
            'message': record.getMessage(),
            'file': record.filename,
            'line': record.lineno
        }

        # 추가 필드
        if hasattr(record, 'user_id'):
            log_data['user_id'] = record.user_id
        if hasattr(record, 'request_id'):
            log_data['request_id'] = record.request_id

        return json.dumps(log_data, ensure_ascii=False)

# 설정
logger = logging.getLogger('api')
handler = logging.StreamHandler()
handler.setFormatter(JsonFormatter())
logger.addHandler(handler)
logger.setLevel(logging.INFO)

# 사용
logger.info("사용자 로그인", extra={'user_id': 123, 'request_id': 'abc-123'})

# 출력:
# {"timestamp": "2024-01-15 10:30:15,123", "level": "INFO", "logger": "api",
#  "message": "사용자 로그인", "file": "test.py", "line": 42,
#  "user_id": 123, "request_id": "abc-123"}
```

## 5. 로그 로테이션

**비유**: 로그 로테이션은 **일기장을 주기적으로 교체**하는 것입니다. 파일이 너무 커지면 새 파일로 전환합니다.

### 5.1 RotatingFileHandler - 크기 기반

```python
import logging
from logging.handlers import RotatingFileHandler

logger = logging.getLogger('app')
logger.setLevel(logging.INFO)

# 파일 크기 기반 로테이션
# 최대 1MB, 백업 5개
handler = RotatingFileHandler(
    'app.log',
    maxBytes=1024 * 1024,  # 1MB
    backupCount=5
)

formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s')
handler.setFormatter(formatter)
logger.addHandler(handler)

# 사용
for i in range(100000):
    logger.info(f"로그 메시지 #{i}")

# 파일 생성:
# app.log         (최신)
# app.log.1
# app.log.2
# app.log.3
# app.log.4
# app.log.5       (가장 오래됨)
```

### 5.2 TimedRotatingFileHandler - 시간 기반

```python
from logging.handlers import TimedRotatingFileHandler

logger = logging.getLogger('app')
logger.setLevel(logging.INFO)

# 매일 자정에 로그 파일 교체
handler = TimedRotatingFileHandler(
    'app.log',
    when='midnight',  # 'S': 초, 'M': 분, 'H': 시간, 'D': 일, 'midnight': 자정
    interval=1,
    backupCount=7  # 7일치 보관
)

formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s')
handler.setFormatter(formatter)
logger.addHandler(handler)

# 파일 생성:
# app.log                 (오늘)
# app.log.2024-01-14
# app.log.2024-01-13
# ...
```

## 6. 디버깅 도구

### 6.1 pdb - Python Debugger

**비유**: pdb는 코드 실행을 **일시정지**하고, **한 줄씩** 진행하며 상태를 확인하는 도구입니다.

```python
# debug_example.py
def calculate_total(items):
    total = 0

    for item in items:
        # 디버거 시작점
        import pdb; pdb.set_trace()

        total += item['price'] * item['quantity']

    return total

# 실행
items = [
    {'name': 'Apple', 'price': 100, 'quantity': 2},
    {'name': 'Banana', 'price': 50, 'quantity': 3}
]

result = calculate_total(items)
print(f"Total: {result}")
```

**pdb 주요 명령어**:

## 7. 실전 예제 - 웹 API 로깅

```python
# api_logger.py
import logging
import time
from functools import wraps

# 로거 설정
def setup_logging():
    """로깅 설정"""
    # 루트 로거
    logger = logging.getLogger()
    logger.setLevel(logging.DEBUG)

    # 콘솔 핸들러 (INFO 이상)
    console_handler = logging.StreamHandler()
    console_handler.setLevel(logging.INFO)
    console_format = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
    )
    console_handler.setFormatter(console_format)

    # 파일 핸들러 (모든 레벨)
    from logging.handlers import RotatingFileHandler
    file_handler = RotatingFileHandler(
        'api.log',
        maxBytes=10 * 1024 * 1024,  # 10MB
        backupCount=5
    )
    file_handler.setLevel(logging.DEBUG)
    file_format = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - [%(filename)s:%(lineno)d] - %(message)s'
    )
    file_handler.setFormatter(file_format)

    # 핸들러 등록
    logger.addHandler(console_handler)
    logger.addHandler(file_handler)

# 데코레이터 - API 호출 로깅
def log_api_call(func):
    """API 호출을 로깅하는 데코레이터"""
    logger = logging.getLogger(func.__module__)

    @wraps(func)
    def wrapper(*args, **kwargs):
        logger.info(f"API 호출: {func.__name__}")
        logger.debug(f"  인수: args={args}, kwargs={kwargs}")

        start = time.time()

        try:
            result = func(*args, **kwargs)
            elapsed = time.time() - start

            logger.info(f"API 성공: {func.__name__} ({elapsed:.2f}초)")
            logger.debug(f"  결과: {result}")

            return result

        except Exception as e:
            elapsed = time.time() - start

            logger.error(f"API 실패: {func.__name__} ({elapsed:.2f}초)")
            logger.exception(f"  예외: {e}")

            raise

    return wrapper

# 사용 예제
setup_logging()
logger = logging.getLogger(__name__)

@log_api_call
def get_user(user_id):
    """사용자 조회 API"""
    logger.debug(f"DB에서 사용자 조회: {user_id}")
    # 시뮬레이션
    time.sleep(0.1)
    return {'id': user_id, 'name': 'Alice'}

@log_api_call
def create_order(user_id, items):
    """주문 생성 API"""
    logger.debug(f"주문 생성 중: user={user_id}, items={items}")

    if not items:
        raise ValueError("주문 상품이 없습니다")

    time.sleep(0.2)
    return {'order_id': 123, 'status': 'created'}

# 실행
if __name__ == '__main__':
    user = get_user(1)
    print(f"사용자: {user}")

    try:
        order = create_order(1, ['item1', 'item2'])
        print(f"주문: {order}")
    except ValueError as e:
        print(f"에러: {e}")

# 콘솔 출력:
# 2024-01-15 10:30:15 - __main__ - INFO - API 호출: get_user
# 2024-01-15 10:30:15 - __main__ - INFO - API 성공: get_user (0.10초)
# 사용자: {'id': 1, 'name': 'Alice'}
# 2024-01-15 10:30:15 - __main__ - INFO - API 호출: create_order
# 2024-01-15 10:30:15 - __main__ - INFO - API 성공: create_order (0.20초)
# 주문: {'order_id': 123, 'status': 'created'}
```

### 💡 Tip 2: 로그에 컨텍스트 추가

```python
import logging
from contextvars import ContextVar

# 요청 ID 컨텍스트
request_id_var = ContextVar('request_id', default=None)

class ContextFilter(logging.Filter):
    """컨텍스트 정보를 로그에 추가"""

    def filter(self, record):
        record.request_id = request_id_var.get() or 'N/A'
        return True

# 설정
logger = logging.getLogger(__name__)
handler = logging.StreamHandler()
handler.addFilter(ContextFilter())
formatter = logging.Formatter(
    '%(asctime)s - [%(request_id)s] - %(levelname)s - %(message)s'
)
handler.setFormatter(formatter)
logger.addHandler(handler)
logger.setLevel(logging.INFO)

# 사용
def handle_request(request_id):
```

```python
# file_processor.py
import logging
from logging.handlers import RotatingFileHandler
import os

def setup_logging():
    """로깅 설정"""
    logger = logging.getLogger('file_processor')
    logger.setLevel(logging.DEBUG)

    # 콘솔 핸들러
    console_handler = logging.StreamHandler()
    console_handler.setLevel(logging.INFO)
    console_format = logging.Formatter('%(levelname)s - %(message)s')
    console_handler.setFormatter(console_format)

    # 파일 핸들러
    file_handler = RotatingFileHandler(
        'file_processor.log',
        maxBytes=1024 * 1024,
        backupCount=3
    )
    file_handler.setLevel(logging.DEBUG)
    file_format = logging.Formatter(
        '%(asctime)s - %(levelname)s - [%(filename)s:%(lineno)d] - %(message)s'
    )
    file_handler.setFormatter(file_format)

    logger.addHandler(console_handler)
    logger.addHandler(file_handler)

    return logger

logger = setup_logging()

def process_file(file_path):
    """파일 처리"""
    logger.info(f"파일 처리 시작: {file_path}")

    # 파일 존재 확인
    if not os.path.exists(file_path):
        logger.error(f"파일이 존재하지 않음: {file_path}")
        return None

    file_size = os.path.getsize(file_path)
    logger.debug(f"파일 크기: {file_size} bytes")

    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            lines = f.readlines()

        logger.info(f"파일 읽기 완료: {len(lines)} 라인")

        # 처리
        processed = []
        for i, line in enumerate(lines, 1):
            logger.debug(f"라인 {i} 처리 중: {line[:20]}...")

            if not line.strip():
                logger.warning(f"라인 {i}: 빈 줄 건너뜀")
                continue

            processed.append(line.strip().upper())

        logger.info(f"처리 완료: {len(processed)}개 라인 변환")
        return processed

    except UnicodeDecodeError as e:
        logger.error(f"인코딩 에러: {e}")
        logger.exception("상세 에러:")
        return None

    except Exception as e:
        logger.critical(f"예상치 못한 에러: {e}")
        logger.exception("상세 에러:")
        raise

if __name__ == '__main__':
    # 테스트
    result = process_file('test.txt')
    if result:
        logger.info(f"결과: {len(result)}개 라인")
```

## 핵심 요약

1. **로그 레벨**
   ```python
   DEBUG < INFO < WARNING < ERROR < CRITICAL
   ```

2. **기본 설정**
   ```python
   import logging

   logging.basicConfig(
       level=logging.INFO,
       format='%(asctime)s - %(levelname)s - %(message)s',
       filename='app.log'
   )
   ```

3. **로거 사용**
   ```python
   logger = logging.getLogger(__name__)
   logger.info("정보")
   logger.warning("경고")
   logger.error("에러")
   logger.exception("예외")  # 스택 트레이스 포함
   ```

   ```python
   breakpoint()  # Python 3.7+
   import pdb; pdb.set_trace()  # 구버전
   ```

   - `print()` 대신 `logging` 사용
   - 모듈별로 로거 분리
   - 로그 로테이션 설정
   - 프로덕션에서는 INFO 이상 레벨
