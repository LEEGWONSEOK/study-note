# Chapter 1. Python 소개

## 1.1 Python이란?

**Python**은 1991년 Guido van Rossum이 개발한 **고수준, 범용 프로그래밍 언어**입니다.

> 🐍 **이름의 유래**: "Python"은 뱀이 아니라 영국 코미디 그룹 "Monty Python"에서 따왔습니다!
> Guido는 재미있고 사용하기 쉬운 언어를 만들고 싶었습니다.

### 특징

> 💡 **핵심 철학**: "삶은 짧으니 Python을 쓰자" (Life is short, use Python)

1. **간결하고 읽기 쉬운 문법**
   - 영어 문장처럼 읽힘
   - 들여쓰기로 블록 구분

   **비유**: Java가 **법률 문서**라면, Python은 **일기**입니다.
   - Java: 정확하지만 장황함
   - Python: 간결하고 직관적

2. **동적 타입 (Dynamic Typing)**
   - 변수 선언 시 타입 명시 불필요
   - 런타임에 타입 결정

   **비유**:
   - Java: 상자에 "정수만", "문자열만" 미리 표시
   - Python: 상자에 뭐든 넣고 나중에 알아서 판단

3. **인터프리터 언어**
   - 컴파일 불필요
   - 즉시 실행 가능

   **비유**:
   - Java: 요리책(코드) → 레시피 번역(컴파일) → 요리(실행)
   - Python: 요리책(코드) → 바로 요리(실행)

4. **멀티 패러다임**
   - 객체지향 (클래스, 상속)
   - 함수형 (map, filter, lambda)
   - 절차적 (순차 실행)

   **비유**: **스위스 아미 나이프**처럼 여러 방식으로 문제 해결 가능

5. **방대한 생태계**
   - 표준 라이브러리: "배터리 포함" (Batteries Included)
   - PyPI (Python Package Index): 40만+ 패키지

   **비유**: **레고 블록**처럼 필요한 부품을 조립해서 사용

## 1.2 Java vs Python 비교

### 코드 비교: Hello World

**Java**:
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

**Python**:
```python
print("Hello, World!")
```

---

### 주요 차이점

| 특성 | Java | Python |
|------|------|--------|
| 타입 시스템 | 정적 타입 (Static) | 동적 타입 (Dynamic) |
| 컴파일 | 컴파일 필요 (.class) | 인터프리터 실행 |
| 코드 양 | 많음 (보일러플레이트) | 적음 (간결함) |
| 성능 | 빠름 (JIT 컴파일) | 느림 (인터프리터) |
| 블록 구분 | 중괄호 `{}` | 들여쓰기 |
| 세미콜론 | 필수 `;` | 선택 (보통 안 씀) |
| 변수 선언 | 타입 명시 필수 | 타입 추론 |
| 주 용도 | Enterprise, Android | AI/ML, 웹, 스크립팅 |

---

### 코드 비교: 리스트 필터링

**Java**:
```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
List<Integer> even = numbers.stream()
    .filter(n -> n % 2 == 0)
    .collect(Collectors.toList());
System.out.println(even);  // [2, 4]
```

**Python**:
```python
numbers = [1, 2, 3, 4, 5]
even = [n for n in numbers if n % 2 == 0]
print(even)  # [2, 4]
```

### 가상 환경 (venv)

**왜 필요한가?**
- 프로젝트별 독립적인 패키지 관리
- 의존성 충돌 방지

**생성**:
```bash
# 가상 환경 생성
python3 -m venv venv

# 활성화 (macOS/Linux)
source venv/bin/activate

# 활성화 (Windows)
venv\Scripts\activate

# 비활성화
deactivate
```

**Java와 비교**:
- Java: Maven/Gradle로 프로젝트별 의존성 관리
- Python: venv로 프로젝트별 Python 환경 분리

---

**Java의 Maven/Gradle과 유사**

## 1.7 실전 예제: 간단한 계산기

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "0으로 나눌 수 없습니다"
    return a / b

# 사용
print(f"10 + 5 = {add(10, 5)}")
print(f"10 - 5 = {subtract(10, 5)}")
print(f"10 * 5 = {multiply(10, 5)}")
print(f"10 / 5 = {divide(10, 5)}")
```

## 1.8 Java vs Python: 문법 차이 요약

### 1. 변수 선언

**Java**:
```java
int age = 30;
String name = "Alice";
boolean isActive = true;
```

**Python**:
```python
age = 30
name = "Alice"
is_active = True
```

---

### 2. 조건문

**Java**:
```java
if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}
```

**Python**:
```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

---

### 3. 반복문

**Java**:
```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

**Python**:
```python
for i in range(5):
    print(i)
```

---

### 4. 함수

**Java**:
```java
public int add(int a, int b) {
    return a + b;
}
```

**Python**:
```python
def add(a, b):
    return a + b
```

## 실전 팁

### 💡 Tip 1: Python은 들여쓰기가 문법

```python
# ✅ 올바른 코드
if True:
    print("Hello")  # 4칸 들여쓰기

# ❌ 잘못된 코드
if True:
print("Hello")  # IndentationError!
```

```python
user_id = 123
first_name = "Alice"
```
