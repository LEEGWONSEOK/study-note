## 2.1 들여쓰기 (Indentation)

Python의 가장 큰 특징: **들여쓰기가 문법**입니다.

> 💡 **비유**: Java에서 중괄호 `{}`가 **울타리**라면, Python에서는 **계단**입니다.
> 같은 층(레벨)에 있는 코드는 같은 들여쓰기를 가져야 합니다.

**왜 이렇게 만들었을까?**
Python 창시자 Guido는 "코드는 사람이 읽는 것"이라고 믿었습니다. 들여쓰기를 강제하면 자연스럽게 읽기 쉬운 코드가 됩니다.

### Java vs Python

**Java**:
```java
if (true) {
    System.out.println("Hello");
    System.out.println("World");
}
```

**Python**:
```python
if True:
    print("Hello")
    print("World")
```

---

### 들여쓰기 규칙

> 🏗️ **건물로 비유하면**:
> - 1층(메인 코드): 들여쓰기 0칸
> - 2층(if 안쪽): 들여쓰기 4칸
> - 3층(if 안의 for): 들여쓰기 8칸
>
> 각 층은 정확히 4칸씩 올라갑니다!

1. **공백 4칸** (PEP 8 권장) - 2칸도, 8칸도 아닌 **정확히 4칸**
2. **탭 대신 스페이스** 사용 - 탭과 스페이스를 섞으면 오류!
3. **일관성 유지** (같은 블록 내에서) - 한 번 4칸으로 시작했으면 계속 4칸

```python
# ✅ 올바른 예
def greet():
    name = "Alice"
    if name:
        print(f"Hello, {name}")
        print("Welcome!")

# ❌ 잘못된 예
def greet():
    name = "Alice"
    if name:
      print(f"Hello, {name}")  # 2칸 들여쓰기
        print("Welcome!")  # 4칸 들여쓰기 - IndentationError!
```

### 다중 할당

> 🎁 **비유**: Python은 **선물 교환**이 매우 쉽습니다.
> Java는 선물을 바꾸려면 임시 보관함(temp)이 필요하지만,
> Python은 동시에 교환 가능!

```python
# 여러 변수 동시 할당 (한 번에 여러 선물 받기)
a, b, c = 1, 2, 3
print(a, b, c)  # 1 2 3

# 같은 값 할당 (같은 선물 여러 명에게)
x = y = z = 0
print(x, y, z)  # 0 0 0

# 변수 swap (선물 교환)
a, b = 10, 20
a, b = b, a  # 마법처럼 바로 교환!
print(a, b)  # 20 10
```

**실생활 비유**:
```python
# 실제 상황: 이름과 성을 바꾸고 싶다면?
first_name = "길동"
last_name = "홍"

# Python: 한 줄로 해결!
first_name, last_name = last_name, first_name
print(first_name, last_name)  # 홍 길동
```

**Java와 비교**:
```java
// Java - swap을 위해 임시 변수 필요 (보관함 필요)
int a = 10, b = 20;
int temp = a;  // temp에 잠시 보관
a = b;
b = temp;

// Python - 임시 변수 불필요! (동시 교환)
a, b = 10, 20
a, b = b, a
```

### 문자열 연산

> 🔪 **비유**: 문자열은 **김밥**입니다.
>
> - 인덱싱: 특정 위치의 한 조각 꺼내기
> - 슬라이싱: 여러 조각 잘라내기
> - 반복: 김밥을 여러 개 만들기

```python
# 연결 (김밥 이어붙이기)
str1 = "Hello"
str2 = "World"
result = str1 + " " + str2  # "Hello World"

# 반복 (같은 김밥 여러 개)
repeat = "Ha" * 3  # "HaHaHa"
print("=" * 20)    # ====================  (구분선 만들 때 유용!)

# 길이
length = len("Python")  # 6

# 인덱싱 (0부터 시작!)
text = "Python"
#      P  y  t  h  o  n
#      0  1  2  3  4  5  (앞에서부터)
#     -6 -5 -4 -3 -2 -1  (뒤에서부터)

print(text[0])   # P (첫 번째)
print(text[-1])  # n (마지막)
print(text[-2])  # o (뒤에서 두 번째)

# 슬라이싱 [시작:끝] (끝은 포함 안 됨!)
print(text[0:3])   # Pyt (0,1,2번째)
print(text[:3])    # Pyt (처음부터 3번째 전까지)
print(text[3:])    # hon (3번째부터 끝까지)
print(text[-3:])   # hon (뒤에서 3개)
print(text[::2])   # Pto (2칸씩 건너뛰기)
print(text[::-1])  # nohtyP (거꾸로!)
```

**실생활 예시**:
```python
# 이메일 주소에서 아이디 추출
```

### Falsy 값

> 🚦 **비유**: Python은 **신호등**처럼 값을 판단합니다.
>
> - 🟢 Truthy (참으로 간주): 뭔가 있으면 True
> - 🔴 Falsy (거짓으로 간주): 비어있거나 0이면 False

**Python에서 False로 평가되는 값** (외우세요!):
- `False` - 거짓 자체
- `None` - 없음
- `0`, `0.0` - 숫자 0
- `""` - 빈 문자열
- `[]` - 빈 리스트
- `{}` - 빈 딕셔너리
- `()` - 빈 튜플

```python
# Falsy 값들
if not 0:
    print("0 is falsy")  # 출력됨

if not "":
    print("Empty string is falsy")  # 출력됨

if not []:
    print("Empty list is falsy")  # 출력됨

# Truthy 값 (비어있지 않으면 True!)
if "text":
    print("Non-empty string is truthy")  # 출력됨

if [1, 2, 3]:
    print("Non-empty list is truthy")  # 출력됨
```

**실전 활용**:
```python
# 사용자 입력 검증
username = input("사용자명: ")

# ❌ Java 스타일
if username != "" and username != None:
    print(f"환영합니다, {username}님!")

# ✅ Python 스타일 (간결!)
if username:  # 비어있지 않으면 True
    print(f"환영합니다, {username}님!")

# 리스트가 비어있는지 확인
results = []

# ❌ 장황한 방법
if len(results) == 0:
    print("결과 없음")

# ✅ Python 스타일
if not results:  # 빈 리스트는 False
    print("결과 없음")
```

## 2.7 연산자

### 산술 연산자

> 🧮 **주의**: Python의 나눗셈은 Java와 다릅니다!

```python
a = 10
b = 3

print(a + b)   # 13 (덧셈)
print(a - b)   # 7  (뺄셈)
print(a * b)   # 30 (곱셈)

# ⚠️ 중요: 나눗셈 차이!
print(a / b)   # 3.333... (일반 나눗셈, 항상 float!)
print(a // b)  # 3 (정수 나눗셈, floor division)
print(a % b)   # 1 (나머지)

print(a ** b)  # 1000 (거듭제곱, a^b)
```

**Java와 차이**:
```java
// Java
int a = 10;
int b = 3;
System.out.println(a / b);  // 3 (정수 나눗셈)
System.out.println((double)a / b);  // 3.333... (실수 나눗셈)

// Python
a = 10
b = 3
print(a / b)   # 3.333... (항상 실수!)
print(a // b)  # 3 (정수만 원하면 //)
```

**실생활 예시**:
```python
# 사탕 나눠주기
candies = 10
children = 3

# 한 명당 몇 개? (정수 나눗셈)
per_child = candies // children  # 3개
print(f"한 명당 {per_child}개")

# 남은 사탕? (나머지)
leftover = candies % children  # 1개
print(f"남은 사탕 {leftover}개")

# 거듭제곱 활용
print(2 ** 10)  # 1024 (2의 10제곱, Java: Math.pow(2, 10))
```

### 비교 연산자

> ⛓️ **Python의 마법**: 비교 연산자 체이닝!
>
> **비유**: 수학 부등식처럼 쓸 수 있습니다.
> - 수학: `18 ≤ age < 65`
> - Python: `18 <= age < 65` (그대로!)
> - Java: 불가능 (&&로 연결해야 함)

```python
print(5 == 5)   # True
print(5 != 3)   # True
print(5 > 3)    # True
print(5 < 3)    # False
print(5 >= 5)   # True
print(5 <= 3)   # False

# ⭐ 체이닝 가능! (Python만의 특권)
age = 25
print(18 <= age < 65)  # True (성인이면서 은퇴 전)

# 여러 비교 동시에
score = 85
print(0 <= score <= 100)  # True (유효한 점수)
print(60 <= score < 70)   # False (D 학점 아님)
```

**Java와 차이**:
```java
// Java - 체이닝 불가, &&로 연결해야 함
if (age >= 18 && age < 65) {
    // ...
}

// Python - 수학처럼 자연스럽게
if 18 <= age < 65:
    # ...
```

**실생활 예시**:
```python
# 온도 범위 체크
temp = 25

if 18 <= temp <= 26:
    print("쾌적한 온도입니다")
elif temp < 18:
    print("춥습니다")
else:
    print("덥습니다")

# 시험 성적 등급
score = 85

if 90 <= score <= 100:
    grade = "A"
elif 80 <= score < 90:
    grade = "B"
elif 70 <= score < 80:
    grade = "C"
else:
    grade = "F"

print(f"성적: {grade}")
```

```python
def calculate_bmi():
    """BMI를 계산합니다."""

        print("정상")
```
