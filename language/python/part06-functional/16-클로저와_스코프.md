# Chapter 16. 클로저와 스코프 (Closures & Scope)

## 16.1 클로저란?

> 🎒 **비유**: 클로저는 **배낭**입니다.
> - 함수: 사람
> - 배낭: 환경 변수
> - 사람이 어디 가든 배낭 들고 다님

**클로저 (Closure)**: 함수가 정의된 환경의 변수를 **기억**하는 함수

---

### 기본 예제

```python
def outer(x):
    """외부 함수"""
    def inner(y):
        """내부 함수 - 클로저"""
        return x + y  # 외부 변수 x 기억!
    return inner

# 클로저 생성
add_10 = outer(10)
add_20 = outer(20)

# 사용
print(add_10(5))  # 15 (10 + 5)
print(add_20(5))  # 25 (20 + 5)

# add_10은 x=10을 "기억"하고 있음
# add_20은 x=20을 "기억"하고 있음
```

---

### Java와 비교

**Java** (익명 클래스):
```java
interface Function {
    int apply(int y);
}

Function createAdder(final int x) {
    return new Function() {
        public int apply(int y) {
            return x + y;  // final 변수만 접근 가능
        }
    };
}

// 사용
Function add10 = createAdder(10);
System.out.println(add10.apply(5));  // 15
```

**Python** (클로저):
```python
def create_adder(x):
    def adder(y):
        return x + y
    return adder

add_10 = create_adder(10)
print(add_10(5))  # 15
```

## 16.2 스코프 (Scope)

> 🏢 **비유**: 스코프는 **회사 조직도**
> - L: Local (팀)
> - E: Enclosing (부서)
> - G: Global (회사)
> - B: Built-in (산업 표준)

**LEGB 규칙**: 변수 검색 순서

---

### LEGB 예제

```python
# B: Built-in
# print, len, range 등

# G: Global
global_var = "회사 차원"

def outer():
    # E: Enclosing
    enclosing_var = "부서 차원"

    def inner():
        # L: Local
        local_var = "팀 차원"

        print(local_var)       # L: 팀 차원
        print(enclosing_var)   # E: 부서 차원
        print(global_var)      # G: 회사 차원
        print(len([1, 2, 3]))  # B: 3

    inner()

outer()
```

---

### 변수 가리기 (Shadowing)

```python
x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)  # local

    inner()
    print(x)  # enclosing

outer()
print(x)  # global
```

## 16.3 nonlocal과 global

### global - 전역 변수 수정

```python
count = 0

def increment():
    global count  # 전역 변수 수정 선언
    count += 1

increment()
increment()
print(count)  # 2
```

---

### nonlocal - 상위 스코프 변수 수정

```python
def outer():
    count = 0

    def increment():
        nonlocal count  # 상위 함수 변수 수정
        count += 1

    def get_count():
        return count

    # 5번 증가
    for _ in range(5):
        increment()

    return get_count()

result = outer()
print(result)  # 5
```

### 실전 예제: 카운터

```python
def create_counter(initial=0):
    """카운터 생성 (클로저)"""
    count = initial

    def increment():
        nonlocal count
        count += 1
        return count

    def decrement():
        nonlocal count
        count -= 1
        return count

    def get():
        return count

    def reset():
        nonlocal count
        count = initial

    # 딕셔너리로 반환
    return {
        'increment': increment,
        'decrement': decrement,
        'get': get,
        'reset': reset
    }

# 사용
counter = create_counter(10)

print(counter['increment']())  # 11
print(counter['increment']())  # 12
print(counter['decrement']())  # 11
print(counter['get']())        # 11
counter['reset']()
print(counter['get']())        # 10
```

### 3. 상태 캡슐화

```python
def create_bank_account(initial_balance):
    """은행 계좌 (private 상태)"""
    balance = initial_balance
    transaction_log = []

    def deposit(amount):
        nonlocal balance
        if amount > 0:
            balance += amount
            transaction_log.append(f"입금: +{amount:,}")
            return balance
        raise ValueError("입금액은 양수여야 합니다")

    def withdraw(amount):
        nonlocal balance
        if amount > balance:
            raise ValueError("잔액 부족")
        if amount > 0:
            balance -= amount
            transaction_log.append(f"출금: -{amount:,}")
            return balance
        raise ValueError("출금액은 양수여야 합니다")

    def get_balance():
        return balance

    def get_log():
        return transaction_log.copy()

    return {
        'deposit': deposit,
        'withdraw': withdraw,
        'balance': get_balance,
        'log': get_log
    }

# 사용
account = create_bank_account(100000)

account['deposit'](50000)
account['withdraw'](30000)
print(f"잔액: {account['balance']():,}원")  # 잔액: 120,000원

print("\n거래 내역:")
for log in account['log']():
    print(f"  {log}")
# 입금: +50,000
# 출금: -30,000
```

### 4. 메모이제이션 (Memoization)

```python
def memoize(func):
    """클로저를 사용한 메모이제이션"""
    cache = {}

    def wrapper(*args):
        if args not in cache:
            print(f"계산: {args}")
            cache[args] = func(*args)
        else:
            print(f"캐시: {args}")
        return cache[args]

    return wrapper

@memoize
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(5))
# 계산: (5,)
# 계산: (4,)
# 계산: (3,)
# 계산: (2,)
# 계산: (1,)
# 계산: (0,)
# 캐시: (1,)
# 캐시: (2,)
# 캐시: (3,)
# 5
```

## 16.5 클로저 vs 클래스

> 🤔 **언제 뭘 쓸까?**
> - 클로저: 간단한 상태 + 몇 개의 함수
> - 클래스: 복잡한 상태 + 많은 메서드

### 클로저 방식

```python
def create_counter(initial=0):
    count = initial

    def increment():
        nonlocal count
        count += 1
        return count

    def decrement():
        nonlocal count
        count -= 1
        return count

    def get():
        return count

    return {
        'increment': increment,
        'decrement': decrement,
        'get': get
    }

counter = create_counter(10)
print(counter['increment']())  # 11
```

---

### 클래스 방식

```python
class Counter:
    def __init__(self, initial=0):
        self._count = initial

    def increment(self):
        self._count += 1
        return self._count

    def decrement(self):
        self._count -= 1
        return self._count

    def get(self):
        return self._count

counter = Counter(10)
print(counter.increment())  # 11
```

## 16.7 실전 예제

### 예제 1: 타이머 데코레이터

```python
import time

def create_timer():
    """타이머 클로저"""
    total_time = 0
    call_count = 0

    def timer(func):
        """데코레이터"""
        def wrapper(*args, **kwargs):
            nonlocal total_time, call_count

            start = time.time()
            result = func(*args, **kwargs)
            elapsed = time.time() - start

            total_time += elapsed
            call_count += 1

            print(f"{func.__name__}: {elapsed:.4f}초")
            return result

        def stats():
            """통계"""
            avg = total_time / call_count if call_count > 0 else 0
            return {
                'total': total_time,
                'count': call_count,
                'average': avg
            }

        wrapper.stats = stats
        return wrapper

    return timer

# 사용
timer = create_timer()

@timer
def slow_function(n):
    time.sleep(0.1)
    return sum(range(n))

# 여러 번 호출
slow_function(1000)
slow_function(2000)
slow_function(3000)

# 통계 확인
stats = slow_function.stats()
print(f"\n총 시간: {stats['total']:.4f}초")
print(f"호출 횟수: {stats['count']}")
print(f"평균 시간: {stats['average']:.4f}초")
```

### 예제 2: 설정 관리자

```python
def create_config_manager(defaults=None):
    """설정 관리자 (클로저)"""
    config = defaults.copy() if defaults else {}
    listeners = []

    def get(key, default=None):
        """값 가져오기"""
        return config.get(key, default)

    def set(key, value):
        """값 설정"""
        old_value = config.get(key)
        config[key] = value

        # 리스너 알림
        for listener in listeners:
            listener(key, old_value, value)

    def update(data):
        """여러 값 업데이트"""
        for key, value in data.items():
            set(key, value)

    def delete(key):
        """값 삭제"""
        if key in config:
            del config[key]

    def on_change(listener):
        """변경 리스너 등록"""
        listeners.append(listener)

    def get_all():
        """모든 설정"""
        return config.copy()

    return {
        'get': get,
        'set': set,
        'update': update,
        'delete': delete,
        'on_change': on_change,
        'all': get_all
    }

# 사용
config = create_config_manager({'debug': False, 'port': 8000})

# 변경 리스너
def log_change(key, old, new):
    print(f"[CONFIG] {key}: {old} → {new}")

config['on_change'](log_change)

# 설정 변경
config['set']('debug', True)
# [CONFIG] debug: False → True

config['set']('port', 9000)
# [CONFIG] port: 8000 → 9000

config['update']({'host': 'localhost', 'timeout': 30})
# [CONFIG] host: None → localhost
# [CONFIG] timeout: None → 30

print(config['all']())
# {'debug': True, 'port': 9000, 'host': 'localhost', 'timeout': 30}
```

### 예제 3: 이벤트 핸들러

```python
def create_event_emitter():
    """이벤트 에미터 (클로저)"""
    handlers = {}

    def on(event_name, handler):
        """이벤트 핸들러 등록"""
        if event_name not in handlers:
            handlers[event_name] = []
        handlers[event_name].append(handler)

    def off(event_name, handler):
        """이벤트 핸들러 제거"""
        if event_name in handlers:
            handlers[event_name].remove(handler)

    def emit(event_name, *args, **kwargs):
        """이벤트 발생"""
        if event_name in handlers:
            for handler in handlers[event_name]:
                handler(*args, **kwargs)

    def once(event_name, handler):
        """한 번만 실행되는 핸들러"""
        def wrapper(*args, **kwargs):
            handler(*args, **kwargs)
            off(event_name, wrapper)
        on(event_name, wrapper)

    return {
        'on': on,
        'off': off,
        'emit': emit,
        'once': once
    }

# 사용
emitter = create_event_emitter()

# 핸들러 등록
def user_login(user):
    print(f"👤 {user} 로그인")

def send_welcome_email(user):
    print(f"📧 {user}님께 환영 이메일 전송")

emitter['on']('login', user_login)
emitter['on']('login', send_welcome_email)

# 한 번만 실행
emitter['once']('login', lambda user: print(f"🎉 첫 로그인: {user}"))

# 이벤트 발생
emitter['emit']('login', 'Alice')
# 👤 Alice 로그인
# 📧 Alice님께 환영 이메일 전송
# 🎉 첫 로그인: Alice

emitter['emit']('login', 'Bob')
# 👤 Bob 로그인
# 📧 Bob님께 환영 이메일 전송
# (첫 로그인 메시지 없음 - once!)
```

### 예제 4: 비율 제한기 (Rate Limiter)

```python
import time

def create_rate_limiter(max_calls, time_window):
    """비율 제한기 (초당 호출 횟수 제한)"""
    calls = []

    def is_allowed():
        """호출 허용 여부"""
        nonlocal calls
        now = time.time()

        # 시간 윈도우 밖의 호출 제거
        calls = [call_time for call_time in calls if now - call_time < time_window]

        # 제한 확인
        if len(calls) < max_calls:
            calls.append(now)
            return True
        return False

    def wait_time():
        """대기 시간"""
        if len(calls) < max_calls:
            return 0
        oldest = calls[0]
        return time_window - (time.time() - oldest)

    return {
        'is_allowed': is_allowed,
        'wait_time': wait_time
    }

# 사용 (초당 3회 제한)
limiter = create_rate_limiter(max_calls=3, time_window=1.0)

for i in range(5):
    if limiter['is_allowed']():
        print(f"✅ 요청 {i+1} 허용")
    else:
        wait = limiter['wait_time']()
        print(f"❌ 요청 {i+1} 거부 ({wait:.2f}초 후 재시도)")
    time.sleep(0.2)

# ✅ 요청 1 허용
# ✅ 요청 2 허용
# ✅ 요청 3 허용
# ❌ 요청 4 거부 (0.40초 후 재시도)
# ❌ 요청 5 거부 (0.20초 후 재시도)
```

## 16.8 클로저의 함정

### 함정 1: 루프 변수 캡처

```python
# ❌ 잘못된 예
functions = []
for i in range(3):
    functions.append(lambda x: x + i)

# 예상: [1, 2, 3]
# 실제: [2, 2, 2] (모두 i=2를 참조!)
print([f(0) for f in functions])

# ✅ 해결 1: 기본값으로 즉시 바인딩
functions = []
for i in range(3):
    functions.append(lambda x, i=i: x + i)

print([f(0) for f in functions])  # [0, 1, 2]

# ✅ 해결 2: 클로저 생성 함수
def make_adder(n):
    return lambda x: x + n

functions = [make_adder(i) for i in range(3)]
print([f(0) for f in functions])  # [0, 1, 2]
```

### 함정 2: 가변 기본값

# ❌ 위험!
def create_appender(item, items=[]):
    items.append(item)
    return items

    if items is None:
        items = []
    new_items = items.copy()
    new_items.append(item)
    return new_items

print(create_appender(1))  # [1]

### 문제 2: 함수 호출 횟수 제한

최대 n번까지만 호출 가능한 데코레이터

<details>
<summary>정답 보기</summary>

```python
def limit_calls(max_calls):
    def decorator(func):
        count = 0

        def wrapper(*args, **kwargs):
            nonlocal count
            if count >= max_calls:
                raise RuntimeError(f"최대 {max_calls}번만 호출 가능")
            count += 1
            return func(*args, **kwargs)

        return wrapper
    return decorator

# 테스트
@limit_calls(3)
def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))    # OK
print(greet("Bob"))      # OK
print(greet("Charlie"))  # OK
# print(greet("David"))  # RuntimeError
```
</details>
