## 3. 추천 도서

### 3.1 초급

**영문**:

- **"Automate the Boring Stuff with Python" by Al Sweigart**
  - 실용적인 자동화 예제
  - 무료 온라인: https://automatetheboringstuff.com

**한글**:
- **"Do it! 점프 투 파이썬" by 박응용**
  - 한국어로 된 Python 입문서
  - 쉽고 체계적

- **"혼자 공부하는 파이썬" by 윤인성**
  - 독학용 교재
  - 동영상 강의 포함

### 3.2 중급

**영문**:
- **"Fluent Python" by Luciano Ramalho**
  - Python의 깊이 있는 이해
  - 중급자 필독서

- **"Effective Python" by Brett Slatkin**
  - 베스트 프랙티스 90개
  - 코드 품질 향상

**한글**:
- **"전문가를 위한 파이썬" (Fluent Python 번역)**
  - Python 고급 기법

- **"파이썬 코딩의 기술" (Effective Python 번역)**
  - 실전 팁과 노하우

### 3.3 고급

- **"Python Cookbook" by David Beazley and Brian K. Jones**
  - 고급 레시피 모음
  - 실무 문제 해결

- **"High Performance Python" by Micha Gorelick and Ian Ozsvald**
  - 성능 최적화
  - 프로파일링과 튜닝

## 학습 로드맵 제안

### 초급 (1-3개월)
1. Python 공식 튜토리얼 완독
2. "Python Crash Course" 또는 "점프 투 파이썬"
3. LeetCode Easy 문제 50개
4. 간단한 프로젝트 1-2개

### 중급 (3-6개월)
1. "Fluent Python" 또는 "Effective Python"
2. 오픈소스 프로젝트 읽기
3. LeetCode Medium 문제 50개
4. 중급 프로젝트 (웹 앱, API 서버 등)

### 고급 (6개월+)
1. 전문 분야 선택 (웹, 데이터, ML 등)
2. 해당 분야 심화 학습
3. 오픈소스 기여
4. 블로그 작성 또는 발표
