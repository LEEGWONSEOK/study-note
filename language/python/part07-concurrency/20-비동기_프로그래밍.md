## 1. 비동기 프로그래밍이란?

### 1.1 동기 vs 비동기

**비유**:
- **동기(Sync)**: 식당에서 주문하고 음식이 나올 때까지 **가만히 서서 기다림**
- **비동기(Async)**: 주문하고 **진동벨을 받아** 다른 일을 하다가, 벨이 울리면 음식을 가져옴

```python
"""
동기 (Synchronous):
┌─────────────────────────────────┐
│  요청1 ████████ (완료 대기)      │
│         └─> 응답1                │
│                요청2 ████████    │
│                     └─> 응답2    │
│  총 시간: ████████████████       │
└─────────────────────────────────┘

비동기 (Asynchronous):
┌─────────────────────────────────┐
│  요청1 ████                      │
│     └─> 응답1 (나중에)           │
│  요청2 ████                      │
│     └─> 응답2 (나중에)           │
│  총 시간: ████ (대기 없음!)      │
└─────────────────────────────────┘
"""
```

### Java vs Python

**Java (CompletableFuture)**:
```java
CompletableFuture<String> future1 = CompletableFuture.supplyAsync(() -> {
    // 비동기 작업
    return downloadUrl("https://example.com");
});

CompletableFuture<String> future2 = CompletableFuture.supplyAsync(() -> {
    return downloadUrl("https://example.org");
});

// 결과 조합
CompletableFuture<String> combined = future1.thenCombine(future2,
    (result1, result2) -> result1 + result2);

String result = combined.get();
```

**Python (asyncio)**:
```python
import asyncio

async def main():
    # 비동기 작업
    task1 = asyncio.create_task(download_url("https://example.com"))
    task2 = asyncio.create_task(download_url("https://example.org"))

    # 결과 대기
    result1 = await task1
    result2 = await task2

    return result1 + result2

# 실행
result = asyncio.run(main())
```

## 2. async/await 기초

### 2.1 첫 번째 비동기 함수

```python
import asyncio

# async 키워드로 코루틴 함수 정의
async def say_hello():
    print("👋 Hello")
    await asyncio.sleep(1)  # 비동기 대기 (블로킹 없음)
    print("👋 World")

# 실행
asyncio.run(say_hello())

# 출력:
# 👋 Hello
# (1초 대기)
# 👋 World
```

**핵심 개념**:
- `async def`: 코루틴 함수 정의
- `await`: 비동기 작업이 완료될 때까지 대기 (다른 작업은 계속 실행)
- `asyncio.run()`: 이벤트 루프 시작 및 코루틴 실행

### 2.2 동기 vs 비동기 비교

```python
import asyncio
import time

# 동기 방식
def sync_version():
    print("🐌 동기 시작")
    start = time.time()

    time.sleep(1)
    print("  작업 1 완료")

    time.sleep(1)
    print("  작업 2 완료")

    time.sleep(1)
    print("  작업 3 완료")

    print(f"⏱️  총 시간: {time.time() - start:.2f}초")

# 비동기 방식
async def async_version():
    print("🚀 비동기 시작")
    start = time.time()

    # 동시에 실행
    await asyncio.gather(
        task_async(1),
        task_async(2),
        task_async(3)
    )

    print(f"⏱️  총 시간: {time.time() - start:.2f}초")

async def task_async(n):
    await asyncio.sleep(1)
    print(f"  작업 {n} 완료")

if __name__ == '__main__':
    sync_version()
    # 출력:
    # 🐌 동기 시작
    #   작업 1 완료
    #   작업 2 완료
    #   작업 3 완료
    # ⏱️  총 시간: 3.00초

    print()

    asyncio.run(async_version())
    # 출력:
    # 🚀 비동기 시작
    #   작업 1 완료
    #   작업 2 완료
```

## 3. Task와 gather

### 3.1 Task 생성

**비유**: Task는 주문한 음식의 **진동벨**입니다. 여러 개를 동시에 가질 수 있습니다.

```python
import asyncio

async def download_file(file_id):
    print(f"📥 파일 {file_id} 다운로드 시작")
    await asyncio.sleep(2)  # 다운로드 시뮬레이션
    print(f"✅ 파일 {file_id} 완료")
    return f"file_{file_id}.dat"

async def main():
    # Task 생성 (즉시 시작됨!)
    task1 = asyncio.create_task(download_file(1))
    task2 = asyncio.create_task(download_file(2))
    task3 = asyncio.create_task(download_file(3))

    # 다른 작업 가능
    print("🎯 다른 작업 수행 중...")

    # 결과 대기
    file1 = await task1
    file2 = await task2
    file3 = await task3

    print(f"📁 다운로드된 파일: {file1}, {file2}, {file3}")

asyncio.run(main())

# 출력:
# 📥 파일 1 다운로드 시작
# 📥 파일 2 다운로드 시작
# 📥 파일 3 다운로드 시작
# 🎯 다른 작업 수행 중...
# ✅ 파일 1 완료
# ✅ 파일 2 완료
# ✅ 파일 3 완료
# 📁 다운로드된 파일: file_1.dat, file_2.dat, file_3.dat
```

### 3.2 asyncio.gather - 여러 작업 동시 실행

### 3.3 에러 처리

```python
import asyncio

async def risky_task(n):
    await asyncio.sleep(1)
    if n == 2:
        raise ValueError(f"작업 {n} 실패!")
    return f"작업 {n} 성공"

async def main_with_error_handling():
    try:
        # return_exceptions=True: 예외를 결과로 반환
        results = await asyncio.gather(
            risky_task(1),
            risky_task(2),
            risky_task(3),
            return_exceptions=True  # 중요!
        )

        for i, result in enumerate(results, 1):
            if isinstance(result, Exception):
                print(f"❌ 작업 {i}: {result}")
            else:
                print(f"✅ 작업 {i}: {result}")

    except Exception as e:
        print(f"❌ 전체 실패: {e}")

asyncio.run(main_with_error_handling())

# 출력:
# ✅ 작업 1: 작업 1 성공
# ❌ 작업 2: 작업 2 실패!
# ✅ 작업 3: 작업 3 성공
```

## 4. 실전 예제 - HTTP 요청

### 4.1 aiohttp로 웹 스크래핑

```python
import asyncio
import aiohttp
import time

async def fetch_url(session, url):
    """URL 비동기 다운로드"""
    async with session.get(url) as response:
        content = await response.text()
        print(f"✅ {url}: {len(content)} bytes")
        return {
            'url': url,
            'status': response.status,
            'length': len(content)
        }

async def fetch_all_urls(urls):
    """여러 URL 동시 다운로드"""
    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        results = await asyncio.gather(*tasks)
        return results

async def main():
    urls = [
        'https://www.python.org',
        'https://docs.python.org',
        'https://pypi.org',
        'https://www.djangoproject.com',
        'https://fastapi.tiangolo.com'
    ]

    print(f"📥 {len(urls)}개 URL 다운로드 시작...\n")

    start = time.time()
    results = await fetch_all_urls(urls)
    elapsed = time.time() - start

    print(f"\n⏱️  총 시간: {elapsed:.2f}초")
    print(f"📊 평균 속도: {len(urls) / elapsed:.2f} requests/sec")

if __name__ == '__main__':
    # 주의: aiohttp 설치 필요
    # pip install aiohttp
    asyncio.run(main())
```

### 4.2 API 호출 병렬 처리

```python
import asyncio
import aiohttp

async def call_api(session, endpoint, params):
    """API 호출"""
    url = f"https://api.example.com/{endpoint}"

    try:
        async with session.get(url, params=params, timeout=5) as response:
            data = await response.json()
            return {
                'endpoint': endpoint,
                'status': 'success',
                'data': data
            }

    except asyncio.TimeoutError:
        return {
            'endpoint': endpoint,
            'status': 'timeout',
            'data': None
        }

    except Exception as e:
        return {
            'endpoint': endpoint,
            'status': 'error',
            'error': str(e)
        }

async def fetch_user_dashboard(user_id):
    """사용자 대시보드 데이터 수집 (여러 API 동시 호출)"""
    async with aiohttp.ClientSession() as session:
        # 여러 API를 동시에 호출
        results = await asyncio.gather(
            call_api(session, 'user/profile', {'id': user_id}),
            call_api(session, 'user/orders', {'id': user_id}),
            call_api(session, 'user/notifications', {'id': user_id}),
            call_api(session, 'user/settings', {'id': user_id})
        )

        return {
            'profile': results[0],
            'orders': results[1],
            'notifications': results[2],
            'settings': results[3]
        }

async def main():
    user_id = 12345
    dashboard_data = await fetch_user_dashboard(user_id)

    print(f"📊 사용자 {user_id} 대시보드:")
    for key, value in dashboard_data.items():
        print(f"  {key}: {value['status']}")

if __name__ == '__main__':
    asyncio.run(main())
```

## 5. 고급 패턴

### 5.1 세마포어 - 동시 실행 제한

**비유**: 세마포어는 **주차장의 제한된 주차 공간**입니다. 동시에 N개만 실행됩니다.

```python
import asyncio
import aiohttp

async def download_with_semaphore(session, url, semaphore):
    """세마포어로 동시 다운로드 제한"""
    async with semaphore:  # 세마포어 획득
        print(f"📥 다운로드 시작: {url}")
        async with session.get(url) as response:
            content = await response.text()
            print(f"✅ 완료: {url} ({len(content)} bytes)")
            return content

async def download_all_with_limit(urls, max_concurrent=3):
    """동시 다운로드 수 제한"""
    semaphore = asyncio.Semaphore(max_concurrent)

    async with aiohttp.ClientSession() as session:
        tasks = [
            download_with_semaphore(session, url, semaphore)
            for url in urls
        ]
        results = await asyncio.gather(*tasks)
        return results

if __name__ == '__main__':
    urls = [f"https://httpbin.org/delay/1?id={i}" for i in range(10)]

    # 동시에 최대 3개만 실행
    asyncio.run(download_all_with_limit(urls, max_concurrent=3))
```

## 8. 실전 예제 - 웹 크롤러

### 8.1 완전한 비동기 크롤러

```python
import asyncio
import aiohttp
from bs4 import BeautifulSoup
from urllib.parse import urljoin, urlparse
import time

class AsyncWebCrawler:
    """비동기 웹 크롤러"""

    def __init__(self, max_concurrent=5, max_depth=2):
        self.max_concurrent = max_concurrent
        self.max_depth = max_depth
        self.visited = set()
        self.results = []

    async def fetch_page(self, session, url):
        """페이지 다운로드"""
        try:
            async with session.get(url, timeout=10) as response:
                if response.status == 200:
                    html = await response.text()
                    return html
                else:
                    print(f"❌ {url}: HTTP {response.status}")
                    return None

        except Exception as e:
            print(f"❌ {url}: {e}")
            return None

    def extract_links(self, html, base_url):
        """링크 추출"""
        soup = BeautifulSoup(html, 'html.parser')
        links = []

        for a_tag in soup.find_all('a', href=True):
            link = urljoin(base_url, a_tag['href'])

            # 동일 도메인만
            if urlparse(link).netloc == urlparse(base_url).netloc:
                links.append(link)

        return links

    async def crawl_page(self, session, url, depth, semaphore):
        """페이지 크롤링"""
        if depth > self.max_depth or url in self.visited:
            return

        self.visited.add(url)

        async with semaphore:
            print(f"{'  ' * depth}📄 크롤링: {url}")

            html = await self.fetch_page(session, url)
            if not html:
                return

            # 결과 저장
            self.results.append({
                'url': url,
                'depth': depth,
                'length': len(html)
            })

            # 링크 추출
            links = self.extract_links(html, url)

            # 하위 링크 크롤링
            if depth < self.max_depth:
                tasks = [
                    self.crawl_page(session, link, depth + 1, semaphore)
                    for link in links[:5]  # 최대 5개만
                ]
                await asyncio.gather(*tasks, return_exceptions=True)

    async def crawl(self, start_url):
        """크롤링 시작"""
        semaphore = asyncio.Semaphore(self.max_concurrent)

        async with aiohttp.ClientSession() as session:
            await self.crawl_page(session, start_url, 0, semaphore)

        return self.results

async def main():
    crawler = AsyncWebCrawler(max_concurrent=3, max_depth=1)

    start = time.time()
    results = await crawler.crawl('https://www.python.org')
    elapsed = time.time() - start

    print(f"\n✅ 크롤링 완료!")
    print(f"📊 방문한 페이지: {len(results)}개")
    print(f"⏱️  소요 시간: {elapsed:.2f}초")

if __name__ == '__main__':
    asyncio.run(main())
```

## 9. 스레드/프로세스와 함께 사용

### 9.1 CPU 집약적 작업을 비동기에서 실행

```python
import asyncio
from concurrent.futures import ProcessPoolExecutor
import time

def cpu_bound_task(n):
    """CPU 집약적 작업 (동기 함수)"""
    print(f"🧮 계산 중: {n}")
    result = sum(i * i for i in range(n))
    return result

async def run_cpu_tasks():
    """비동기 환경에서 CPU 작업 실행"""
    loop = asyncio.get_running_loop()

    # ProcessPoolExecutor 사용
    with ProcessPoolExecutor() as executor:
        tasks = [
            loop.run_in_executor(executor, cpu_bound_task, 5000000),
            loop.run_in_executor(executor, cpu_bound_task, 5000000),
            loop.run_in_executor(executor, cpu_bound_task, 5000000)
        ]

        results = await asyncio.gather(*tasks)

    print(f"✅ 결과: {results}")

asyncio.run(run_cpu_tasks())
```

### 9.2 동기 라이브러리를 비동기에서 사용

```python
import asyncio
import requests
from concurrent.futures import ThreadPoolExecutor

def sync_download(url):
    """동기 함수 (requests 라이브러리)"""
    response = requests.get(url)
    return len(response.content)

async def async_download_wrapper(url):
    """동기 함수를 비동기로 래핑"""
    loop = asyncio.get_running_loop()

    # ThreadPoolExecutor에서 실행
    with ThreadPoolExecutor() as executor:
        result = await loop.run_in_executor(executor, sync_download, url)

    return result

async def main():
    urls = [
        'https://www.python.org',
        'https://www.djangoproject.com',
        'https://fastapi.tiangolo.com'
    ]

    # 동기 함수를 비동기적으로 실행
    tasks = [async_download_wrapper(url) for url in urls]
    results = await asyncio.gather(*tasks)

    print(f"📊 다운로드 크기: {results}")

asyncio.run(main())
```

<summary>정답 보기</summary>

```python
import asyncio
import aiohttp
import aiofiles
import os

async def download_file(session, url, filename, semaphore):
    """파일 다운로드"""
    async with semaphore:
        try:
            print(f"📥 다운로드 시작: {filename}")

            async with session.get(url) as response:
                if response.status != 200:
                    print(f"❌ {filename}: HTTP {response.status}")
                    return

                # 파일 크기
                total_size = int(response.headers.get('content-length', 0))

                # 파일 쓰기
                downloaded = 0
                async with aiofiles.open(filename, 'wb') as f:
                    async for chunk in response.content.iter_chunked(1024):
                        await f.write(chunk)
                        downloaded += len(chunk)

                        # 진행률 표시
                        if total_size > 0:
                            percent = (downloaded / total_size) * 100
                            print(f"  {filename}: {percent:.1f}% ({downloaded}/{total_size})")

            print(f"✅ 완료: {filename}")
            return filename

        except Exception as e:
            print(f"❌ {filename}: {e}")
            return None

async def download_all(urls, max_concurrent=3):
    """여러 파일 동시 다운로드"""
    semaphore = asyncio.Semaphore(max_concurrent)

    async with aiohttp.ClientSession() as session:
        tasks = []
        for i, url in enumerate(urls):
            filename = f"download_{i}.dat"
            task = download_file(session, url, filename, semaphore)
            tasks.append(task)

        results = await asyncio.gather(*tasks)

    # 결과 요약
    successful = [r for r in results if r is not None]
    print(f"\n✅ 성공: {len(successful)}개")
    print(f"❌ 실패: {len(urls) - len(successful)}개")

if __name__ == '__main__':
    urls = [
        'https://httpbin.org/bytes/1024',
        'https://httpbin.org/bytes/2048',
        'https://httpbin.org/bytes/4096'
    ]
    asyncio.run(download_all(urls))
```

### 문제 3: 비동기 생산자-소비자
비동기 Queue를 사용한 생산자-소비자 패턴을 구현하세요.

<details>
<summary>정답 보기</summary>

```python
import asyncio
import random

async def producer(queue, producer_id, num_items):
    """생산자"""
    for i in range(num_items):
        item = f"P{producer_id}-Item{i}"
        await queue.put(item)
        print(f"📤 생산자 {producer_id}: {item} 생산")
        await asyncio.sleep(random.uniform(0.1, 0.5))

    print(f"✅ 생산자 {producer_id} 완료")

async def consumer(queue, consumer_id):
    """소비자"""
    while True:
        try:
            # 1초 타임아웃으로 대기
            item = await asyncio.wait_for(queue.get(), timeout=1.0)

            print(f"📥 소비자 {consumer_id}: {item} 처리 중...")
            await asyncio.sleep(random.uniform(0.2, 0.8))

            queue.task_done()

        except asyncio.TimeoutError:
            # 큐가 비어있고 타임아웃
            if queue.empty():
                print(f"🛑 소비자 {consumer_id} 종료")
                break

async def producer_consumer_pattern():
    """생산자-소비자 패턴"""
    queue = asyncio.Queue(maxsize=10)

    # 생산자 3개, 소비자 2개
    producers = [
        asyncio.create_task(producer(queue, i, 5))
        for i in range(3)
    ]

    consumers = [
        asyncio.create_task(consumer(queue, i))
        for i in range(2)
    ]

    # 생산자 완료 대기
    await asyncio.gather(*producers)

    # 큐의 모든 작업 완료 대기
    await queue.join()

    # 소비자 완료 대기
    await asyncio.gather(*consumers)

    print("\n✅ 모든 작업 완료!")

if __name__ == '__main__':
    asyncio.run(producer_consumer_pattern())
```

## 핵심 요약

1. **비동기 프로그래밍 개념**
   - 단일 스레드에서 여러 I/O 작업을 동시에 처리
   - CPU는 놀지 않고, 대기 시간에 다른 작업 수행
   - 협력적 멀티태스킹 (명시적 양보)

2. **핵심 문법**
   ```python
   # 코루틴 함수 정의
   async def my_function():
       result = await async_operation()
       return result

   # 실행
   asyncio.run(my_function())
   ```

3. **주요 패턴**
   - `asyncio.create_task()`: Task 생성
   - `asyncio.gather()`: 여러 작업 동시 실행
   - `asyncio.wait_for()`: 타임아웃 처리
   - `asyncio.as_completed()`: 완료 순서대로 처리

4. **언제 사용하나**
   - ✅ I/O 집약적 작업 (HTTP, DB, 파일)
   - ✅ 많은 수의 동시 연결
   - ❌ CPU 집약적 작업 (→ multiprocessing 사용)

5. **주의사항**
   - 블로킹 코드 사용 금지 (`time.sleep()` → `asyncio.sleep()`)
   - CPU 집약적 작업은 `run_in_executor()` 사용
   - 항상 `await` 키워드 사용

6. **Java와 비교**
   - Java: CompletableFuture, Project Reactor
   - Python: asyncio (더 직관적인 문법)
