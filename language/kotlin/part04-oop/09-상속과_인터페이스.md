# Chapter 9. 상속과 인터페이스

## 개요

Kotlin의 상속과 인터페이스는 Java와 유사하지만, **기본적으로 상속 불가능(final)**하다는 중요한 차이가 있습니다.

---

## 9.1 상속 (open, override)

### Kotlin의 상속 철학

**기본 원칙**: 모든 클래스는 기본적으로 `final`입니다.

```kotlin
class Person  // final, 상속 불가

// class Student : Person()  // 컴파일 에러!
// This type is final, so it cannot be inherited from
```

**이유**: "Effective Java" - *상속을 위해 설계되고 문서화되지 않은 클래스는 상속을 금지하라*

---

### open 키워드

상속을 허용하려면 `open` 키워드를 사용해야 합니다.

```kotlin
open class Person(val name: String, val age: Int) {
    open fun introduce() {
        println("안녕하세요, 저는 ${name}입니다.")
    }

    fun breathe() {
        println("숨을 쉽니다")
    }
}

class Student(
    name: String,
    age: Int,
    val studentId: String
) : Person(name, age) {

    override fun introduce() {
        println("안녕하세요, 학생 ${name}입니다. 학번: ${studentId}")
    }

    // breathe()는 open이 아니므로 오버라이드 불가
}

fun main() {
    val student = Student("홍길동", 20, "2024001")
    student.introduce()  // 안녕하세요, 학생 홍길동입니다. 학번: 2024001
    student.breathe()    // 숨을 쉽니다
}
```

### Java와 비교

**Java**:
```java
// Java - 기본적으로 상속 가능
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void introduce() {
        System.out.println("안녕하세요, 저는 " + name + "입니다.");
    }

    // final 메소드는 오버라이드 불가
    public final void breathe() {
        System.out.println("숨을 쉽니다");
    }
}

public class Student extends Person {
    private String studentId;

    public Student(String name, int age, String studentId) {
        super(name, age);
        this.studentId = studentId;
    }

    @Override
    public void introduce() {
        System.out.println("안녕하세요, 학생입니다.");
    }
}
```

**Kotlin**:
```kotlin
open class Person(val name: String, val age: Int) {
    open fun introduce() {
        println("안녕하세요, 저는 ${name}입니다.")
    }

    fun breathe() {  // final (기본값)
        println("숨을 쉽니다")
    }
}

class Student(
    name: String,
    age: Int,
    val studentId: String
) : Person(name, age) {
    override fun introduce() {
        println("안녕하세요, 학생입니다.")
    }
}
```

**차이점**:
- Java: 기본이 상속 가능, `final`로 막음
- Kotlin: 기본이 `final`, `open`으로 허용

### override 키워드

`override`는 **필수**입니다 (Java에서는 `@Override` 애노테이션이 선택).

```kotlin
open class Animal {
    open fun makeSound() {
        println("Some sound")
    }
}

class Dog : Animal() {
    override fun makeSound() {
        println("멍멍!")
    }
}

class Cat : Animal() {
    override fun makeSound() {
        println("야옹~")
    }
}

fun main() {
    val dog: Animal = Dog()
    val cat: Animal = Cat()

    dog.makeSound()  // 멍멍!
    cat.makeSound()  // 야옹~
}
```

### 오버라이드 금지

오버라이드한 메소드를 더 이상 오버라이드하지 못하게 하려면 `final`을 명시:

```kotlin
open class Animal {
    open fun makeSound() {
        println("Some sound")
    }
}

open class Dog : Animal() {
    final override fun makeSound() {
        println("멍멍!")
    }
}

class Puppy : Dog() {
    // override fun makeSound() { }  // 컴파일 에러! final이므로
}
```

### 프로퍼티 오버라이드

```kotlin
open class Shape {
    open val vertexCount: Int = 0
}

class Rectangle : Shape() {
    override val vertexCount = 4
}

class Triangle : Shape() {
    override val vertexCount = 3
}

fun main() {
    val rect: Shape = Rectangle()
    println(rect.vertexCount)  // 4

    val tri: Shape = Triangle()
    println(tri.vertexCount)   // 3
}
```

**val을 var로 오버라이드**:
```kotlin
open class Shape {
    open val area: Double = 0.0
}

class Circle(val radius: Double) : Shape() {
    override var area: Double = 0.0
        get() = Math.PI * radius * radius
}
```

### super 키워드

부모 클래스의 메소드나 프로퍼티에 접근:

```kotlin
open class Person(val name: String) {
    open fun introduce() {
        println("저는 ${name}입니다.")
    }
}

class Student(name: String, val studentId: String) : Person(name) {
    override fun introduce() {
        super.introduce()  // 부모 메소드 호출
        println("학번은 ${studentId}입니다.")
    }
}

fun main() {
    val student = Student("홍길동", "2024001")
    student.introduce()
    // 저는 홍길동입니다.
    // 학번은 2024001입니다.
}
```

## 9.2 추상 클래스

### 기본 개념

**추상 클래스**: 인스턴스화할 수 없으며, 추상 멤버를 포함할 수 있습니다.

```kotlin
abstract class Shape {
    abstract val area: Double
    abstract fun draw()

    // 일반 메소드도 가질 수 있음
    fun describe() {
        println("이 도형의 넓이는 ${area}입니다.")
    }
}

class Circle(val radius: Double) : Shape() {
    override val area: Double
        get() = Math.PI * radius * radius

    override fun draw() {
        println("원을 그립니다.")
    }
}

class Rectangle(val width: Double, val height: Double) : Shape() {
    override val area: Double
        get() = width * height

    override fun draw() {
        println("사각형을 그립니다.")
    }
}

fun main() {
    // val shape = Shape()  // 컴파일 에러! 추상 클래스는 인스턴스화 불가

    val circle = Circle(5.0)
    circle.draw()      // 원을 그립니다.
    circle.describe()  // 이 도형의 넓이는 78.53981633974483입니다.

    val rect = Rectangle(4.0, 5.0)
    rect.draw()        // 사각형을 그립니다.
    rect.describe()    // 이 도형의 넓이는 20.0입니다.
}
```

---

```kotlin
abstract class Base {
```

### Java와 비교

**Java**:
```java
public abstract class Shape {
    public abstract double getArea();
    public abstract void draw();

    public void describe() {
        System.out.println("Area: " + getArea());
    }
}

public class Circle extends Shape {
    private double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public void draw() {
        System.out.println("Drawing circle");
    }
}
```

**Kotlin**:
```kotlin
abstract class Shape {
    abstract val area: Double
    abstract fun draw()

    fun describe() {
        println("Area: $area")
    }
}

class Circle(val radius: Double) : Shape() {
    override val area get() = Math.PI * radius * radius
    override fun draw() = println("Drawing circle")
}
```

## 9.3 인터페이스

### 기본 사용법

```kotlin
interface Clickable {
    fun click()
    fun showOff() {  // 기본 구현 가능
        println("I'm clickable!")
    }
}

class Button : Clickable {
    override fun click() {
        println("Button clicked!")
    }
    // showOff는 오버라이드 선택 사항
}

fun main() {
    val button = Button()
    button.click()     // Button clicked!
    button.showOff()   // I'm clickable!
}
```

---

### 프로퍼티 선언

인터페이스에서 프로퍼티를 선언할 수 있습니다:

```kotlin
interface User {
    val nickname: String  // 추상 프로퍼티
    val email: String
        get() = "no-email"  // 기본 구현 (backing field 없음)
}

class PrivateUser(override val nickname: String) : User

class SubscribingUser(override val email: String) : User {
    override val nickname: String
        get() = email.substringBefore("@")
}

fun main() {
    val privateUser = PrivateUser("test123")
    println(privateUser.nickname)  // test123
    println(privateUser.email)     // no-email

    val subscribingUser = SubscribingUser("user@example.com")
    println(subscribingUser.nickname)  // user
    println(subscribingUser.email)     // user@example.com
}
```

---

### 여러 인터페이스 구현

```kotlin
interface Clickable {
    fun click()
    fun showOff() {
        println("I'm clickable!")
    }
}

interface Focusable {
    fun setFocus(focused: Boolean)
    fun showOff() {
        println("I'm focusable!")
    }
}

class Button : Clickable, Focusable {
    override fun click() {
        println("Clicked")
    }

    override fun setFocus(focused: Boolean) {
        println("Focus: $focused")
    }

    // 이름이 같은 메소드가 여러 인터페이스에 있으면 반드시 오버라이드
    override fun showOff() {
        super<Clickable>.showOff()  // I'm clickable!
        super<Focusable>.showOff()  // I'm focusable!
    }
}

fun main() {
    val button = Button()
    button.showOff()
    // I'm clickable!
    // I'm focusable!
}
```

## 9.4 인터페이스의 기본 구현

### Java 8+ default 메소드와 유사

```kotlin
interface Repository<T> {
    fun save(item: T)
    fun findById(id: Long): T?

    // 기본 구현
    fun saveAll(items: List<T>) {
        items.forEach { save(it) }
    }

    fun count(): Int {
        return 0  // 기본 구현
    }
}

class UserRepository : Repository<User> {
    private val users = mutableListOf<User>()

    override fun save(item: User) {
        users.add(item)
    }

    override fun findById(id: Long): User? {
        return users.find { it.id == id }
    }

    override fun count(): Int {
        return users.size
    }

    // saveAll은 기본 구현 사용
}
```

### 실전 예제: 로깅 인터페이스

```kotlin
interface Loggable {
    val loggerName: String
        get() = this::class.simpleName ?: "Unknown"

    fun log(message: String) {
        println("[$loggerName] $message")
    }

    fun logError(message: String, error: Throwable) {
        println("[$loggerName] ERROR: $message")
        println(error.stackTraceToString())
    }
}

class UserService : Loggable {
    fun createUser(name: String) {
        log("Creating user: $name")
        // ...
    }

    fun deleteUser(id: Long) {
        log("Deleting user: $id")
        // ...
    }
}

fun main() {
    val service = UserService()
    service.createUser("Alice")  // [UserService] Creating user: Alice
    service.deleteUser(1)        // [UserService] Deleting user: 1
}
```

## 9.5 다중 상속 문제 해결

### 다이아몬드 문제

```kotlin
interface A {
    fun foo() {
        println("A")
    }
}

interface B : A {
    override fun foo() {
        println("B")
    }
}

interface C : A {
    override fun foo() {
        println("C")
    }
}

class D : B, C {
    override fun foo() {
        super<B>.foo()  // B의 foo 호출
        super<C>.foo()  // C의 foo 호출
        println("D")
    }
}

fun main() {
    val d = D()
    d.foo()
    // B
    // C
    // D
}
```

### 충돌 해결

```kotlin
interface Drawable {

    }

    fun draw() {
```

```java
public abstract class Animal {
```

### 문제 1: 도형 계층 구조
추상 클래스 Shape을 만들고 Circle, Rectangle을 구현하세요.

<details>
<summary>정답 보기</summary>

```kotlin
abstract class Shape {
    abstract val area: Double
    abstract val perimeter: Double
    abstract fun draw()
}

class Circle(val radius: Double) : Shape() {
    override val area: Double
        get() = Math.PI * radius * radius

    override val perimeter: Double
        get() = 2 * Math.PI * radius

    override fun draw() {
        println("원을 그립니다 (반지름: $radius)")
    }
}

class Rectangle(val width: Double, val height: Double) : Shape() {
    override val area: Double
        get() = width * height

    override val perimeter: Double
        get() = 2 * (width + height)

    override fun draw() {
        println("사각형을 그립니다 (너비: $width, 높이: $height)")
    }
}

fun main() {
    val shapes: List<Shape> = listOf(
        Circle(5.0),
        Rectangle(4.0, 6.0)
    )

    shapes.forEach { shape ->
        shape.draw()
        println("넓이: ${shape.area}")
        println("둘레: ${shape.perimeter}")
        println()
    }
}
```

```kotlin
interface Drawable {
    fun draw()
}

interface Clickable {
    fun click()
    fun isEnabled(): Boolean = true  // 기본 구현

class Button(val text: String) : Drawable, Clickable {
    private var enabled = true

    override fun draw() {
        println("Drawing button: $text")

    button.click()  // Button 'Submit' is disabled
}
```

## 핵심 요약

### 꼭 기억할 것

1. **open 키워드**
   - 기본이 `final`
   - 상속 허용하려면 `open` 필요

2. **override 키워드**
   - 필수 (Java는 선택)
   - 실수 방지

3. **추상 클래스**
   - `abstract` 키워드
   - 추상 멤버는 자동으로 `open`

4. **인터페이스**
   - 기본 구현 가능
   - 프로퍼티 선언 가능
   - 다중 구현 가능

5. **Java 대비 차이**
   - 기본이 final (더 안전)
   - override 필수 (실수 방지)
   - 간결한 문법
