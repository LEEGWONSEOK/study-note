# Chapter 16. 스코프 함수

## 개요

스코프 함수(Scope Functions)는 객체의 컨텍스트 내에서 코드 블록을 실행하는 함수입니다. Kotlin 표준 라이브러리는 5가지 스코프 함수를 제공합니다: `let`, `run`, `with`, `apply`, `also`

---

## 16.1 let

### 기본 사용법

**특징**:
- 수신 객체: `it`
- 반환값: 람다 결과

```kotlin
val name = "Alice"

val result = name.let {
    println("Name: $it")
    it.uppercase()
}

println(result)  // ALICE
```

---

### Null 안전성

**가장 일반적인 용도**:

```kotlin
val nullableName: String? = getName()

// ❌ 명시적 null 체크
if (nullableName != null) {
    println(nullableName.length)
}

// ✅ let 사용
nullableName?.let {
    println(it.length)
}
```

---

### 체이닝

```kotlin
val user: User? = getUser()

user?.let {
    validateUser(it)
}?.let {
    saveUser(it)
}?.let {
    sendEmail(it)
}
```

---

### 실전 예제

```kotlin
// 사용자 정보 처리
fun processUser(userId: String?) {
    userId?.let { id ->
        findUser(id)
    }?.let { user ->
        validateUser(user)
        user
    }?.let { validUser ->
        saveToDatabase(validUser)
        sendWelcomeEmail(validUser)
    } ?: println("User processing failed")
}

// 설정 값 처리
fun loadConfig() {
    getConfigValue("api_key")?.let { apiKey ->
        println("API Key loaded: ${apiKey.take(5)}...")
        initializeApi(apiKey)
    } ?: println("API Key not found")
}
```

## 16.2 run

### 기본 사용법

**특징**:
- 수신 객체: `this`
- 반환값: 람다 결과

```kotlin
val result = "Hello".run {
    println("Length: $length")  // this.length
    uppercase()  // this.uppercase()
}

println(result)  // HELLO
```

---

### 객체 초기화와 계산

```kotlin
data class Person(var name: String, var age: Int)

val description = Person("Alice", 25).run {
    age += 1  // this.age
    "Name: $name, Age: $age"  // 마지막 표현식이 반환값
}

println(description)  // Name: Alice, Age: 26
```

---

### 실전 예제

```kotlin
// 복잡한 계산
fun calculateOrderTotal(order: Order): Double {
    return order.run {
        val subtotal = items.sumOf { it.price * it.quantity }
        val tax = subtotal * 0.1
        val shipping = if (subtotal > 50) 0.0 else 5.0
        subtotal + tax + shipping
    }
}

// 데이터베이스 쿼리
fun findUsers(criteria: SearchCriteria): List<User> {
    return database.run {
        val query = buildQuery(criteria)
        execute(query)
        fetchResults()
    }
}
```

## 16.3 with

### 기본 사용법

**특징**:
- 확장 함수 아님 (일반 함수)
- 수신 객체: `this`
- 반환값: 람다 결과

```kotlin
val person = Person("Alice", 25)

val description = with(person) {
    name = "Bob"  // this.name
    age = 30      // this.age
    "Name: $name, Age: $age"
}

println(description)  // Name: Bob, Age: 30
```

---

### 여러 메소드 호출

```kotlin
class StringBuilder {
    fun append(text: String): StringBuilder { /* ... */ }
    fun appendLine(text: String): StringBuilder { /* ... */ }
    override fun toString(): String { /* ... */ }
}

val result = with(StringBuilder()) {
    append("Hello")
    append(" ")
    append("World")
    appendLine("!")
    append("From Kotlin")
    toString()
}

println(result)
```

---

### 실전 예제

```kotlin
// 설정 객체 초기화
fun createServerConfig(): ServerConfig {
    return with(ServerConfig()) {
        host = "localhost"
        port = 8080
        timeout = 30
        maxConnections = 100
        this  // 객체 반환
    }
}

// 복잡한 UI 설정
fun setupView(view: View) {
    with(view) {
        setBackgroundColor(Color.WHITE)
        setPadding(16, 16, 16, 16)
        setOnClickListener { /* ... */ }
        visibility = View.VISIBLE
    }
}
```

## 16.4 apply

### 기본 사용법

**특징**:
- 수신 객체: `this`
- 반환값: **객체 자체**

```kotlin
val person = Person("", 0).apply {
    name = "Alice"  // this.name
    age = 25        // this.age
}

println(person)  // Person(name=Alice, age=25)
```

---

### 객체 초기화에 최적

```kotlin
// ✅ apply 사용
val textView = TextView(context).apply {
    text = "Hello"
    textSize = 20f
    setTextColor(Color.BLACK)
    gravity = Gravity.CENTER
}

// ❌ apply 없이
val textView2 = TextView(context)
textView2.text = "Hello"
textView2.textSize = 20f
textView2.setTextColor(Color.BLACK)
textView2.gravity = Gravity.CENTER
```

---

### 빌더 패턴 대체

```kotlin
data class User(
    var name: String = "",
    var email: String = "",
    var age: Int = 0,
    var phone: String = ""
)

val user = User().apply {
    name = "Alice"
    email = "alice@example.com"
    age = 25
    phone = "010-1234-5678"
}
```

### 실전 예제

```kotlin
// HTTP 요청 설정
fun createRequest(url: String): Request {
```

## 16.5 also

### 기본 사용법

**특징**:
- 수신 객체: `it`
- 반환값: **객체 자체**

```kotlin
val numbers = mutableListOf(1, 2, 3).also {
    println("초기값: $it")
}

numbers.add(4)
println(numbers)  // [1, 2, 3, 4]
```

---

### 부수 효과(로깅, 검증)

```kotlin
fun processUser(user: User): User {
    return user
        .also { println("Processing user: ${it.name}") }
        .also { validateUser(it) }
        .also { logger.info("User validated: ${it.id}") }
}
```

---

### 실전 예제

```kotlin
// 파일 작성 후 로깅
fun saveFile(filename: String, content: String): File {
    return File(filename).also {
        it.writeText(content)
        println("File saved: ${it.absolutePath}")
    }
}

// 데이터 저장 후 이벤트 발생
fun createOrder(order: Order): Order {
    return repository.save(order).also {
        eventPublisher.publish(OrderCreatedEvent(it))
        logger.info("Order created: ${it.id}")
    }
}

// 체이닝에서 중간 디버깅
fun processData(data: List<Int>): List<Int> {
    return data
        .filter { it > 0 }
        .also { println("After filter: $it") }
        .map { it * 2 }
        .also { println("After map: $it") }
        .sorted()
}
```

## 16.6 스코프 함수 선택 가이드

### 비교표

| 함수 | 객체 참조 | 반환값 | 용도 |
|------|-----------|--------|------|
| `let` | `it` | 람다 결과 | null 체크, 변환 |
| `run` | `this` | 람다 결과 | 객체 초기화 후 계산 |
| `with` | `this` | 람다 결과 | 여러 메소드 호출 |
| `apply` | `this` | 객체 자체 | 객체 설정 |
| `also` | `it` | 객체 자체 | 부수 효과 (로깅 등) |

---

### 선택 플로우차트

```
객체를 반환하고 싶은가?
├─ Yes
│  ├─ 객체 설정? → apply
│  └─ 부수 효과? → also
└─ No (계산 결과 반환)
   ├─ null 체크 필요? → let
   ├─ 확장 함수로? → run
   └─ 파라미터로? → with
```

---

### 실전 선택 가이드

```kotlin
// let: null 체크 + 변환
val length: Int? = nullableString?.let { it.length }

// run: 객체로 계산
val formatted: String = user.run {
    "$name ($age)"
}

// with: 여러 메소드 호출
val result = with(stringBuilder) {
    append("a")
    append("b")
    toString()
}

// apply: 객체 초기화
val user = User().apply {
    name = "Alice"
    age = 25
}

// also: 부수 효과 (로깅)
val savedUser = repository.save(user).also {
    logger.info("Saved: $it")
}
```

## 16.7 Java와 비교: 빌더 패턴 대체

### Java 빌더 패턴

**Java**:
```java
public class User {
    private String name;
    private String email;
    private int age;

    public static class Builder {
        private String name;
        private String email;
        private int age;

        public Builder name(String name) {
            this.name = name;
            return this;
        }

        public Builder email(String email) {
            this.email = email;
            return this;
        }

        public Builder age(int age) {
            this.age = age;
            return this;
        }

        public User build() {
            User user = new User();
            user.name = this.name;
            user.email = this.email;
            user.age = this.age;
            return user;
        }
    }
}

// 사용
User user = new User.Builder()
    .name("Alice")
    .email("alice@example.com")
    .age(25)
    .build();
```

**Kotlin**:
```kotlin
data class User(
    var name: String = "",

    var age: Int = 0
)

    name = "Alice"
```

## 실전 팁

### 💡 Tip 1: let으로 null 안전성

```kotlin
// ✅ let 사용
fun processUser(user: User?) {
    user?.let {
        validateUser(it)
        saveUser(it)
        notifyUser(it)
    } ?: println("User is null")
}

// ❌ 명시적 체크
fun processUser(user: User?) {
    if (user != null) {
        validateUser(user)
        saveUser(user)
        notifyUser(user)
    } else {
        println("User is null")
    }
}
```

---

### 💡 Tip 2: apply로 객체 초기화

```kotlin
// ✅ apply
val request = HttpRequest().apply {
    url = "https://api.example.com"
    method = "POST"
    body = jsonBody
    headers["Authorization"] = token
}

// ❌ 반복적인 코드
val request = HttpRequest()
request.url = "https://api.example.com"
request.method = "POST"
request.body = jsonBody
request.headers["Authorization"] = token
```

---

### 💡 Tip 3: also로 로깅/디버깅

```kotlin
fun processData(data: List<Int>): List<Int> {
    return data
        .filter { it > 0 }
        .also { println("Positive numbers: $it") }
        .map { it * 2 }
        .also { println("Doubled: $it") }
        .sorted()
        .also { println("Final result: $it") }
}
```

---

### 💡 Tip 4: 중첩 피하기

```kotlin
// ❌ 중첩된 스코프 함수
val result = data.let {
    it.filter { item ->
        item.value > 0
    }.let { filtered ->
        filtered.map { item ->
            item.value * 2
        }
    }
}

// ✅ 체이닝
val result = data
    .filter { it.value > 0 }
    .map { it.value * 2 }
```

## 연습 문제

### 문제 1: 적절한 스코프 함수 선택

<details>
<summary>정답 보기</summary>

```kotlin
data class Config(
    var host: String = "",
    var port: Int = 0,
    var timeout: Int = 0
)

// apply - 객체 초기화
fun createConfig(): Config {
    return Config().apply {
        host = "localhost"
        port = 8080
        timeout = 30
    }
}

// let - null 체크
fun processConfig(config: Config?) {
    config?.let {
        println("Connecting to ${it.host}:${it.port}")
    }
}

// also - 로깅
fun saveConfig(config: Config): Config {
    return config.also {
        println("Saving config: $it")
    }
}
```
</details>

### 문제 2: 스코프 함수로 리팩토링

<details>
<summary>정답 보기</summary>

```kotlin
// Before
fun createUser(name: String, email: String, age: Int): User {
    val user = User()
    user.name = name
    user.email = email
    user.age = age

    validateUser(user)
    val savedUser = repository.save(user)
    logger.info("User created: ${savedUser.id}")

    return savedUser
}

// After
fun createUser(name: String, email: String, age: Int): User {
    return User().apply {
        this.name = name
        this.email = email
        this.age = age
    }.also {
        validateUser(it)
    }.let {
        repository.save(it)
    }.also {
        logger.info("User created: ${it.id}")
    }
}
```
</details>

## 핵심 요약

### 꼭 기억할 것

1. **let**
   - null 안전성
   - 변환
   - `it` / 람다 결과

2. **run**
   - 객체로 계산
   - `this` / 람다 결과

3. **with**
   - 여러 메소드 호출
   - `this` / 람다 결과
   - 확장 함수 아님

4. **apply**
   - 객체 초기화
   - `this` / 객체 자체

5. **also**
   - 부수 효과
   - `it` / 객체 자체
