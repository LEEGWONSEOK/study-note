# Chapter 8. 람다와 고차 함수

## 개요

람다와 고차 함수는 Kotlin 함수형 프로그래밍의 핵심입니다. Java 8+의 람다보다 훨씬 강력하고 유연합니다.

---

## 8.1 람다 표현식 기초

### 람다란?

**람다(Lambda)**: 이름 없는 함수, 함수 리터럴

**기본 문법**:
```kotlin
{ 파라미터 -> 본문 }
```

---

### 간단한 예제

```kotlin
// 일반 함수
fun sum(a: Int, b: Int): Int {
    return a + b
}

// 람다로 표현
val sum = { a: Int, b: Int -> a + b }

// 사용
println(sum(3, 5))  // 8
```

---

### 컬렉션에서 람다 사용

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

// 람다로 짝수 필터링
val evenNumbers = numbers.filter { number -> number % 2 == 0 }
println(evenNumbers)  // [2, 4]

// 람다로 제곱
val squares = numbers.map { number -> number * number }
println(squares)  // [1, 4, 9, 16, 25]
```

---

### Java와 비교

**Java 8+**:
```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// 람다 사용
List<Integer> evenNumbers = numbers.stream()
    .filter(number -> number % 2 == 0)
    .collect(Collectors.toList());

// 메소드 참조
List<Integer> doubled = numbers.stream()
    .map(n -> n * 2)
    .collect(Collectors.toList());
```

**Kotlin**:
```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

val evenNumbers = numbers.filter { number -> number % 2 == 0 }
val doubled = numbers.map { n -> n * 2 }
```

**차이점**:
- ✅ Stream 생성 불필요
- ✅ collect() 불필요
- ✅ 마지막 파라미터가 람다면 괄호 밖으로 뺄 수 있음

## 8.2 고차 함수 (Higher-order Functions)

### 개념

**고차 함수**: 함수를 파라미터로 받거나 함수를 반환하는 함수

---

### 함수를 파라미터로 받기

```kotlin
// 고차 함수 정의
fun calculate(a: Int, b: Int, operation: (Int, Int) -> Int): Int {
    return operation(a, b)
}

// 사용
val sum = calculate(3, 5) { a, b -> a + b }
val product = calculate(3, 5) { a, b -> a * b }
val max = calculate(3, 5) { a, b -> if (a > b) a else b }

println(sum)      // 8
println(product)  // 15
println(max)      // 5
```

---

### 실전 예제: 리스트 처리

```kotlin
fun processNumbers(
    numbers: List<Int>,
    processor: (Int) -> Int
): List<Int> {
    return numbers.map(processor)
}

val numbers = listOf(1, 2, 3, 4, 5)

val doubled = processNumbers(numbers) { it * 2 }
val squared = processNumbers(numbers) { it * it }

println(doubled)  // [2, 4, 6, 8, 10]
println(squared)  // [1, 4, 9, 16, 25]
```

---

### 함수를 반환하기

```kotlin
fun makeMultiplier(factor: Int): (Int) -> Int {
    return { number -> number * factor }
}

val double = makeMultiplier(2)
val triple = makeMultiplier(3)

println(double(5))  // 10
println(triple(5))  // 15
```

**실전 예제**:
```kotlin
fun makeGreeting(prefix: String): (String) -> String {
    return { name -> "$prefix, $name!" }
}

val hello = makeGreeting("Hello")
val hi = makeGreeting("Hi")

println(hello("Alice"))   // Hello, Alice!
println(hi("Bob"))        // Hi, Bob!
```

---

### 표준 라이브러리 고차 함수

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

// filter: (T) -> Boolean
val even = numbers.filter { it % 2 == 0 }

// map: (T) -> R
val squared = numbers.map { it * it }

// forEach: (T) -> Unit
numbers.forEach { println(it) }

// any: (T) -> Boolean
val hasEven = numbers.any { it % 2 == 0 }

// all: (T) -> Boolean
val allPositive = numbers.all { it > 0 }

// none: (T) -> Boolean
val noNegative = numbers.none { it < 0 }
```

## 8.3 it 키워드

### 암시적 파라미터 이름

파라미터가 하나인 람다는 `it`을 사용할 수 있습니다.

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

// 명시적 파라미터
val doubled1 = numbers.map { number -> number * 2 }

// it 사용 (더 간결)
val doubled2 = numbers.map { it * 2 }

// 체이닝에서 it
val result = numbers
    .filter { it % 2 == 0 }
    .map { it * it }
    .sum()

println(result)  // 20 (2² + 4² = 4 + 16)
```

---

### it을 사용하지 말아야 할 때

**중첩된 람다**:
```kotlin
val lists = listOf(
    listOf(1, 2, 3),
    listOf(4, 5, 6)
)

// ❌ 혼란스러움
val result1 = lists.map {
    it.map { it * 2 }  // 어떤 it?
}

// ✅ 명확함
val result2 = lists.map { list ->
    list.map { number -> number * 2 }
}
```

**복잡한 로직**:
```kotlin
// ❌ it이 무엇인지 불명확
users.filter { it.age > 18 && it.isActive && it.email != null }

// ✅ 더 명확
users.filter { user ->
    user.age > 18 && user.isActive && user.email != null
}
```

## 8.4 함수 타입

### 함수 타입 선언

```kotlin
// 타입 지정
val sum: (Int, Int) -> Int = { a, b -> a + b }
val greet: (String) -> String = { name -> "Hello, $name!" }
val print: (String) -> Unit = { message -> println(message) }

// 사용
println(sum(3, 5))        // 8
println(greet("Alice"))   // Hello, Alice!
print("Test")             // Test
```

---

### Nullable 함수 타입

```kotlin
var operation: ((Int, Int) -> Int)? = null

operation = { a, b -> a + b }

// 안전 호출
val result = operation?.invoke(3, 5)
println(result)  // 8

// 또는
if (operation != null) {
    println(operation(3, 5))  // 8
}
```

---

### 함수 타입을 파라미터로

```kotlin
fun executeOperation(
    a: Int,
    b: Int,
    operation: (Int, Int) -> Int
): Int {
    println("Executing operation...")
    return operation(a, b)
}

val result = executeOperation(10, 5) { a, b -> a - b }
println(result)  // 5
```

---

### 기본값을 가진 함수 타입

```kotlin
fun processString(
    str: String,
    transformer: (String) -> String = { it.uppercase() }
): String {
    return transformer(str)
}

println(processString("hello"))  // HELLO (기본값 사용)
println(processString("hello") { it.lowercase() })  // hello
```

## 8.5 인라인 함수 (inline)

### 개념

**inline**: 함수 호출을 함수 본문으로 치환하여 성능 향상

---

### 왜 필요한가?

**람다는 객체로 생성됩니다** (오버헤드 발생):

```kotlin
// 이 코드는...
fun processNumbers(numbers: List<Int>, action: (Int) -> Unit) {
    for (number in numbers) {
        action(number)
    }
}

processNumbers(listOf(1, 2, 3)) { println(it) }

// 내부적으로 이렇게 컴파일됩니다 (간소화)
processNumbers(listOf(1, 2, 3), object : Function1<Int, Unit> {
    override fun invoke(number: Int) {
        println(number)
    }
})
```

---

### inline 사용

```kotlin
inline fun processNumbers(numbers: List<Int>, action: (Int) -> Unit) {
    for (number in numbers) {
        action(number)
    }
}

processNumbers(listOf(1, 2, 3)) { println(it) }

// inline이면 이렇게 컴파일됩니다
for (number in listOf(1, 2, 3)) {
    println(number)
}
// 람다 객체 생성 없음!
```

---

### 표준 라이브러리의 inline 함수

대부분의 컬렉션 함수는 `inline`입니다:

```kotlin
// kotlin.collections
public inline fun <T> Iterable<T>.filter(
    predicate: (T) -> Boolean
): List<T> {
    // ...
}

public inline fun <T, R> Iterable<T>.map(
    transform: (T) -> R
): List<R> {
    // ...
}
```

---

### noinline - 일부 람다만 제외

```kotlin
inline fun processNumbers(
    numbers: List<Int>,
    action: (Int) -> Unit,
    noinline logger: ((String) -> Unit)? = null
) {
    logger?.invoke("Processing started")
    for (number in numbers) {
        action(number)
    }
    logger?.invoke("Processing completed")
}
```

---

### crossinline - non-local return 방지

```kotlin
inline fun runOperation(crossinline operation: () -> Unit) {
    val runnable = Runnable {
        operation()  // crossinline이 없으면 에러
    }
    runnable.run()
}

fun test() {
    runOperation {
        println("Running")
        // return  // crossinline이므로 non-local return 불가
    }
}
```

## 8.6 수신 객체 지정 람다

### 개념

**수신 객체 지정 람다**: `this`로 특정 객체에 접근하는 람다

---

### 함수 타입과 확장 함수 타입

```kotlin
// 일반 함수 타입
val normalLambda: (String) -> String = { str -> str.uppercase() }

// 확장 함수 타입 (수신 객체 지정)
val extensionLambda: String.() -> String = { this.uppercase() }

// 사용
println(normalLambda("hello"))       // HELLO
println("hello".extensionLambda())   // HELLO
```

---

### with 함수

```kotlin
data class Person(var name: String, var age: Int)

val person = Person("Alice", 25)

// with: 수신 객체를 this로 접근
val description = with(person) {
    name = "Bob"  // this.name
    age = 30      // this.age
    "Name: $name, Age: $age"
}

println(description)  // Name: Bob, Age: 30
println(person)       // Person(name=Bob, age=30)
```

---

### apply 함수

```kotlin
data class Person(var name: String = "", var age: Int = 0)

// apply: 객체 설정 후 객체 자체를 반환
val person = Person().apply {
    name = "Alice"
    age = 25
}

println(person)  // Person(name=Alice, age=25)
```

**실전 예제**:
```kotlin
val textView = TextView(context).apply {
    text = "Hello"
    textSize = 20f
    setTextColor(Color.BLACK)
}
```

---

### also 함수

```kotlin
data class Person(val name: String, val age: Int)

// also: 부수 효과 수행 후 객체 반환
val person = Person("Alice", 25).also {
    println("Created: $it")
    logger.info("Person created: ${it.name}")
}
```

---

### let 함수

```kotlin
val name: String? = "Alice"

// let: 결과 변환
val length = name?.let {
    println("Name: $it")
    it.length
}

println(length)  // 5
```

---

### run 함수

```kotlin
data class Person(var name: String, var age: Int)

val person = Person("Alice", 25)

// run: 수신 객체에 대해 작업 수행 후 결과 반환
val description = person.run {
    age += 1
    "Name: $name, Age: $age"
}

println(description)  // Name: Alice, Age: 26
```

---

### 스코프 함수 비교

| 함수 | 수신 객체 | 반환 값 | 주 용도 |
|------|-----------|---------|---------|
| let | it | 람다 결과 | null 체크, 변환 |
| run | this | 람다 결과 | 객체 초기화, 계산 |
| with | this | 람다 결과 | 여러 메소드 호출 |
| apply | this | 객체 자체 | 객체 설정 |
| also | it | 객체 자체 | 부수 효과 |

---

### 실전 예제

```kotlin
data class User(
    var name: String = "",
    var email: String = "",
    var age: Int = 0
)

fun createUser(): User {
    return User().apply {
        name = "Alice"
        email = "alice@example.com"
        age = 25
    }.also {
        println("User created: $it")
        database.save(it)
    }
}

fun processUser(user: User?) {
    user?.let {
        validateUser(it)
        sendEmail(it.email)
    } ?: println("No user to process")
}

fun updateUserAge(user: User): String {
    return user.run {

        "Updated age to $age"
    }
}
```

### 커스텀 수신 객체 지정 람다

```kotlin
// HTML DSL 예제
fun html(init: HTML.() -> Unit): HTML {
    val html = HTML()
    html.init()
    return html
}

class HTML {
    private val children = mutableListOf<String>()

    fun head(init: Head.() -> Unit) {
        val head = Head()
        head.init()
        children.add(head.toString())
    }

    fun body(init: Body.() -> Unit) {
        val body = Body()
        body.init()
        children.add(body.toString())
    }

    override fun toString() = "<html>${children.joinToString("")}</html>"
}

class Head {
    var title = ""
    override fun toString() = "<head><title>$title</title></head>"
}

class Body {
    private val children = mutableListOf<String>()

    fun h1(text: String) {
        children.add("<h1>$text</h1>")
    }

    fun p(text: String) {
        children.add("<p>$text</p>")
    }

    override fun toString() = "<body>${children.joinToString("")}</body>"
}

// 사용
val page = html {
    head {
        title = "Kotlin DSL"
    }
    body {
        h1("Hello, Kotlin!")
        p("This is a DSL example.")
    }
}

println(page)
// <html><head><title>Kotlin DSL</title></head><body><h1>Hello, Kotlin!</h1><p>This is a DSL example.</p></body></html>
```

### 💡 Tip 3: 고차 함수로 중복 제거

```kotlin
// ❌ 중복된 코드
fun saveUser(user: User) {
    database.beginTransaction()
    try {
        database.save(user)
        database.commit()
    } catch (e: Exception) {
        database.rollback()
        throw e
    }
}

fun deleteUser(id: Long) {
    database.beginTransaction()
    try {
        database.delete(id)
        database.commit()
    } catch (e: Exception) {
        database.rollback()
        throw e
    }
}

// ✅ 고차 함수로 리팩토링
fun <T> transaction(block: () -> T): T {
    database.beginTransaction()
    return try {
        val result = block()
        database.commit()
        result
    } catch (e: Exception) {
        database.rollback()
        throw e
    }
}

fun saveUser(user: User) = transaction {
    database.save(user)
}

fun deleteUser(id: Long) = transaction {
    database.delete(id)
}
```

## 핵심 요약

### 꼭 기억할 것

1. **람다 표현식**
   - `{ 파라미터 -> 본문 }`
   - 파라미터 하나면 `it` 사용 가능

2. **고차 함수**
   - 함수를 파라미터로 받거나 반환
   - 코드 재사용성 향상

3. **인라인 함수**
   - `inline` 키워드
   - 람다 오버헤드 제거

4. **스코프 함수**
   - `let`, `run`, `with`, `apply`, `also`
   - 각각의 용도에 맞게 사용

5. **수신 객체 지정 람다**
   - `Type.() -> ReturnType`
   - DSL 구축에 활용
