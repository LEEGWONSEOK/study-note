# Chapter 12. 제네릭

## 개요

제네릭은 타입을 파라미터화하여 재사용 가능한 코드를 작성하는 기법입니다. Kotlin의 제네릭은 Java보다 더 강력하고 안전합니다.

---

## 12.1 제네릭 기초

### 제네릭 클래스

```kotlin
class Box<T>(val value: T)

fun main() {
    val intBox = Box(42)
    val stringBox = Box("Hello")

    println(intBox.value)     // 42
    println(stringBox.value)  // Hello
}
```

### 제네릭 함수

```kotlin
fun <T> printItem(item: T) {
    println("Item: $item")
}

fun <T> listOf(vararg items: T): List<T> {
    return items.toList()
}

fun main() {
```

### 타입 파라미터 명명 규칙

| 이름 | 의미 |
|------|------|
| T | Type (일반적인 타입) |
| E | Element (컬렉션 요소) |
| K | Key (맵의 키) |
| V | Value (맵의 값) |
| R | Return (반환 타입) |

```kotlin
class Pair<K, V>(val key: K, val value: V)

fun <T, R> transform(item: T, converter: (T) -> R): R {
    return converter(item)
}
```

## 12.3 변성 (Variance): in, out

### 공변성 (Covariance): out

**out**: 생산자 역할, 타입 파라미터를 반환만 할 수 있음

```kotlin
interface Producer<out T> {
    fun produce(): T
    // fun consume(item: T)  // 컴파일 에러! out은 반환 위치에만
}

class StringProducer : Producer<String> {
    override fun produce() = "Hello"
}

fun main() {
    val stringProducer: Producer<String> = StringProducer()
    val anyProducer: Producer<Any> = stringProducer  // OK! 공변성

    println(anyProducer.produce())  // Hello
}
```

---

### 반공변성 (Contravariance): in

**in**: 소비자 역할, 타입 파라미터를 파라미터로만 받을 수 있음

```kotlin
interface Consumer<in T> {
    fun consume(item: T)
    // fun produce(): T  // 컴파일 에러! in은 파라미터 위치에만
}

class AnyConsumer : Consumer<Any> {
    override fun consume(item: Any) {
        println("Consumed: $item")
    }
}

fun main() {
    val anyConsumer: Consumer<Any> = AnyConsumer()
    val stringConsumer: Consumer<String> = anyConsumer  // OK! 반공변성

    stringConsumer.consume("Hello")  // Consumed: Hello
}
```

---

### 실전 예제: List vs MutableList

```kotlin
// List<out E>: 공변성 (읽기 전용)
interface List<out E> {
    fun get(index: Int): E  // OK
    // fun add(element: E)  // 불가능
}

// MutableList<E>: 무공변 (읽기/쓰기)
interface MutableList<E> : List<E> {
    fun add(element: E)  // OK
}

fun printNumbers(numbers: List<Number>) {
    for (number in numbers) {
        println(number)
    }
}

fun main() {
    val integers: List<Int> = listOf(1, 2, 3)
    printNumbers(integers)  // OK! List는 공변성

    // val mutableIntegers: MutableList<Int> = mutableListOf(1, 2, 3)
    // printMutableNumbers(mutableIntegers)  // 에러! MutableList는 무공변
}
```

---

### Java와 비교

**Java**:
```java
// Java - 사용 지점 변성 (use-site variance)
List<String> strings = new ArrayList<>();
List<? extends Object> objects = strings;  // 공변성

List<Object> objectList = new ArrayList<>();
List<? super String> stringList = objectList;  // 반공변성
```

**Kotlin**:
```kotlin
// Kotlin - 선언 지점 변성 (declaration-site variance)
interface List<out E>  // 공변성 (선언 시점에 결정)

interface Comparator<in T>  // 반공변성
```

**차이점**:
- Java: 사용할 때마다 `<? extends>`, `<? super>` 지정
- Kotlin: 선언할 때 `out`, `in` 지정 (더 간결)

## 12.4 타입 소거와 reified

### 타입 소거 (Type Erasure)

제네릭 타입 정보는 **런타임에 소거**됩니다.

```kotlin
fun <T> isListOfType(value: Any): Boolean {
    // return value is List<T>  // 컴파일 에러! 타입 소거
    return value is List<*>  // OK (star projection)
}

fun main() {
    val list = listOf(1, 2, 3)
    println(list is List<Int>)  // 컴파일 에러!
    println(list is List<*>)    // OK
}
```

---

### reified - 실체화된 타입 파라미터

**`reified`**: 인라인 함수에서 타입 파라미터를 실제 타입으로 사용 가능

```kotlin
inline fun <reified T> isType(value: Any): Boolean {
    return value is T  // OK! reified 덕분에
}

inline fun <reified T> List<*>.filterIsInstance(): List<T> {
    return this.filter { it is T }.map { it as T }
}

fun main() {
    val value: Any = "Hello"
    println(isType<String>(value))  // true
    println(isType<Int>(value))     // false

    val mixed: List<Any> = listOf(1, "two", 3, "four", 5)
    val strings = mixed.filterIsInstance<String>()
    val integers = mixed.filterIsInstance<Int>()

    println(strings)   // [two, four]
    println(integers)  // [1, 3, 5]
}
```

---

### 실전 예제: JSON 파싱

```kotlin
// JSON 파싱에 reified 활용
inline fun <reified T> parseJson(json: String): T {
    // T의 실제 타입을 알 수 있음
    return when (T::class) {
        String::class -> json as T
        Int::class -> json.toInt() as T
        else -> throw IllegalArgumentException("Unsupported type")
    }
}

inline fun <reified T> fromJson(json: String): T {
    // Gson, Jackson 등의 라이브러리 사용
    // return Gson().fromJson(json, T::class.java)
    return json as T  // 간소화된 예제
}

fun main() {
    val string = parseJson<String>("Hello")
    val number = parseJson<Int>("42")

    println(string)  // Hello
    println(number)  // 42
}
```

## 12.5 제네릭 제약

### 상한 제약 (Upper Bound)

```kotlin
fun <T : Number> sum(a: T, b: T): Double {
    return a.toDouble() + b.toDouble()
}

fun <T : Comparable<T>> max(a: T, b: T): T {
    return if (a > b) a else b
}

fun main() {
    println(sum(10, 20))      // 30.0
    println(sum(1.5, 2.5))    // 4.0
    // println(sum("a", "b"))  // 컴파일 에러! String은 Number가 아님

    println(max(10, 20))      // 20
    println(max("abc", "xyz"))  // xyz
}
```

---

### 여러 제약

```kotlin
interface Named {
    val name: String
}

fun <T> printName(item: T) where T : Named, T : Comparable<T> {
    println(item.name)
}

data class Person(
    override val name: String,
    val age: Int

    override fun compareTo(other: Person) = age.compareTo(other.age)
}

fun main() {

}
```

### 실전 예제: Repository 패턴

```kotlin
interface Entity {
    val id: Long
}

data class User(override val id: Long, val name: String) : Entity
data class Product(override val id: Long, val title: String) : Entity

class Repository<T : Entity> {
    private val items = mutableListOf<T>()

    fun save(item: T) {
        items.add(item)
    }

    fun findById(id: Long): T? {
        return items.find { it.id == id }
    }

    fun findAll(): List<T> {
        return items.toList()
    }

    fun delete(id: Long) {
        items.removeIf { it.id == id }
    }
}

fun main() {
    val userRepo = Repository<User>()
    userRepo.save(User(1, "Alice"))
    userRepo.save(User(2, "Bob"))

    println(userRepo.findById(1))  // User(id=1, name=Alice)
    println(userRepo.findAll())    // [User(id=1, name=Alice), User(id=2, name=Bob)]
}
```

## 12.6 Java와 비교: 제네릭 처리

### 와일드카드 vs 변성

**Java**:
```java
// 공변성
List<? extends Number> numbers = new ArrayList<Integer>();

// 반공변성
List<? super Integer> integers = new ArrayList<Number>();

// PECS: Producer Extends, Consumer Super
public <T> void copy(
    List<? extends T> source,
    List<? super T> destination
) {
    for (T item : source) {
        destination.add(item);
    }
}
```

**Kotlin**:
```kotlin
// 공변성 (선언 지점)
interface List<out E>

// 반공변성 (선언 지점)
interface Comparator<in T>

// 함수에서
fun <T> copy(
    source: List<T>,      // out 불필요 (List가 이미 out)
    destination: MutableList<in T>  // 사용 지점 변성
) {
    for (item in source) {
        destination.add(item)
    }
}
```

```kotlin
class Stack<T> {
    private val items = mutableListOf<T>()

    fun push(item: T) {
        items.add(item)
    }

    fun pop(): T? {
        return if (items.isNotEmpty()) {
            items.removeAt(items.lastIndex)
        } else {
            null
        }
    }

    fun peek(): T? {
        return items.lastOrNull()
    }

    fun isEmpty() = items.isEmpty()

    fun size() = items.size
}

fun main() {
    val stack = Stack<Int>()

    stack.push(1)
    stack.push(2)
    stack.push(3)

    println(stack.pop())   // 3
    println(stack.peek())  // 2
    println(stack.size())  // 2
}
```

### 문제 2: 제네릭 변환 함수

```kotlin
fun <T, R> List<T>.mapCustom(transform: (T) -> R): List<R> {
    val result = mutableListOf<R>()
    for (item in this) {
        result.add(transform(item))
    }
    return result
}

fun <T> List<T>.filterCustom(predicate: (T) -> Boolean): List<T> {
    val result = mutableListOf<T>()
    for (item in this) {
        if (predicate(item)) {
            result.add(item)
        }
    }
    return result
}

fun main() {
    val numbers = listOf(1, 2, 3, 4, 5)

    val doubled = numbers.mapCustom { it * 2 }
    println(doubled)  // [2, 4, 6, 8, 10]

    val evens = numbers.filterCustom { it % 2 == 0 }
    println(evens)  // [2, 4]
}
```

### 문제 3: reified를 사용한 타입 체크

<details>
<summary>정답 보기</summary>

```kotlin
inline fun <reified T> checkType(value: Any): String {
    return when {
        value is T -> "${value} is ${T::class.simpleName}"
        else -> "${value} is not ${T::class.simpleName}"
    }
}

inline fun <reified T> List<*>.countOfType(): Int {
    return this.count { it is T }
}

fun main() {
    println(checkType<String>("Hello"))  // Hello is String
    println(checkType<Int>("Hello"))     // Hello is not Int

    val mixed: List<Any> = listOf(1, "two", 3, "four", 5.0)
    println("Strings: ${mixed.countOfType<String>()}")  // 2
    println("Integers: ${mixed.countOfType<Int>()}")    // 2
    println("Doubles: ${mixed.countOfType<Double>()}")  // 1
}
```

## 핵심 요약

### 꼭 기억할 것

1. **제네릭 기본**
   - `class Box<T>`, `fun <T>`
   - 타입 안전성 제공

2. **변성**
   - `out T`: 공변성 (Producer)
   - `in T`: 반공변성 (Consumer)

3. **reified**
   - 인라인 함수에서만 사용
   - 런타임에 타입 정보 유지

4. **제약**
   - `<T : SuperType>`
   - 여러 제약: `where` 사용

5. **Star Projection**
   - `List<*>`: 타입을 모를 때
