## 2.2 macOS 설치 (Homebrew)

### 설치

```bash
# 1. Homebrew 설치 (없으면)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. PostgreSQL 설치
brew install postgresql@15

# 3. 버전 확인
postgres --version
# postgresql (PostgreSQL) 15.x

# 4. 서비스 시작
brew services start postgresql@15

# 5. 서비스 상태 확인
brew services list
# Name          Status  User
# postgresql@15 started quan.io

# 6. 서비스 중지 (필요 시)
brew services stop postgresql@15
```

### 초기 설정

```bash
# 1. 기본 데이터베이스 접속
psql postgres

# 2. 사용자 목록 확인
\du

# 3. 데이터베이스 목록
\l

# 4. 종료
\q
```

### 환경변수 (선택)

```bash
# ~/.zshrc 또는 ~/.bashrc
export PATH="/opt/homebrew/opt/postgresql@15/bin:$PATH"

# 적용
source ~/.zshrc
```

## 2.3 Ubuntu 설치 (APT)

### 설치

```bash
# 1. 패키지 목록 업데이트
sudo apt update

# 2. PostgreSQL 설치
sudo apt install postgresql postgresql-contrib

# 3. 버전 확인
psql --version
# psql (PostgreSQL) 15.x

# 4. 서비스 상태 확인
sudo systemctl status postgresql

# 5. 서비스 시작/중지
sudo systemctl start postgresql
sudo systemctl stop postgresql
sudo systemctl restart postgresql

# 6. 부팅 시 자동 시작
sudo systemctl enable postgresql
```

### postgres 사용자로 접속

```bash
# 1. postgres 사용자로 전환
sudo -i -u postgres

# 2. psql 실행
psql

# 3. 종료
\q
exit

# 또는 한 줄로
sudo -u postgres psql
```

### 새 사용자 생성

```bash
# 1. postgres 사용자로
sudo -u postgres psql

# 2. 새 사용자 생성
CREATE USER myuser WITH PASSWORD 'mypassword';

# 3. 데이터베이스 생성
CREATE DATABASE mydb OWNER myuser;

# 4. 권한 부여
GRANT ALL PRIVILEGES ON DATABASE mydb TO myuser;

# 5. 종료
\q

# 6. 새 사용자로 접속
psql -U myuser -d mydb -h localhost
# Password: mypassword
```

## 2.5 Docker 설치 (권장: 개발/테스트)

### 기본 실행

```bash
# 1. PostgreSQL 컨테이너 실행
docker run -d \
  --name postgres \
  -e POSTGRES_PASSWORD=mysecret \
  -e POSTGRES_USER=myuser \
  -e POSTGRES_DB=mydb \
  -p 5432:5432 \
  postgres:15

# 2. 상태 확인
docker ps

# 3. 접속
docker exec -it postgres psql -U myuser -d mydb

# 4. 종료
\q

# 5. 컨테이너 중지/시작
docker stop postgres
docker start postgres

# 6. 삭제
docker rm -f postgres
```

### 볼륨 사용 (데이터 보존)

```bash
# 1. 볼륨 생성
docker volume create pgdata

# 2. 볼륨 마운트하여 실행
docker run -d \
  --name postgres \
  -e POSTGRES_PASSWORD=mysecret \
  -p 5432:5432 \
  -v pgdata:/var/lib/postgresql/data \
  postgres:15

# 3. 컨테이너 삭제해도 데이터 유지
docker rm -f postgres

# 4. 다시 시작 (데이터 그대로)
docker run -d \
  --name postgres \
  -e POSTGRES_PASSWORD=mysecret \
  -p 5432:5432 \
  -v pgdata:/var/lib/postgresql/data \
  postgres:15
```

### Docker Compose (권장)

```yaml
# docker-compose.yml
version: '3.8'

services:
  postgres:
    image: postgres:15
    container_name: postgres
    restart: always
    environment:
      POSTGRES_USER: myuser
      POSTGRES_PASSWORD: mysecret
      POSTGRES_DB: mydb
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql

volumes:
  pgdata:
```

```bash
# 시작
docker-compose up -d

# 로그 확인
docker-compose logs -f

# 중지
docker-compose down

# 데이터까지 삭제
docker-compose down -v
```

## 2.7 postgresql.conf 설정

### 파일 위치

```bash
# macOS (Homebrew)
/opt/homebrew/var/postgresql@15/postgresql.conf

# Ubuntu
/etc/postgresql/15/main/postgresql.conf

# Docker
docker exec -it postgres bash
cat /var/lib/postgresql/data/postgresql.conf

# 설정 파일 위치 확인 (psql에서)
SHOW config_file;
```

### 주요 설정

```conf
# postgresql.conf

# === 연결 설정 ===
listen_addresses = '*'          # 모든 IP에서 접속 허용
port = 5432                     # 포트
max_connections = 100           # 최대 연결 수

# === 메모리 설정 ===
shared_buffers = 256MB          # 공유 버퍼 (RAM의 25%)
effective_cache_size = 1GB      # OS 캐시 크기 (RAM의 50-75%)
work_mem = 4MB                  # 정렬/해시 작업용 메모리
maintenance_work_mem = 64MB     # VACUUM 등 유지보수용

# === WAL 설정 ===
wal_level = replica             # 복제 가능 수준
max_wal_size = 1GB              # WAL 최대 크기
min_wal_size = 80MB             # WAL 최소 크기

# === 쿼리 계획 ===
random_page_cost = 1.1          # SSD: 1.1, HDD: 4.0
effective_io_concurrency = 200  # SSD: 200, HDD: 2

# === 로깅 ===
logging_collector = on
log_directory = 'log'
log_filename = 'postgresql-%Y-%m-%d.log'
log_statement = 'all'           # 개발: all, 프로덕션: none
log_duration = on
log_min_duration_statement = 1000  # 1초 이상 쿼리만 로그

# === 통계 ===
shared_preload_libraries = 'pg_stat_statements'
pg_stat_statements.track = all
```

### 설정 변경 후 적용

```bash
# 재시작 (대부분의 설정)
# macOS
brew services restart postgresql@15

# Ubuntu
sudo systemctl restart postgresql

# Docker
docker restart postgres

# 재시작 없이 적용 (일부 설정만)
# psql에서
SELECT pg_reload_conf();
```

## 2.8 pg_hba.conf (인증 설정)

### 파일 위치

```bash
# macOS
/opt/homebrew/var/postgresql@15/pg_hba.conf

# Ubuntu
/etc/postgresql/15/main/pg_hba.conf

# 위치 확인 (psql에서)
SHOW hba_file;
```

### 기본 구조

```conf
# pg_hba.conf
# TYPE  DATABASE    USER        ADDRESS         METHOD

# 로컬 연결 (Unix socket)
local   all         all                         peer

# IPv4 로컬
host    all         all         127.0.0.1/32    scram-sha-256

# IPv6 로컬
host    all         all         ::1/128         scram-sha-256

# 외부 연결 허용 (개발 환경)
host    all         all         0.0.0.0/0       scram-sha-256
```

### 인증 방법

```
trust:
- 비밀번호 없이 접속
- 로컬 개발만 사용

password:
- 평문 비밀번호 (비권장)
- 사용 금지

md5:
- MD5 해시 비밀번호
- 레거시

scram-sha-256: (권장)
- SHA-256 해시
- PostgreSQL 10+

peer:
- OS 사용자 이름 = DB 사용자 이름
- Unix socket만

ident:
- peer와 유사
- TCP 연결 가능
```

### 실전 예시

```conf
# pg_hba.conf

# === 로컬 개발 환경 ===
local   all         all                         trust
host    all         all         127.0.0.1/32    trust

# === 프로덕션 환경 ===
# 로컬 Unix socket
local   all         postgres                    peer
local   all         all                         scram-sha-256

# 로컬 TCP
host    all         all         127.0.0.1/32    scram-sha-256
host    all         all         ::1/128         scram-sha-256

# 특정 IP만 허용
host    mydb        myuser      192.168.1.0/24  scram-sha-256

# VPN 대역
host    all         all         10.0.0.0/8      scram-sha-256

# 모든 외부 (비권장, 개발만)
host    all         all         0.0.0.0/0       scram-sha-256
```

# macOS
brew services reload postgresql@15

# Ubuntu
sudo systemctl reload postgresql

# psql에서

## 2.9 연결 테스트

### psql로 연결

```bash
# 기본 연결 (로컬)
psql

# 사용자 지정
psql -U myuser

# 데이터베이스 지정
psql -U myuser -d mydb

# 호스트 지정
psql -U myuser -d mydb -h localhost

# 포트 지정
psql -U myuser -d mydb -h localhost -p 5432

# 한 줄 쿼리 실행
psql -U myuser -d mydb -c "SELECT version();"

# 파일 실행
psql -U myuser -d mydb -f script.sql
```

### 연결 문자열

```bash
# URI 형식
psql postgresql://myuser:mypassword@localhost:5432/mydb

# 환경변수
export PGUSER=myuser
export PGPASSWORD=mypassword
export PGDATABASE=mydb
export PGHOST=localhost
export PGPORT=5432

psql  # 환경변수 사용
```

### .pgpass로 비밀번호 저장

```bash
# 1. 파일 생성
# macOS/Linux: ~/.pgpass
# Windows: %APPDATA%\postgresql\pgpass.conf

# 2. 형식
# hostname:port:database:username:password
localhost:5432:mydb:myuser:mypassword
localhost:5432:*:myuser:mypassword

# 3. 권한 설정 (macOS/Linux)
chmod 600 ~/.pgpass

# 4. 사용
psql -U myuser -d mydb
# 비밀번호 입력 없이 접속됨
```

## 2.11 트러블슈팅

### 연결 실패

```bash
# 1. PostgreSQL 실행 확인
# macOS
brew services list | grep postgresql

# Ubuntu
sudo systemctl status postgresql

# Docker
docker ps | grep postgres

# 2. 포트 리스닝 확인
lsof -i :5432
# 또는
netstat -an | grep 5432

# 3. 로그 확인
# macOS
tail -f /opt/homebrew/var/log/postgresql@15.log

# Ubuntu
sudo tail -f /var/log/postgresql/postgresql-15-main.log

# Docker
docker logs -f postgres
```

### 비밀번호 오류

```sql
-- postgres 사용자 비밀번호 재설정
-- 1. postgres로 접속
sudo -u postgres psql

-- 2. 비밀번호 변경
ALTER USER postgres PASSWORD 'newpassword';

-- 3. 다른 사용자 비밀번호 변경
ALTER USER myuser PASSWORD 'newpassword';
```

### 권한 오류

```sql
-- 1. 데이터베이스 권한
GRANT ALL PRIVILEGES ON DATABASE mydb TO myuser;

-- 2. 스키마 권한
GRANT ALL ON SCHEMA public TO myuser;

-- 3. 테이블 권한
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO myuser;

-- 4. 시퀀스 권한
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO myuser;
```

### 포트 충돌

```bash
# 1. 5432 포트 사용 중인 프로세스 확인
lsof -i :5432

# 2. 프로세스 종료
kill -9 <PID>

# 또는 PostgreSQL 포트 변경
# postgresql.conf
port = 5433

# 재시작 후 연결
psql -p 5433
```
