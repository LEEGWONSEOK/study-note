## 2. Flyway

### 설치 및 설정

```bash
# Flyway CLI 다운로드
wget -qO- https://repo1.maven.org/maven2/org/flywaydb/flyway-commandline/9.16.0/flyway-commandline-9.16.0-linux-x64.tar.gz | tar xvz

# 설정 파일
# flyway.conf
flyway.url=jdbc:postgresql://localhost:5432/mydb
flyway.user=postgres
flyway.password=password
flyway.locations=filesystem:./sql
```

### 마이그레이션 파일

```sql
-- sql/V1__Create_users_table.sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    created_at TIMESTAMPTZ DEFAULT now()
);

-- sql/V2__Add_email_column.sql
ALTER TABLE users ADD COLUMN email VARCHAR(100);

-- sql/V3__Create_posts_table.sql
CREATE TABLE posts (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id),
    title VARCHAR(200),
    content TEXT,
    created_at TIMESTAMPTZ DEFAULT now()
);
```

### 실행

```bash
# 마이그레이션 실행
./flyway migrate

# 정보 확인
./flyway info

# 롤백 (Undo 마이그레이션 작성 필요)
-- sql/U2__Undo_add_email_column.sql
ALTER TABLE users DROP COLUMN email;

./flyway undo
```

## 3. Liquibase

### 설치

```bash
# Liquibase 다운로드
wget https://github.com/liquibase/liquibase/releases/download/v4.20.0/liquibase-4.20.0.tar.gz
tar -xzf liquibase-4.20.0.tar.gz
```

### changeLog (YAML)

```yaml
# db/changelog/db.changelog-master.yaml
databaseChangeLog:
  - changeSet:
      id: 1
      author: alice
      changes:
        - createTable:
            tableName: users
            columns:
              - column:
                  name: id
                  type: serial
                  constraints:
                    primaryKey: true
              - column:
                  name: name
                  type: varchar(100)
                  constraints:
                    nullable: false
              - column:
                  name: created_at
                  type: timestamp
                  defaultValueComputed: now()

  - changeSet:
      id: 2
      author: alice
      changes:
        - addColumn:
            tableName: users
            columns:
              - column:
                  name: email
                  type: varchar(100)

  - changeSet:
      id: 3
      author: alice
      changes:
        - createIndex:
            indexName: idx_users_email
            tableName: users
            columns:
              - column:
                  name: email
```

### 실행

```bash
# 마이그레이션 실행
liquibase --changeLogFile=db/changelog/db.changelog-master.yaml \
  --url=jdbc:postgresql://localhost:5432/mydb \
  --username=postgres \
  --password=password \
  update

# 롤백
liquibase rollback-count 1
```

## 4. node-pg-migrate

### 설치

```bash
npm install node-pg-migrate
```

### 마이그레이션 생성

```bash
# 마이그레이션 생성
npx node-pg-migrate create create-users-table

# migrations/1705300000000_create-users-table.js 생성됨
```

```javascript
// migrations/1705300000000_create-users-table.js
exports.up = (pgm) => {
  pgm.createTable('users', {
    id: 'id',
    name: {
      type: 'varchar(100)',
      notNull: true,
    },
    email: {
      type: 'varchar(100)',
      unique: true,
    },
    created_at: {
      type: 'timestamp',
      notNull: true,
      default: pgm.func('current_timestamp'),
    },
  });

  pgm.createIndex('users', 'email');
};

exports.down = (pgm) => {
  pgm.dropTable('users');
};
```

### 실행

```bash
# 실행
DATABASE_URL=postgresql://postgres:password@localhost:5432/mydb \
  npx node-pg-migrate up

# 롤백
npx node-pg-migrate down
```

## 5. CI/CD 통합

### GitHub Actions

```yaml
# .github/workflows/deploy.yml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  migrate:
    runs-on: ubuntu-latest

    services:
      postgres:
        image: postgres:14
        env:
          POSTGRES_PASSWORD: password
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'

      - name: Install dependencies
        run: npm ci

      - name: Run migrations
        env:
          DATABASE_URL: postgresql://postgres:password@localhost:5432/mydb
        run: npx node-pg-migrate up
```
