# Chapter 14. 도메인 구매와 설정

## 14.1 도메인이란?

### 정의

```
도메인 = 인터넷 주소의 이름

93.184.216.34 → example.com

비유: 집 주소
도로명주소: "서울 강남구 테헤란로 123"
도메인: "example.com"
```

### 도메인 구조

```
https://blog.example.com:443/posts/123

┌──────────────────────────────────────┐
│  프로토콜: https://                  │
├──────────────────────────────────────┤
│  서브도메인: blog                     │
│  ─────────────────┐                  │
│              도메인: example          │
│                      ────────┐       │
│                          TLD: com    │
└──────────────────────────────────────┘

FQDN (Fully Qualified Domain Name):
blog.example.com.
                │
                └─ Root (생략됨)
```

### 도메인 레벨

```
.                           (Root)
    │
    ├── com.               (TLD: Top Level Domain)
    │     │
    │     └── example.com.  (Second Level Domain)
    │           │
    │           ├── www.example.com.    (Third Level)
    │           ├── blog.example.com.
    │           └── api.example.com.
    │
    ├── kr.                (국가 코드 TLD)
    │     ├── co.kr.
    │     └── ac.kr.
    │
    └── io.
          └── github.io.
```

## 14.2 TLD (Top Level Domain) 종류

### gTLD (Generic TLD)

```
일반 도메인:
.com   - 상업용 (가장 인기)
.net   - 네트워크
.org   - 비영리단체
.edu   - 교육기관
.gov   - 정부기관

신규 gTLD:
.io    - 기술 스타트업 인기
.dev   - 개발자
.app   - 앱
.ai    - AI 관련
.tech  - 기술
```

### ccTLD (Country Code TLD)

```
국가 코드:
.kr    - 대한민국
.us    - 미국
.jp    - 일본
.cn    - 중국
.de    - 독일

한국 하위 도메인:
.co.kr  - 기업
.or.kr  - 비영리
.go.kr  - 정부
.ac.kr  - 교육
```

### 가격 비교

```
┌────────┬─────────────┬──────────────┐
│  TLD   │  연간 가격   │  특징         │
├────────┼─────────────┼──────────────┤
│  .com  │  $10-15     │  가장 신뢰도 높음│
│  .net  │  $12-18     │  com 대안    │
│  .io   │  $30-50     │  개발자 선호  │
│  .dev  │  $12-18     │  구글 소유    │
│  .app  │  $15-20     │  HTTPS 필수   │
│  .kr   │  15,000원   │  한국 전용    │
│  .co.kr│  18,000원   │  한국 기업    │
└────────┴─────────────┴──────────────┘
```

## 14.3 도메인 구매

### 주요 도메인 등록 업체

```
글로벌:
- Namecheap      ✅ 추천 (저렴, 프라이버시 무료)

국내:
- 가비아
- 후이즈
- 카페24

클라우드:
- AWS Route 53
- GCP Cloud Domains
```

### 도메인 구매 프로세스 (Namecheap)

```
1. 도메인 검색
   https://www.namecheap.com
   → 검색: myproject.com

2. 도메인 선택
   myproject.com   $10.98/year ✅
   myproject.io    $34.88/year
   myproject.dev   $14.98/year

3. 장바구니 추가
   - WhoisGuard (프라이버시 보호) ✅ 추천
   - Premium DNS (선택)
   - SSL 인증서 (Let's Encrypt 무료 대안 있음)

4. 결제
   신용카드, PayPal

5. 이메일 확인
   도메인 소유권 인증 메일
   → 링크 클릭 (24시간 내)
```

### AWS Route 53으로 구매

```bash
# AWS CLI로 도메인 구매 (비싸지만 편리)
aws route53domains register-domain \
  --domain-name myproject.com \
  --duration-in-years 1 \
  --admin-contact file://contact.json \
  --registrant-contact file://contact.json \
  --tech-contact file://contact.json

# 가격: 일반적으로 다른 등록업체보다 비쌈
# 장점: AWS 통합 관리 편리
```

## 14.4 네임서버 설정

### 네임서버란?

```
도메인의 DNS 레코드를 관리하는 서버

흐름:
1. 도메인 구매 (Namecheap)
2. 네임서버를 AWS Route 53으로 변경
3. Route 53에서 DNS 레코드 관리
```

### Route 53 네임서버로 변경

```
1. Route 53 Hosted Zone 생성
   - Domain: myproject.com
   - Type: Public

2. NS 레코드 확인
   ns-123.awsdns-12.com
   ns-456.awsdns-23.net
   ns-789.awsdns-34.org
   ns-012.awsdns-45.co.uk

3. Namecheap에서 네임서버 변경
   Dashboard → Domain List → Manage
   → Nameservers: Custom DNS
   → 위 4개 입력

4. 전파 대기 (24-48시간, 보통 1-2시간)
```

### Cloudflare DNS 사용 (무료, 추천)

```
장점:
- 무료
- 빠름
- DDoS 보호
- CDN 포함

설정:
1. Cloudflare 가입
2. 사이트 추가: myproject.com
3. 네임서버 확인
   - alice.ns.cloudflare.com
   - bob.ns.cloudflare.com

4. 도메인 등록업체에서 변경
5. Cloudflare에서 DNS 레코드 관리
```

## 14.5 DNS 레코드 설정 (Route 53)

### Terraform 예시

```hcl
# 1. Hosted Zone 생성
resource "aws_route53_zone" "main" {
  name = "myproject.com"

  tags = {
    Project = "MyProject"
  }
}

# 2. A 레코드 (웹사이트)
resource "aws_route53_record" "root" {
  zone_id = aws_route53_zone.main.zone_id
  name    = "myproject.com"
  type    = "A"
  ttl     = 300
  records = ["13.125.1.100"]
}

# 3. CNAME 레코드 (www)
resource "aws_route53_record" "www" {
  zone_id = aws_route53_zone.main.zone_id
  name    = "www.myproject.com"
  type    = "CNAME"
  ttl     = 300
  records = ["myproject.com"]
}

# 4. A 레코드 (API)
resource "aws_route53_record" "api" {
  zone_id = aws_route53_zone.main.zone_id
  name    = "api.myproject.com"
  type    = "A"
  ttl     = 300
  records = ["13.125.1.101"]
}

# 5. ALIAS 레코드 (ALB)
resource "aws_route53_record" "alb" {
  zone_id = aws_route53_zone.main.zone_id
  name    = "app.myproject.com"
  type    = "A"

  alias {
    name                   = aws_lb.main.dns_name
    zone_id                = aws_lb.main.zone_id
    evaluate_target_health = true
  }
}

# 6. MX 레코드 (Gmail)
resource "aws_route53_record" "mx" {
  zone_id = aws_route53_zone.main.zone_id
  name    = "myproject.com"
  type    = "MX"
  ttl     = 3600
  records = [
    "1 aspmx.l.google.com",
    "5 alt1.aspmx.l.google.com",
  ]
}

# 7. TXT 레코드 (도메인 인증)
resource "aws_route53_record" "verification" {
  zone_id = aws_route53_zone.main.zone_id
  name    = "myproject.com"
  type    = "TXT"
  ttl     = 300
  records = [
    "google-site-verification=abc123...",
    "v=spf1 include:_spf.google.com ~all"
  ]
}
```

## 14.7 HTTPS 인증서 발급

### Let's Encrypt (무료)

```bash
# Certbot 설치
sudo apt install certbot python3-certbot-nginx

# 인증서 발급
sudo certbot --nginx -d myproject.com -d www.myproject.com

# 자동 갱신 (90일마다)
sudo certbot renew --dry-run

# Cron 설정
sudo crontab -e
0 3 * * * certbot renew --quiet
```

### AWS ACM (AWS Certificate Manager)

```hcl
# Terraform
resource "aws_acm_certificate" "cert" {
  domain_name       = "myproject.com"
  validation_method = "DNS"

  subject_alternative_names = [
    "*.myproject.com",  # 와일드카드
  ]

  lifecycle {
    create_before_destroy = true
  }
}

# DNS 검증 레코드
resource "aws_route53_record" "cert_validation" {
  for_each = {
    for dvo in aws_acm_certificate.cert.domain_validation_options : dvo.domain_name => {
      name   = dvo.resource_record_name
      record = dvo.resource_record_value
      type   = dvo.resource_record_type
    }
  }

  zone_id = aws_route53_zone.main.zone_id
  name    = each.value.name
  type    = each.value.type
  records = [each.value.record]
  ttl     = 60
}

# 검증 완료 대기
resource "aws_acm_certificate_validation" "cert" {
  certificate_arn         = aws_acm_certificate.cert.arn
  validation_record_fqdns = [for record in aws_route53_record.cert_validation : record.fqdn]
}
```

## 14.8 도메인 이전

### 도메인 이전 프로세스

```
1. 현재 등록업체에서 잠금 해제
   Domain Lock: OFF

2. Auth Code (EPP Code) 받기
   이전 인증 코드

3. 새 등록업체에서 이전 요청
   - 도메인 입력
   - Auth Code 입력

4. 이메일 확인
   - 현재 등록업체: 이전 승인
   - 새 등록업체: 이전 수락

5. 이전 완료 (5-7일)
   1년 자동 연장됨
```

### 주의사항

```
⚠️ 이전 불가 기간:
- 도메인 등록 후 60일 이내
- 이전 완료 후 60일 이내

⚠️ 준비사항:
- 네임서버 정보 백업
- DNS 레코드 백업
- 이메일 주소 유효한지 확인
```

## 14.9 도메인 갱신 관리

### 자동 갱신 설정

```
모든 등록업체에서 지원:
✅ Auto-Renew 활성화 권장

만료 주의:
- 만료 30일 전: 1차 알림
- 만료 7일 전: 2차 알림
- 만료일: 서비스 중단
- 만료 후 30일: 복구 기간 (추가 비용)
- 만료 후 75일: 삭제
```

### 도메인 만료 시나리오

```
Day 0: 만료일
→ 웹사이트 즉시 중단!
→ 이메일 중단
→ API 중단

Day 1-30: Grace Period
→ 갱신 가능 (정상 가격)

Day 31-75: Redemption Period
→ 복구 가능 (비용 $100-200)

Day 76+: 삭제
→ 누구나 다시 등록 가능
→ 복구 불가능!

→ 반드시 자동 갱신 설정!
```

## 14.11 도메인 보안

### DNSSEC

```
DNS 응답 위변조 방지

활성화:
Route 53 → Hosted Zone → DNSSEC Signing
→ KSK (Key Signing Key) 생성
→ DS 레코드를 도메인 등록업체에 등록

검증:
dig myproject.com +dnssec
```

### Domain Lock

```
무단 이전 방지

설정:
등록업체 → Domain Lock: ON

이전 시:
1. Domain Lock: OFF
2. 이전 완료
3. Domain Lock: ON (다시 활성화)
```

### WhoisGuard (프라이버시 보호)

```
WHOIS 조회 시 개인정보 숨김

WHOIS 조회:
whois myproject.com

보호 OFF:
Registrant: 홍길동
Email: hong@example.com
Phone: 010-1234-5678

보호 ON:
Registrant: WhoisGuard Protected
Email: 12345@whoisguard.com
Phone: +507-xxx-xxxx

→ 스팸, 해킹 방지
```
