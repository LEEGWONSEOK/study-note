# Chapter 29. 캐싱 전략

## 29.1 캐싱이란?

### 정의

```
캐싱 (Caching):
자주 사용하는 데이터를 빠른 저장소에 임시 보관

비유: 책상 서랍
┌────────────────────────────────┐
│ 자주 쓰는 물건 → 책상 위       │
│ 가끔 쓰는 물건 → 서랍          │
│ 안 쓰는 물건 → 창고            │
└────────────────────────────────┘

캐시 = 책상 위 (빠름, 용량 작음)
DB = 창고 (느림, 용량 큼)
```

### 캐싱 계층

```
브라우저 캐시
   ↓
CDN 캐시
   ↓
서버 캐시 (Redis/Memcached)
   ↓
애플리케이션 캐시 (메모리)
   ↓
데이터베이스 쿼리 캐시
   ↓
디스크
```

## 29.2 HTTP 캐싱

### Cache-Control

```
Cache-Control 헤더:
브라우저/CDN에 캐싱 방법 지시

주요 디렉티브:
- max-age: 캐시 유효 시간 (초)
- public: 모든 곳에서 캐싱 가능
- private: 브라우저만 캐싱
- no-cache: 재검증 필요
- no-store: 캐싱 금지
```

### 예시

```javascript
const express = require('express');
const app = express();

// 정적 파일 (1년 캐싱)
app.use('/static', express.static('public', {
  maxAge: '1y',
  immutable: true
}));
// → Cache-Control: public, max-age=31536000, immutable

// API 응답 (캐싱 안 함)
app.get('/api/user', (req, res) => {
  res.set('Cache-Control', 'no-store');
  res.json({ name: 'John' });
});

// HTML (재검증)
app.get('/', (req, res) => {
  res.set('Cache-Control', 'no-cache');
  res.sendFile('index.html');
});

// 이미지 (1주일 캐싱, CDN도 OK)
app.get('/images/:name', (req, res) => {
  res.set('Cache-Control', 'public, max-age=604800');
  res.sendFile(`images/${req.params.name}`);
});
```

### Cache-Control 조합

```javascript
// 1. 정적 리소스 (JS, CSS, 이미지)
// 파일명에 해시 포함: app.abc123.js
res.set('Cache-Control', 'public, max-age=31536000, immutable');
// → 1년 캐싱, 변경 불가

// 2. HTML
res.set('Cache-Control', 'no-cache');
// → 매번 서버에 검증 (304 Not Modified 가능)

// 3. API (개인정보)
res.set('Cache-Control', 'private, max-age=300');
// → 브라우저만 5분 캐싱

// 4. API (공개 데이터)
res.set('Cache-Control', 'public, max-age=3600, s-maxage=86400');
// → 브라우저 1시간, CDN 24시간

// 5. 민감 정보
res.set('Cache-Control', 'no-store');
// → 아예 캐싱 안 함
```

## 29.3 ETag와 조건부 요청

### ETag

```
ETag (Entity Tag):
리소스의 버전 식별자

비유: 파일 지문
┌────────────────────────────┐
│ 파일 내용 → ETag 생성      │
│ "abc123"                   │
│                            │
│ 파일 변경 → ETag 변경      │
│ "def456"                   │
└────────────────────────────┘
```

### 동작 원리

```
1차 요청:
Client → Server: GET /style.css
Server → Client: 200 OK
                 ETag: "abc123"
                 Cache-Control: no-cache

2차 요청:
Client → Server: GET /style.css
                 If-None-Match: "abc123"

[파일 변경 안 됨]
Server → Client: 304 Not Modified
                 (바디 없음, 빠름)

[파일 변경됨]
Server → Client: 200 OK
                 ETag: "def456"
                 (새 파일)
```

### Express 구현

```javascript
const crypto = require('crypto');
const express = require('express');
const app = express();

// ETag 자동 생성
app.set('etag', 'strong');  // 기본값

// 수동 ETag
app.get('/api/data', async (req, res) => {
  const data = await fetchData();
  const etag = crypto
    .createHash('md5')
    .update(JSON.stringify(data))
    .digest('hex');

  res.set('ETag', `"${etag}"`);
  res.set('Cache-Control', 'no-cache');

  // If-None-Match 확인
  if (req.headers['if-none-match'] === `"${etag}"`) {
    return res.status(304).end();
  }

  res.json(data);
});
```

### Last-Modified

```javascript
// Last-Modified 사용
app.get('/api/posts', async (req, res) => {
  const posts = await Post.findAll({
    order: [['updatedAt', 'DESC']],
    limit: 1
  });

  const lastModified = posts[0].updatedAt;

  res.set('Last-Modified', lastModified.toUTCString());
  res.set('Cache-Control', 'no-cache');

  // If-Modified-Since 확인
  const ifModifiedSince = req.headers['if-modified-since'];
  if (ifModifiedSince && new Date(ifModifiedSince) >= lastModified) {
    return res.status(304).end();
  }

  res.json(posts);
});
```

## 29.4 Redis 캐싱

### 기본 캐싱

```javascript
const express = require('express');
const { createClient } = require('redis');

const app = express();
const redis = createClient({
  host: process.env.REDIS_HOST || 'localhost',
  port: process.env.REDIS_PORT || 6379
});

redis.connect();

// 캐시 미들웨어
function cache(duration) {
  return async (req, res, next) => {
    const key = `cache:${req.originalUrl}`;

    try {
      const cached = await redis.get(key);

      if (cached) {
        console.log('Cache HIT:', key);
        return res.json(JSON.parse(cached));
      }

      console.log('Cache MISS:', key);

      // 원본 res.json 저장
      const originalJson = res.json.bind(res);

      // res.json 오버라이드
      res.json = (data) => {
        redis.setEx(key, duration, JSON.stringify(data));
        originalJson(data);
      };

      next();
    } catch (err) {
      console.error('Redis error:', err);
      next();
    }
  };
}

// 사용
app.get('/api/posts', cache(300), async (req, res) => {
  // 5분 캐싱
  const posts = await Post.findAll();
  res.json(posts);
});

app.get('/api/users/:id', cache(60), async (req, res) => {
  // 1분 캐싱
  const user = await User.findByPk(req.params.id);
  res.json(user);
});
```

### 캐시 무효화

```javascript
// 특정 키 삭제
app.post('/api/posts', async (req, res) => {
  const post = await Post.create(req.body);

  // 목록 캐시 무효화
  await redis.del('cache:/api/posts');

  res.status(201).json(post);
});

// 패턴으로 삭제
app.delete('/api/posts/:id', async (req, res) => {
  await Post.destroy({ where: { id: req.params.id } });

  // /api/posts로 시작하는 모든 캐시 삭제
  const keys = await redis.keys('cache:/api/posts*');
  if (keys.length > 0) {
    await redis.del(keys);
  }

  res.status(204).end();
});
```

### Cache-Aside 패턴

```javascript
// Cache-Aside (Lazy Loading)
async function getUser(userId) {
  const key = `user:${userId}`;

  // 1. 캐시 확인
  let user = await redis.get(key);

  if (user) {
    console.log('Cache HIT');
    return JSON.parse(user);
  }

  console.log('Cache MISS');

  // 2. DB 조회
  user = await User.findByPk(userId);

  // 3. 캐시 저장 (1시간)
  await redis.setEx(key, 3600, JSON.stringify(user));

  return user;
}

// 사용
app.get('/api/users/:id', async (req, res) => {
  const user = await getUser(req.params.id);
  res.json(user);
});

// 업데이트 시 캐시 무효화
app.put('/api/users/:id', async (req, res) => {
  const user = await User.update(req.body, {
    where: { id: req.params.id }
  });

  // 캐시 삭제
  await redis.del(`user:${req.params.id}`);

  res.json(user);
});
```

## 29.5 고급 캐싱 패턴

### Write-Through

```javascript
// Write-Through: 쓰기 시 캐시도 업데이트
async function updateUser(userId, data) {
  // 1. DB 업데이트
  const user = await User.update(data, {
    where: { id: userId },
    returning: true
  });

  // 2. 캐시 업데이트
  await redis.setEx(
    `user:${userId}`,
    3600,
    JSON.stringify(user)
  );

  return user;
}
```

### Write-Behind

```javascript
// Write-Behind: 캐시 먼저, DB는 나중에
async function updateUserAsync(userId, data) {
  // 1. 캐시 업데이트 (즉시)
  await redis.setEx(
    `user:${userId}`,
    3600,
    JSON.stringify(data)
  );

  // 2. DB 업데이트 큐에 추가
  await queue.add('update-user', { userId, data });

  return data;
}

// Worker에서 처리
queue.process('update-user', async (job) => {

```

### Refresh-Ahead

```javascript
// Refresh-Ahead: 만료 전 미리 갱신
async function getPopularPosts() {
  const key = 'posts:popular';

  let posts = await redis.get(key);

  if (posts) {
    const ttl = await redis.ttl(key);

    // 만료 5분 전이면 백그라운드 갱신
    if (ttl < 300) {
      refreshPopularPosts();  // 비동기
    }

    return JSON.parse(posts);
  }

  // 캐시 없으면 동기 로드
  posts = await Post.findAll({
    order: [['views', 'DESC']],
    limit: 10
  });

  await redis.setEx(key, 3600, JSON.stringify(posts));

  return posts;
}

async function refreshPopularPosts() {
  const posts = await Post.findAll({
    order: [['views', 'DESC']],
    limit: 10
  });

  await redis.setEx('posts:popular', 3600, JSON.stringify(posts));
}
```

## 29.6 캐시 만료 전략

### TTL (Time To Live)

```javascript
// 1. 고정 TTL
await redis.setEx('key', 3600, 'value');  // 1시간

// 2. 동적 TTL
function getTTL(dataType) {
  const ttls = {
    user: 3600,        // 1시간
    post: 1800,        // 30분
    comment: 300,      // 5분
    trending: 60       // 1분
  };
  return ttls[dataType] || 300;
}

await redis.setEx(
  `${type}:${id}`,
  getTTL(type),
  JSON.stringify(data)
);

// 3. 슬라이딩 윈도우
async function getWithSlidingExpiration(key, ttl) {
  const value = await redis.get(key);

  if (value) {
    // 캐시 히트 시 TTL 갱신
    await redis.expire(key, ttl);
    return JSON.parse(value);
  }

  return null;
}
```

### LRU (Least Recently Used)

```javascript
// Redis LRU 설정
// redis.conf
// maxmemory 1gb
// maxmemory-policy allkeys-lru

// 또는 런타임 설정
await redis.configSet('maxmemory', '1gb');
await redis.configSet('maxmemory-policy', 'allkeys-lru');

// 정책 종류:
// - noeviction: 메모리 가득 차면 에러

// - volatile-lru: expire 설정된 키만 LRU 제거

// - volatile-ttl: expire 가까운 것 먼저 제거
```

```javascript
const AWS = require('aws-sdk');
```

## 29.8 브라우저 캐싱 최적화

### Service Worker 캐싱

```javascript
// service-worker.js
const CACHE_NAME = 'v1';
const URLS_TO_CACHE = [
  '/',
  '/styles/main.css',
  '/scripts/app.js',
  '/images/logo.png'
];

// 설치 시 캐싱
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME)
      .then(cache => cache.addAll(URLS_TO_CACHE))
  );
});

// Network First (API)
self.addEventListener('fetch', (event) => {
  if (event.request.url.includes('/api/')) {
    event.respondWith(
      fetch(event.request)
        .then(response => {
          // 응답 캐싱
          const clone = response.clone();
          caches.open(CACHE_NAME)
            .then(cache => cache.put(event.request, clone));
          return response;
        })
        .catch(() => {
          // 네트워크 실패 시 캐시 사용
          return caches.match(event.request);
        })
    );
  }
});

// Cache First (정적 리소스)
self.addEventListener('fetch', (event) => {
  if (event.request.url.includes('/static/')) {
    event.respondWith(
      caches.match(event.request)
        .then(response => {
          return response || fetch(event.request);
        })
    );
  }
});
```

## 29.9 캐싱 안티패턴

### ❌ 나쁜 캐싱

```javascript
// 1. 캐시 키 충돌
await redis.set('user', JSON.stringify(user));
// → 모든 사용자가 같은 키 사용!

// ✅ 고유한 키
await redis.set(`user:${userId}`, JSON.stringify(user));

await redis.set('data', value);

await redis.setEx('data', 3600, value);

const users = await User.findAll();  // 10,000명
await redis.set('all-users', JSON.stringify(users));

// ✅ 페이지네이션 캐싱
await redis.setEx(`users:page:${page}`, 300, JSON.stringify(users));

await redis.set('user:1', JSON.stringify(user));
// [사용자 정보 변경]
// → 캐시는 오래된 데이터
```

## 29.10 실전 캐싱 아키텍처

### Multi-Layer 캐싱

```javascript
// L1: 메모리 캐시 (빠름, 작음)
const memoryCache = new Map();

// L2: Redis (중간, 중간)
const redis = createClient();

// L3: DB (느림, 큼)
const db = new Sequelize();

async function getData(key) {
  // L1 확인
  if (memoryCache.has(key)) {
    console.log('L1 Cache HIT');
    return memoryCache.get(key);
  }

  // L2 확인
  const cached = await redis.get(key);
  if (cached) {
    console.log('L2 Cache HIT');
    const data = JSON.parse(cached);
    memoryCache.set(key, data);  // L1에 저장
    return data;
  }

  // L3: DB 조회
  console.log('Cache MISS');
  const data = await db.query(`SELECT * FROM users WHERE id = ?`, [key]);

  // L2, L1 저장
  await redis.setEx(key, 3600, JSON.stringify(data));
  memoryCache.set(key, data);

  return data;
}
```

### 실전 예제

```javascript
// 전체 캐싱 전략
class CacheManager {
  constructor(redis) {
    this.redis = redis;
    this.memory = new Map();
  }

  // 캐시 읽기 (L1 → L2 → DB)
  async get(key, fetcher, options = {}) {
    const {
      memoryTTL = 60,      // 메모리 1분
      redisTTL = 3600,     // Redis 1시간
      useMemory = true
    } = options;

    // L1: 메모리
    if (useMemory && this.memory.has(key)) {
      const cached = this.memory.get(key);
      if (Date.now() - cached.timestamp < memoryTTL * 1000) {
        return cached.data;
      }
    }

    // L2: Redis
    const redisData = await this.redis.get(key);
    if (redisData) {
      const data = JSON.parse(redisData);
      if (useMemory) {
        this.memory.set(key, { data, timestamp: Date.now() });
      }
      return data;
    }

    // L3: DB
    const data = await fetcher();

    // 캐싱
    await this.redis.setEx(key, redisTTL, JSON.stringify(data));
    if (useMemory) {
      this.memory.set(key, { data, timestamp: Date.now() });
    }

    return data;
  }

  // 캐시 무효화
  async invalidate(pattern) {
    // Redis 삭제
    const keys = await this.redis.keys(pattern);
    if (keys.length > 0) {
      await this.redis.del(keys);
    }

    // 메모리 삭제
    for (const key of this.memory.keys()) {
      if (key.match(new RegExp(pattern.replace('*', '.*')))) {
        this.memory.delete(key);
      }
    }
  }

  // 메모리 정리 (주기적 실행)
  cleanup() {
    const now = Date.now();
    for (const [key, value] of this.memory.entries()) {
      if (now - value.timestamp > 60000) {
        this.memory.delete(key);
      }
    }
  }
}

// 사용
const cache = new CacheManager(redis);

setInterval(() => cache.cleanup(), 60000);  // 1분마다 정리

app.get('/api/users/:id', async (req, res) => {
  const user = await cache.get(
    `user:${req.params.id}`,
    () => User.findByPk(req.params.id),
    { memoryTTL: 30, redisTTL: 300 }
  );

  res.json(user);
});

app.put('/api/users/:id', async (req, res) => {
  await User.update(req.body, { where: { id: req.params.id } });

  await cache.invalidate(`user:${req.params.id}`);

  res.json({ message: '업데이트 완료' });
});
```

## 핵심 요약

### HTTP 캐싱
```
Cache-Control: max-age, public, private
ETag: 리소스 버전 식별
304 Not Modified: 변경 없음
```

### Redis 캐싱
```
Cache-Aside: 읽기 시 캐싱
Write-Through: 쓰기 시 즉시 캐싱
Write-Behind: 비동기 캐싱
Refresh-Ahead: 만료 전 갱신
```

### 만료 전략
```
TTL: 시간 기반
LRU: 사용 빈도 기반
슬라이딩 윈도우: 사용 시 갱신
```

### 계층
```
L1: 메모리 (빠름)
L2: Redis (중간)
L3: DB (느림)
CDN: 지역별 캐싱
```
