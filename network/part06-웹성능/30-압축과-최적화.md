# Chapter 30. 압축과 최적화

## 30.1 압축이란?

### 정의

```
압축 (Compression):
데이터 크기를 줄여서 전송

비유: 짐 싸기
┌────────────────────────────────┐
│ 옷 그냥 넣기 → 가방 꽉참      │
│ 옷 압축팩 사용 → 공간 50% 절약│
└────────────────────────────────┘

압축 전: 1MB 전송 (느림)
압축 후: 200KB 전송 (빠름)
```

### 압축 효과

```
텍스트 파일:
HTML: 60-80% 압축
CSS: 60-70% 압축
JavaScript: 50-70% 압축
JSON: 60-80% 압축

이미지:
JPEG → WebP: 25-35% 감소
PNG → WebP: 26% 감소 (무손실)
```

## 30.2 Gzip 압축

### Express Gzip

```javascript
const express = require('express');
const compression = require('compression');

const app = express();

// 기본 Gzip 압축
app.use(compression());

// 커스텀 설정
app.use(compression({
  // 1KB 이상만 압축
  threshold: 1024,

  // 압축 레벨 (1~9, 기본: 6)
  level: 6,  // 9 = 최대 압축 (느림)

  // 필터링
  filter: (req, res) => {
    // 이미 압축된 파일은 스킵
    if (req.headers['x-no-compression']) {
      return false;
    }

    // 기본 필터 사용
    return compression.filter(req, res);
  }
}));

app.get('/api/data', (req, res) => {
  res.json({ data: '...큰 데이터...' });
  // 자동으로 gzip 압축됨
});
```

### Nginx Gzip

```nginx
# nginx.conf

http {
    # Gzip 활성화
    gzip on;

    # 압축 레벨 (1~9)
    gzip_comp_level 6;

    # 최소 크기 (1KB)
    gzip_min_length 1024;

    # 압축할 MIME 타입
    gzip_types
        text/plain
        text/css
        text/javascript
        application/javascript
        application/json
        application/xml
        image/svg+xml;

    # Vary: Accept-Encoding 헤더 추가
    gzip_vary on;

    # 프록시된 요청도 압축
    gzip_proxied any;

    # IE6는 압축 안 함
    gzip_disable "msie6";

    server {
        listen 80;
        server_name example.com;

        location / {
            proxy_pass http://localhost:3000;

            # 압축 헤더 전달
            proxy_set_header Accept-Encoding gzip;
        }
    }
}
```

## 30.3 Brotli 압축

### Gzip vs Brotli

```
Brotli:
- Google 개발
- Gzip보다 15-20% 더 압축
- 느림 (압축 시간)
- 빠름 (압축 해제 시간)
- HTTPS 필수

언제 사용?
- 정적 파일: Brotli (미리 압축)
- 동적 응답: Gzip (빠른 압축)
```

### Express Brotli

```javascript
const express = require('express');
const shrinkRay = require('shrink-ray-current');

const app = express();

// Brotli + Gzip 자동 선택
app.use(shrinkRay({
  brotli: {
    quality: 11  // 1~11, 기본: 4
  },
  zlib: {
    level: 6  // Gzip 레벨
  }
}));

// 사용
app.get('/api/data', (req, res) => {
  res.json(largeData);
  // Accept-Encoding 보고 br 또는 gzip 선택
});
```

### 정적 파일 사전 압축

```bash
# 빌드 시 Brotli 압축
npm install -g brotli

# 모든 JS/CSS 압축
find ./dist -type f \( -name '*.js' -o -name '*.css' \) -exec brotli {} \;

# 결과:
# app.js → app.js.br
# style.css → style.css.br
```

```nginx
# nginx에서 사전 압축 파일 사용
server {
    listen 443 ssl http2;
    server_name example.com;

    root /var/www/dist;

    # Brotli 정적 파일 우선 사용
    location ~* \.(js|css|svg|json)$ {
        gzip_static on;
        brotli_static on;  # nginx-brotli 모듈 필요

        # .br 파일이 있으면 그걸 사용
        try_files $uri.br $uri$is_args$args;
    }
}
```

## 30.4 이미지 최적화

### 포맷 선택

```
JPEG:
- 사진
- 손실 압축
- 투명도 ❌

PNG:
- 로고, 아이콘
- 무손실 압축
- 투명도 ✅

WebP:
- 모든 용도
- JPEG보다 25-35% 작음
- 투명도 ✅
- 브라우저 지원 95%+

AVIF:
- 차세대 포맷
- WebP보다 50% 작음
- 브라우저 지원 70%+

SVG:
- 벡터 그래픽
- 확대/축소 무손실
- 텍스트 압축 가능
```

### Sharp로 이미지 변환

```javascript
const sharp = require('sharp');
const fs = require('fs').promises;

// JPEG → WebP
async function convertToWebP(inputPath, outputPath) {
  await sharp(inputPath)
    .webp({ quality: 80 })
    .toFile(outputPath);
}

// 리사이징 + WebP
async function optimizeImage(inputPath, outputPath, width) {
  await sharp(inputPath)
    .resize(width, null, {
      fit: 'inside',
      withoutEnlargement: true
    })
    .webp({ quality: 80 })
    .toFile(outputPath);
}

// 다중 크기 생성
async function generateResponsiveImages(inputPath) {
  const sizes = [320, 640, 1024, 1920];
  const promises = sizes.map(size =>
    sharp(inputPath)
      .resize(size)
      .webp({ quality: 80 })
      .toFile(`output-${size}.webp`)
  );

  await Promise.all(promises);
}

// 사용
await convertToWebP('photo.jpg', 'photo.webp');
await optimizeImage('hero.png', 'hero.webp', 1920);
await generateResponsiveImages('banner.jpg');
```

### Lazy Loading

```html
<!-- 네이티브 lazy loading -->
<img src="image.jpg" loading="lazy" alt="Lazy Image">

<!-- Intersection Observer -->
<img data-src="image.jpg" class="lazy" alt="Lazy Image">

<script>
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      img.classList.remove('lazy');
      observer.unobserve(img);
    }
  });
});

document.querySelectorAll('.lazy').forEach(img => {
  observer.observe(img);
});
</script>
```

## 30.7 폰트 최적화

### 폰트 로딩 전략

```css
/* font-display 옵션 */

/* auto: 브라우저 기본 */
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: auto;
}

/* swap: fallback 먼저 표시 (권장) */
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: swap;
  /* FOUT (Flash of Unstyled Text) 발생 가능 */
}

/* block: 폰트 로드까지 대기 (3초) */
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: block;
  /* FOIT (Flash of Invisible Text) */
}

/* fallback: 100ms만 대기 */
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: fallback;
}

/* optional: 캐시된 경우만 사용 */
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2');
  font-display: optional;
}
```

## 30.8 리소스 힌트

### Preload, Prefetch, Preconnect

```html
<!-- Preload: 현재 페이지에 필요 (높은 우선순위) -->
<link rel="preload" href="hero.jpg" as="image">
<link rel="preload" href="app.js" as="script">
<link rel="preload" href="styles.css" as="style">
<link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin>

<!-- Prefetch: 다음 페이지에 필요 (낮은 우선순위) -->
<link rel="prefetch" href="/page2.html">
<link rel="prefetch" href="/page2.js">

<!-- Preconnect: DNS + TCP + TLS 미리 연결 -->
<link rel="preconnect" href="https://api.example.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- DNS-prefetch: DNS만 미리 조회 -->
<link rel="dns-prefetch" href="https://cdn.example.com">

<!-- Prerender: 페이지 미리 렌더링 (Chrome만) -->
<link rel="prerender" href="/next-page.html">
```

### 동적 Prefetch

```javascript
// 링크에 마우스 올리면 prefetch
document.querySelectorAll('a').forEach(link => {
  link.addEventListener('mouseenter', () => {
    const href = link.getAttribute('href');

    if (!document.querySelector(`link[rel="prefetch"][href="${href}"]`)) {
      const prefetch = document.createElement('link');
      prefetch.rel = 'prefetch';
      prefetch.href = href;
      document.head.appendChild(prefetch);
    }
  });
});

// quicklink 라이브러리 사용
import quicklink from 'quicklink';

quicklink.listen({
  threshold: 0.5,  // 50% 보이면 prefetch
  timeout: 2000,   // 2초 idle 후
  priority: true   // fetchpriority="high"
});
```

### 파일 해싱

```javascript
// webpack.config.js
module.exports = {
  output: {
    filename: '[name].[contenthash].js',
    chunkFilename: '[name].[contenthash].chunk.js'
  },

  plugins: [
    new MiniCssExtractPlugin({
      filename: '[name].[contenthash].css'
    })
  ]
};

// 결과:
// app.abc123.js
// vendor.def456.js
// styles.789xyz.css

// → 파일 변경 시 해시 변경
// → 캐시 무효화 자동
```

### HTTP/2 Server Push

```javascript
// Express HTTP/2 Server Push
const http2 = require('http2');
const fs = require('fs');

const server = http2.createSecureServer({
  key: fs.readFileSync('key.pem'),
  cert: fs.readFileSync('cert.pem')
});

server.on('stream', (stream, headers) => {
  if (headers[':path'] === '/') {
    // HTML 응답
    stream.respond({
      'content-type': 'text/html',
      ':status': 200
    });

    // CSS, JS Push
    stream.pushStream({ ':path': '/styles.css' }, (err, pushStream) => {
      pushStream.respond({ 'content-type': 'text/css' });
      pushStream.end(fs.readFileSync('styles.css'));
    });

    stream.pushStream({ ':path': '/app.js' }, (err, pushStream) => {
      pushStream.respond({ 'content-type': 'application/javascript' });
      pushStream.end(fs.readFileSync('app.js'));
    });

    stream.end('<html>...</html>');
  }
});

server.listen(443);
```
